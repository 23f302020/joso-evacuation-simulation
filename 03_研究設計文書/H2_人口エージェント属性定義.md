# H2：人口エージェントの属性定義

> 作成日：2026/04/22  
> 目的：シミュレーションで扱う人口エージェントの種別・台数・行動を定義する。  
> 誰が車で逃げて、誰がバスに乗り、誰が逃げ遅れるかを明示する。

---

| 項目 | 数値 | 出典 |
|------|------|------|
| 総人口 | **61,483人** | 茨城県統計（2015年10月） |

| 非保有世帯の人口 | **約8,000人** | 3,500世帯 × 平均2.3人/世帯 |

## エージェントの種別定義

シミュレーション上の人口を4種別に分類する。

| 種別 | 定義 | 人数（概算） |
|------|------|------------|
| **Type 1：車保有・非高齢者** | 65歳未満かつ自家用車あり | **約38,500人** |
| **Type 2：車保有・高齢者** | 65歳以上かつ自家用車あり | **約12,800人** |
| **Type 3：車非保有・非高齢者** | 65歳未満かつ自家用車なし | **約4,700人** |
| **Type 4：車非保有・高齢者** | 65歳以上かつ自家用車なし | **約3,300人** |

> **Type 1〜2の計算：**  
> 総人口(61,483) − 非保有世帯人口(8,000) = 53,483人が車保有世帯の人口  
> うち高齢者(27%)：53,483 × 0.27 ≈ 12,800人 → Type 2  
> 非高齢者：53,483 − 12,800 = 40,700人 → Type 1（一部は同居家族のため車運転不可だが第1近似として全員が車で避難）  
>   
> **Type 3〜4の計算：**  
> 非保有世帯8,000人のうち高齢者(27%)：8,000 × 0.27 ≈ 2,200人 → Type 4  
> 非高齢者：8,000 − 2,200 = 5,800人 → Type 3（一部は若年者で徒歩も可能）

## シナリオ別の行動定義

### シナリオA（ベースライン：車のみ）

| 種別 | 避難行動 | 道路への影響 |
|------|---------|------------|
| Type 1 | 自家用車で避難所へ向かう | +1台/世帯（平均） |
| Type 2 | 自家用車で避難所へ向かう（同居家族が運転） | +1台/世帯 |
| Type 3 | **自力では逃げられない → 近隣・家族が迎えに来る** | 迎え車 +1台/非保有世帯 |
| Type 4 | **自力では逃げられない → 迎えに来る人がいない場合は孤立** | 迎え車 +(0〜1台)/世帯 |

**シナリオAの道路上の車両数：**

```
自家用車での避難：20,000台（非保有世帯3,500を除いた世帯数）
迎えの救出走行：+3,500台（非保有世帯分）
─────────────────────────
合計：約23,500台
```

---

### シナリオB（提案：バス併用）

| 種別 | 避難行動 | 道路への影響 |
|------|---------|------------|
| Type 1 | 自家用車で避難所へ向かう（シナリオAと同じ） | +1台/世帯 |
| Type 2 | 自家用車で避難所へ向かう（同じ） | +1台/世帯 |
| Type 3 | **バスで避難所へ向かう** | 迎えの救出走行が不要 → 車両削減 |
| Type 4 | **バスで避難所へ向かう（優先乗車）** | 迎えの救出走行が不要 → 車両削減 |

**シナリオBの道路上の車両数：**

```
自家用車での避難：20,000台（シナリオAと同じ）
迎えの救出走行：0台（バスが代替するため不要）
バス：+5台
─────────────────────────
合計：約20,005台（シナリオAより約3,495台減少）
```

> **渋滞緩和の仮説：** 約15%の車両削減（23,500 → 20,005台）が、主要避難路の渋滞を有意に緩和するかどうかを交通流シミュレーションで検証する。

## バス優先乗車の定義（シナリオB）

バスの輸送容量（ベースケース5台で約324人）は全Type 3・4を一度に輸送するには不足する（Type 3+4合計 約8,000人）。  
そのため、乗車優先順位を以下のように定義する。

| 優先度 | 乗車対象 | 人数 |
|--------|---------|------|
| **最優先** | Type 4（車非保有・高齢者） | **約3,300人** |
| 次点 | Type 3（車非保有・非高齢者）のうち行動困難者 | **約500人** |
| それ以外 | Type 3の残り（若年・徒歩避難も可能） | **約4,200人**（徒歩避難または待機） |

**バスの複数往復で段階的に輸送する（先着順ではなく脆弱者優先）。**

## 空間分布の設定方法

| データ | 使用目的 |
|--------|---------|
| e-Stat 250mメッシュ（T001109）| 各メッシュの総人口・高齢者人口を取得 |
| 高齢化率（27%）| 各メッシュに一律に適用（第1近似） |
| 車保有率（85%）| 各メッシュに一律に適用（第1近似） |
| 浸水エリアとの重ね合わせ | 浸水メッシュ内のエージェントのみがシミュレーション対象 |

> **精緻化の余地：** 地区ごとの高齢化率・車保有率に差があるが、第1近似として市全体の平均値を各メッシュに適用する。感度分析として高齢化率の地域差（高齢地区：35%・低齢地区：20%）を試す。

## 浸水エリア内の対象人口（推定）

常総市の浸水面積は約40km²で市全体の約1/3。

| 種別 | 市全体 | 浸水エリア内（推定1/3） |
|------|--------|----------------------|
| Type 1 | 38,500人 | **約12,800人** |
| Type 2 | 12,800人 | **約4,300人** |
| Type 3 | 4,700人 | **約1,600人** |
| Type 4 | 3,300人 | **約1,100人** |
| **合計** | 61,483人 | **約19,800人** |

> シミュレーションの主な対象は上記の約2万人（浸水エリア内）。  
> そのうちバス輸送の優先対象（Type 4 + Type 3行動困難者）は約2,200人。
