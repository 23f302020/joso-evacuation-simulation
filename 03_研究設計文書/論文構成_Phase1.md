## 論文構成

### 第1章 序論

| 節 | 内容 |
|----|------|
| 1.1 研究背景 | 2015年鬼怒川氾濫の概要と被害実態。自家用車避難中の浸水・孤立事例。浸水進行による道路閉鎖が避難を困難にする問題。 |
| 1.2 研究目的 | 実際の浸水時系列データと道路ネットワークを用いて、時間経過に伴う避難困難性の変化を定量的に推計する。 |
| 1.3 研究の対象・範囲 | 空間：茨城県常総市（鬼怒川氾濫浸水域）。時間：破堤（2015/09/10 12:50）から2015/09/16 10:20までの8時点。手法：静的最短経路分析（渋滞は対象外）。 |
| 1.4 論文構成 | 各章の概要を1〜2文で説明。 |

---

### 第2章 先行研究・関連研究

| 節 | 内容 |
|----|------|
| 2.1 洪水時の避難行動研究 | 自家用車避難の実態と問題点に関する既存研究。逃げ遅れ発生メカニズムの先行知見。 |
| 2.2 GISを用いた道路閉鎖・避難経路分析 | 浸水深と道路通行可否の関係（0.5m閾値の根拠）。ネットワーク分析による避難困難性評価の先行事例。 |
| 2.3 オープンデータを活用した防災分析 | OSM・国土数値情報・e-Statを組み合わせた分析事例。 |
| 2.4 本研究の位置づけ | 既存研究との差分：実際の浸水時系列KML+ハザードマップGMLの統合、250mメッシュ人口を用いた時点別逃げ遅れ推計。 |

---

### 第3章 研究手法

| 節 | 内容 |
|----|------|
| 3.1 使用データ | 国土地理院 D1-No.917 KML（8時点浸水境界）、国土数値情報 A31a-2024 GML（浸水深ポリゴン）、OSM（道路NW）、P20 Shapefile（避難施設）、e-Stat 250mメッシュ人口。各データの出典・取得方法・ライセンスを明示。 |
| 3.2 道路封鎖条件の設定 | 浸水深0.5m以上（waterDepth≥2）で当該道路エッジを封鎖と判定する根拠（国土交通省の通行困難基準）。 |
| 3.3 分析フロー | 道路NW取得 → 浸水データ読み込み → 空間照合 → 封鎖リスト生成 → ルート検索の5段階。各段階の入出力を明示。 |
| 3.4 逃げ遅れの定義 | 「当該時点における封鎖状況のもとで、最寄り避難所への最短経路が存在しないエージェント」と定義。Dijkstra法（重み=道路距離）を使用。渋滞・通行速度は考慮しない静的分析であることを明記。 |
| 3.5 実装環境 | Python 3.13、osmnx、geopandas、networkx、pyogrio、folium。 |

---

### 第4章 分析結果

| 節 | 内容 |
|----|------|
| 4.1 常総市道路ネットワークの概要 | ノード数・エッジ数、主要幹線道路の分布。道路NW可視化地図を図として掲載。 |
| 4.2 浸水範囲の時系列変化 | 8時点の浸水ポリゴン面積の推移（表・グラフ）。破堤直後の急速な拡大と収束の様子を記述。 |
| 4.3 時点別道路封鎖状況 | 各時点の封鎖エッジ数・封鎖率（全エッジ数に対する割合）の推移表。封鎖が集中した地域の地図。 |
| 4.4 時点別避難ルートの変化 | 破堤直後と最終時点の避難ルート比較地図。封鎖増加に伴うルート消滅・迂回の発生を視覚的に示す。 |
| 4.5 逃げ遅れ人数の時系列推移 | 各時点の逃げ遅れエージェント数（人口換算）の推移グラフ。地区別の内訳（どの地域で逃げ遅れが多いか）。 |

---

### 第5章 考察

| 節 | 内容 |
|----|------|
| 5.1 浸水進行と避難困難性の関係 | 浸水面積拡大と逃げ遅れ人数増加の相関。逃げ遅れが急増する転換点となる時刻と、その背景（主要幹線道路の封鎖タイミング）の考察。 |
| 5.2 避難困難地域の特定 | 孤立しやすい地区の地理的条件（鬼怒川との位置関係、避難所へのアクセス道路数）。 |
| 5.3 分析の限界と留意点 | 静的分析であること（渋滞・車両競合を考慮しない）。LineStringバッファ処理による誤差。避難行動の意思決定を考慮していないこと。 |
| 5.4 今後の展望 | ①SUMOによる動的シミュレーションで渋滞を考慮した逃げ遅れ推計。②デマンドバス追加による自家用車避難との比較評価。③本手法の他洪水リスク地域への転用。④リアルタイム洪水予報APIとの連携による避難支援システム化。 |
