# 論文構成 — Phase 1 + Phase 2 完成した場合

> 作成日：2026/04/29
> 前提：Phase 1（静的避難困難性推計）+ Phase 2（SUMO動的シミュレーション）まで完成した場合の構成
> 論文タイトル案：「河川氾濫時における自家用車避難の困難性分析 ─ 浸水時系列データとマルチエージェントシミュレーションの統合 ─」

---

## Phase 1 との主な差分

| 項目 | Phase 1 のみ | Phase 1 + 2 |
|------|-------------|-------------|
| 分析手法 | 静的最短経路（Dijkstra） | 静的分析 + SUMO動的シミュレーション |
| 渋滞考慮 | なし | あり（車両競合・速度低下） |
| 逃げ遅れ定義 | 経路が存在しないエージェント | 浸水到達時刻に浸水エリア内に残存した車両 |
| 出力指標 | 逃げ遅れ人数（時点別） | 逃げ遅れ車両数 + 渋滞指標（平均速度・密度） |
| 論文の厚み | 27〜38ページ | 34〜49ページ |

## 論文構成

### 第1章 序論

| 節 | 内容 |
|----|------|
| 1.1 研究背景 | 2015年鬼怒川氾濫の概要と被害実態。自家用車避難中の浸水・孤立事例。渋滞による避難遅延問題（静的分析では捉えられない現象）。 |
| 1.2 研究目的 | 浸水時系列データと交通シミュレーションを組み合わせ、渋滞を考慮した上での避難困難性を定量的に評価する。 |
| 1.3 研究の対象・範囲 | 空間：茨城県常総市。時間：破堤から2015/09/16 10:20までの8時点。手法：静的分析（Phase 1）と動的シミュレーション（Phase 2）の2段構成。 |
| 1.4 論文構成 | 各章の概要を1〜2文で説明。 |

---

### 第2章 先行研究・関連研究

| 節 | 内容 |
|----|------|
| 2.1 洪水時の避難行動研究 | 自家用車避難の実態と問題点に関する既存研究。逃げ遅れ発生メカニズムの先行知見。 |
| 2.2 GISを用いた道路閉鎖・避難経路分析 | 浸水深と道路通行可否の関係（0.5m閾値の根拠）。ネットワーク分析による避難困難性評価の先行事例。 |
| 2.3 交通シミュレーションを用いた避難研究 | SUMOなどのマルチエージェント交通シミュレーターを用いた避難研究事例。渋滞考慮の重要性。 |
| 2.4 オープンデータを活用した防災分析 | OSM・国土数値情報・e-Statを組み合わせた分析事例。 |
| 2.5 本研究の位置づけ | 静的分析と動的シミュレーションを組み合わせた2段構成の新規性。 |

---

### 第3章 研究手法

| 節 | 内容 |
|----|------|
| 3.1 使用データ | 国土地理院KML、A31a GML、OSM、P20 Shapefile、e-Stat 250mメッシュ人口。各データの出典・ライセンスを明示。 |
| 3.2 道路封鎖条件の設定 | 浸水深0.5m以上（waterDepth≥2）で封鎖と判定する根拠。 |
| 3.3 Phase 1：静的避難困難性推計 | 分析フロー・逃げ遅れ定義（Phase 1 の手法を簡潔に記述）。 |
| 3.4 Phase 2：SUMO動的シミュレーション | OSM道路NW → netconvert → SUMO .net.xml 変換手順。車両エージェント投入条件（250mメッシュ重心・保有台数から推計）。TraCIによる浸水時系列連動の動的道路閉鎖手順。逃げ遅れ車両の定義（浸水到達時刻に浸水エリア内に残存）。 |
| 3.5 実装環境 | Python 3.13、osmnx、geopandas、networkx、pyogrio、folium、SUMO、TraCI。 |

### 第4章 分析結果

| 節 | 内容 |
|----|------|
| 4.1 常総市道路ネットワークの概要 | ノード数・エッジ数、主要幹線道路の分布。 |
| 4.2 浸水範囲の時系列変化 | 8時点の浸水ポリゴン面積の推移（表・グラフ）。 |
| 4.3 時点別道路封鎖状況 | 各時点の封鎖エッジ数・封鎖率の推移表と地図。 |
| 4.4 静的分析の結果（Phase 1） | 時点別避難ルートの変化・逃げ遅れ人数の推移（Phase 1 結果の要約）。 |
| 4.5 動的シミュレーションの結果（Phase 2） | 車両速度・密度の時系列変化（渋滞の発生・解消）。渋滞考慮での逃げ遅れ車両数の推移。渋滞発生箇所の地図上での可視化。 |
| 4.6 静的分析と動的シミュレーションの比較 | 逃げ遅れ数の差（渋滞考慮によってどれだけ増加するか）。静的分析が楽観的推計になる理由と差の大きさ。 |

---

### 第5章 考察

| 節 | 内容 |
|----|------|
| 5.1 浸水進行と避難困難性の関係 | 静的分析の結果から、逃げ遅れが急増する転換点と主要幹線道路の封鎖タイミングの考察。 |
| 5.2 渋滞が逃げ遅れに与える影響 | 渋滞考慮の有無で逃げ遅れがどの程度変わるかの定量考察。渋滞が集中しやすい道路区間・時刻の特定。 |
| 5.3 避難困難地域の特定 | 静的分析と動的シミュレーション両方の結果から特定した危険地区。 |
| 5.4 分析の限界と留意点 | 車両の経路選択行動を単純化していること。避難タイミングの均一仮定。公共交通を考慮しないこと。 |
| 5.5 今後の展望 | ①デマンドバス追加によるシナリオ比較（Phase 3）。②他洪水リスク地域への転用。③リアルタイム化による避難支援システム化。 |

---

| 6.2 今後の課題 | 5.5の展望を課題として再整理し、優先順位付きで記述。 |
