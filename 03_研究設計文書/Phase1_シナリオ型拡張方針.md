# Phase 1 シナリオ型拡張方針

作成日：2026/05/01

---

## 1. 目的

本書は、Phase 1 の現状システムを受けて、浸水時系列データをそのまま再現する構成から、研究成果として説明しやすい「シナリオ型浸水拡大・任意地点ルート検索」へ拡張する判断を整理するための文書である。

コード修正前に、修正前後の考え方、変更対象、今後決めるべき事項を明確にする。

---

## 2. 現状の課題

Phase 1 では、実データを用いて浸水時刻ごとの道路閉鎖と迂回ルート検索を実装している。

一方で、現状の浸水時系列データでは、時間ごとの浸水範囲の変化が小さい、またはルート検索の出発地点として扱われる人口メッシュが限られているため、可視化上は「避難ルート検索の成果」が少なく見える。

特に、地図上では広い浸水範囲が表示されている一方、ルート検索では浸水エリアと照合された一部の人口メッシュ重心のみが出発地点になっている。そのため、浸水マップ全体の広がりに対して、検索される避難ルート数が少ないという構造的な差がある。

---

## 3. 修正前と修正後の整理

| 項目 | 修正前 | 修正後 |
| --- | --- | --- |
| Phase 1 の位置づけ | 実際の浸水時系列データを用いて、時刻別の道路閉鎖と迂回ルートを確認する | 実データを根拠にしつつ、最終浸水範囲から段階的に浸水が広がるシナリオを作成し、避難ルート変化を確認する |
| 浸水範囲 | 取得済みの KML / A31a / 浸水ナビ由来データを時刻別に利用 | 最終的な浸水範囲を指定し、破堤地点または基準地点から t0〜t7 に少しずつ拡大する |
| ルート出発地点 | 浸水エリアと交差した人口メッシュ重心 | 地図上でユーザーが指定した任意地点を出発地点にできるようにする |
| 避難先 | P20 避難施設データから抽出した常総市の洪水対応避難所19件 | 同左。最寄りの洪水対応避難所を検索対象とする |
| 道路閉鎖 | 実データの時刻別浸水範囲と道路リンクの交差で閉鎖 | シナリオ上の時刻別浸水範囲と道路リンクの交差で閉鎖 |
| 成果物 | t0〜t7 の静的な避難ルート HTML | t0〜t7 の浸水推移を選び、地点指定でルートを確認できる HTML を追加 |
| 卒論上の説明 | 実績データの再現性を中心に説明 | 実績データを根拠にした避難ルート探索機能の検証シナリオとして説明 |

## 4. 研究上の判断

| 判断項目 | 採用方針 | 理由 |
| --- | --- | --- |
| 実データの扱い | 対象地域・浸水範囲・避難所・道路ネットワークの根拠として継続利用する | 完全な仮想条件にせず、2015年常総市の事例に基づく研究として説明できるため |
| 浸水推移 | 最終浸水範囲を t0〜t7 に段階分割する | 現状の実時系列では変動が小さく、ルート変化の可視化効果が弱いため |
| 破堤地点 | 常総市三坂町の破堤地点を基準候補とする | 2015年9月10日12時50分の破堤時刻・地点が既存文書に整理済みであるため |
| ルート検索 | 任意地点から最寄り避難所へのルート検索を追加する | 浸水地域内の特定地点を想定した避難行動を確認できるため |
| 道路閉鎖 | 浸水深0.5m以上を閉鎖条件とする方針を維持する | 既存 Phase 1 の閉鎖条件と整合するため |
| 累積閉鎖 | 基本は累積閉鎖を採用し、必要に応じて非累積と比較する | 洪水時に一度冠水した道路を安全側に扱えるため |

## 8. 実装前に決める事項

| 決定事項 | 候補 | 現時点の推奨 |
| --- | --- | --- |
| 最大浸水範囲 | A31a の浸水想定区域、既存時系列の最大浸水範囲、手動指定範囲 | A31a または既存時系列の最大範囲を採用 |
| 拡大基準点 | 破堤地点、浸水範囲の重心、複数の浸水開始点 | 破堤地点を基本とする |

| 出力形式 | 既存 HTML に追加、新規シナリオ HTML を作成 | 新規シナリオ HTML を作成し、トップページから遷移 |

## 9. 現時点の結論

Phase 1 は、実データのみの再現に限定するとルート検索結果の変化が小さく、成果として見えにくい。

そのため、実データを基礎資料として維持しながら、最終浸水範囲を段階的に広げるシナリオ型の浸水推移を追加し、任意地点から近くの避難場所へのルート検索を行える構成へ拡張する方針が妥当である。

この変更は、実災害の完全再現ではなく、浸水進行に応じた避難ルート探索の有効性を示すためのシミュレーションとして位置づける。
