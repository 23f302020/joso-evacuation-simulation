## 概要

シミュレーションモデルでは現実を単純化するための「仮定」が必要になる。  
仮定が曖昧なまま実装に進むと、後から根拠を問われた際に答えられなくなる。  
このファイルでは全ての仮定を明示し、根拠の有無・確認状況を管理する。

---

## 1. 要避難者の定義

| 項目 | 内容 |
|------|------|
| **仮定** | 浸水深 **0.5m以上** の250mメッシュに居住する高齢者（65歳以上）を「要避難者」とみなす |
| **根拠** | 国土交通省の洪水浸水想定区域図では「0.5m〜3m未満」を「床上浸水」の基準とし、歩行が困難になる目安として用いられる |
| **確認状況** | ✅ 参考根拠あり（国交省基準） |
| **留意点** | 障害者・乳幼児連れなども要避難者に含めるべきだが、人口メッシュデータで高齢者以外の属性が取れない場合は高齢者のみに限定し、その旨を論文で明記する |

---

## 2. 人口データの粒度

| 項目 | 内容 |
|------|------|
| **仮定** | e-Stat APIの「250mメッシュ人口統計」を使用する |
| **根拠** | 国勢調査ベースで無償取得可能。250mメッシュは浸水エリアとのGIS重ね合わせに十分な粒度 |
| **確認状況** | ✅ e-Stat APIで取得可能であることを確認済み |
| **留意点** | 最新の国勢調査データの年次を確認し、シミュレーション想定年次とのズレを論文で注記する |

---

## 3. 車両容量の仮定

| 車種 | 定員（仮定） | 根拠 |
|------|------------|------|
| 標準ミニバン型デマンド車 | **8人** | 国交省「デマンド型交通の手引き」（ジャンボタクシー型、乗客定員8名）・坂出市の実例「1便当たり8名まで」と一致 |
| 福祉車両（車椅子対応） | **4人**（車椅子1台＋介助者1名＋同乗者2名） | トヨタ ハイエース福祉車両（リフトタイプ、車椅子1台収容）の実仕様と整合 |
| 大型バス | 本研究スコープ外（Phase 1では対象外） | — |

> **確認状況：** ✅ 根拠確認済み（国交省「デマンド型交通の手引き」・ハイエース福祉仕様）

---

## 4. 福祉車両の必要比率

| 項目 | 内容 |
|------|------|
| **仮定** | 要避難者のうち **20%** が福祉車両（車椅子対応）を必要とすると仮定する |
| **根拠** | 公式統計に直接値なし。要介護3以上は65歳以上高齢者全体の約6〜7%（厚労省「介護保険事業状況報告」令和5年度末）。「要避難者（要支援者名簿登録者）」はより障害・介護度が高い集団であるため、20%は保守的（安全側）の上界設定として合理的に解釈できる |
| **確認状況** | ✅ 方針確定：「保守的設定として明記」＋感度分析（10%・20%・30%）で対応 |
| **論文での扱い** | 「要避難者のうち車椅子対応車両を必要とする比率は公式統計から直接確認できないため、保守的な仮定として20%を設定した。感度分析として10%〜30%の範囲で必要車両台数・避難完了時間の変化を確認した。」 |

---

## 5. 道路閉鎖の条件

| 項目 | 内容 |
|------|------|
| **仮定** | 浸水深 **0.5m以上** の道路リンクを通行不可とする（**30cmから修正**） |
| **根拠** | 国土交通省「洪水ハザードマップ作成の手引き」および「川の防災情報」：「浸水深0.5m以上で一般乗用車の通行が事実上不可能。エンジン停止リスク大」と明示。JAF走行テストでも60cmでセダンはエンジン停止を確認 |
| **確認状況** | ✅ 根拠確認済み・0.5mへ修正推奨（要意思決定） |
| **対象データ** | 国土数値情報「浸水想定区域データ（A31）」＋OpenStreetMap道路ネットワーク（osmnx）の重ね合わせ |
| **法定基準** | 「○cm以上で通行止め」という統一的な国家基準は存在しない。自治体が現地判断する。自治体の実務では30〜50cmで通行止め措置が多い |

---

## 6. 避難完了の定義

| 項目 | 内容 |
|------|------|
| **仮定** | 要避難者が **指定避難所に到着した時点** を「避難完了」とみなす |
| **根拠** | 最もシンプルかつ検証しやすい定義。「浸水エリアを脱出した時点」も候補だが、避難所到着の方が現実の評価に近い |
| **確認状況** | ✅ 定義として妥当（先行研究でも同様の定義が多い） |
| **留意点** | 避難所の収容人数の上限を加味するかどうかを Phase 4 で決定する |

---

## 7. シミュレーションの時間設定

| 項目 | 内容 |
|------|------|
| **仮定** | 発災から **6時間以内** をシミュレーション対象とする |
| **根拠** | 気象庁の洪水警報発表から氾濫発生までの標準リードタイム（3〜6時間）・国交省「マイ・タイムライン」が示す「氾濫5時間前からの避難行動開始」と整合。令和元年台風19号等の実際の洪水事例でも避難指示〜浸水まで数時間〜6時間程度 |
| **確認状況** | ✅ 根拠確認済み |
| **出典** | 気象庁「防災気象情報と警戒レベルとの対応」・国交省「マイ・タイムライン」 |

## 9. 避難者の行動モデル（エージェント4種別）

| 種別 | 定義 | シナリオA | シナリオB |
|------|------|----------|----------|
| **Type 1**：車保有・非高齢者 | 65歳未満・車あり | 車で避難 | 車で避難（変わらず） |
| **Type 2**：車保有・高齢者 | 65歳以上・車あり | 車で避難 | 車で避難（変わらず） |
| **Type 3**：車非保有・非高齢者 | 65歳未満・車なし | 救出走行依存 or 孤立 | バスで避難 |
| **Type 4**：車非保有・高齢者 | 65歳以上・車なし | 救出走行依存 or 孤立 | バスで避難（最優先） |

**シナリオAの道路上の車両：約23,500台（自家用車20,000 + 救出走行3,500）**  
**シナリオBの道路上の車両：約20,005台（自家用車20,000 + バス5台）→ 約15%削減**
