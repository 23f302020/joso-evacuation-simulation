## 研究タイトル（案）

**「河川氾濫時における自家用車・救出走行とデマンド交通車両転用型避難シャトルの比較シミュレーション ― 鬼怒川氾濫を事例として ―」**

---

## 研究の背景と動機

### 問題の構造

```
河川氾濫の発生
    ↓
住民が一斉に自家用車で避難を開始
    ↓
道路が車で飽和 → 渋滞発生
    ↓
渋滞中に浸水が進む → 逃げ遅れ発生
```

### 提案するアプローチ

```
想定：既存のデマンド交通車両を災害時に転用
            ↓
災害発生時：事前固定した乗降地点・避難所間の避難シャトルとして往復
            （運行中の需要応答型経路最適化は行わない）
            ↓
道路上の自家用車総数が減少 → 渋滞緩和 → 逃げ遅れ減少
```

上図は研究着手時の**事前仮説であり、結論ではない**（決定47）。実装したScenario Bは、事前生成した固定ルートを運行中に変更しない。

**重要な前提：** 本研究はデマンド交通で使用し得る車両を災害時に転用する想定であり、平時の実運行を再現していない。実装した運行形態は、事前固定した乗降地点・避難所間を往復する避難シャトルであって、予約に応じて経路を最適化する動的DRTではない。

---

## 研究の目的

以下の点について差が生じるか、その差を本モデルで検出できるかを方向中立に検証する。

1. **正式判定：** Scenario A/B間のType3/4避難完了率の差を検出できるか
2. **記述・補助評価：** 完了時間、公平性、道路混雑、逃げ遅れ絶対数にどのような差が観測されるか

---

## 比較シナリオの設計

| シナリオ | 内容 |
|---------|------|
| **A（ベースライン）** | 自家用車8,164台＋Type3/4を送る救出走行1,405台。バスなし。 |
| **B（車両転用）** | 自家用車8,164台＋救出走行1,351台に、デマンド交通車両を転用した固定経路避難シャトルを加える。 |

### バスの設定（提案シナリオB）

| 項目 | 内容 |
|------|------|
| 平常時の運行 | 本モデルでは再現しない。デマンド交通車両を転用可能と仮定 |
| 災害時の切り替え | 事前固定した乗降地点・避難所間をTraCIで往復（需要応答型の経路最適化なし） |
| 主な利用者 | 高齢者・自家用車非保有世帯 |
| 車両 | 複数乗車可能なバス（一度に複数人を乗せることで車の台数を減らす） |

## 評価指標

> **2026-07-20改訂（AUD-1）：正式判定はType3/4避難完了率のみ。完了時間ECDFとworst-offは記述報告、渋滞と逃げ遅れ絶対数は従・限界へ分離した。**

| 指標 | 定義 | 優先度 |
|------|------|--------|
| **Type3/4避難完了率** | 交通弱者（車非保有・高齢＝Type3/4）が設定時間内に浸水域を脱出できた割合 | 正式判定 |
| **Type3/4避難完了時間ECDF** | 到着したType3/4の完了時間分布。完了率と対で記述する | 記述報告 |
| **公平性 worst-off 記述統計** | 到着車両の完了時間について最遅10%の平均と分位点をrun別に記述する | 記述報告 |
| **渋滞発生規模** | 主要避難路の平均速度・渋滞長・渋滞継続時間 | 従・限界 |
| **逃げ遅れ絶対数** | 設定時間内に浸水エリアを脱出できなかった人数 | 従・限界 |
| **避難完了時間（全体）** | 到着した車両の完了時間分布 | 参考 |
| **バスの乗車率・輸送人数** | バス1台が何人を輸送できたか | ★☆☆ 参考指標 |

### 指標階層の適用規則

- **正式判定：** Type3/4避難完了率だけをA/B定量判定に用いる。
- **記述報告：** 完了時間ECDFは完了率と対で示し、worst-off記述統計は診断としてrun別に示す。
- **従・限界：** 渋滞と逃げ遅れ絶対数はモデル条件の影響を受ける補助情報として扱う。
