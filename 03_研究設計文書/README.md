# 03_研究設計文書

研究の設計・実装仕様・論文用文書をまとめたフォルダ。

---

## 読む順番

```
実装仕様書.md                 ← コード変更時はここ（全仕様の基準）
    ↓
データフロー図.md              ← 処理順・中間ファイルを確認するとき
    ↓
目的別ファイル（下記）
```
