> 作成日：2026/04/29
> 前提：Phase 1（静的分析）+ Phase 2（SUMO動的シミュレーション）+ Phase 3（バス追加・A/B比較・感度分析）まで完成した場合の構成
> 論文タイトル案：「河川氾濫時における自家用車・救出走行とデマンド交通車両転用型避難シャトルの比較シミュレーション ─ 2015年鬼怒川氾濫を事例として ─」

> **⚠️ 研究方針の反映メモ（2026-07-03・執筆時に反映）**
> - **T-D-M3（41市区町村の位置づけ）**：41市区町村の全域拡張は RQ 本体（常総市・2015鬼怒川の実事例）とは論理的に分離し、**「手法の移転可能性のデモ」として独立章・節（例：第5章）**に置く。各市シナリオは「A31a想定最大規模の仮想シナリオであり鬼怒川の実浸水時系列とは無関係」と当該章冒頭で明記。RQ接続文は「本手法が入力データ（ハザードマップ・人口メッシュ・道路NW）さえあれば他自治体へ適用可能であることを示す」。
> - **T-D-S2（デマンド呼称の精密化）**：本研究のバスは固定ルートのピストン輸送であり需要応答配車ではない。タイトル・序論では「デマンド交通**車両を転用した**避難シャトル輸送」等へ精密化するか、序論・限界節に「運行形態は固定ルートのピストン輸送に単純化した（需要応答配車は将来課題）」と明示する。
> - 併せて、時間軸は「2015年の再現」ではなく「加速浸水ストレスシナリオ」、逃げ遅れは絶対数でなく A/B 相対比較（人単位・Type別）で記述する（[[時間軸_方針判断_fable5]]）。

> **⚠️ 2026-07-12 主結論確定に伴う構成の含意（[[段4_主指標ヌル確定_方針判断_fable5]] 決定105〜111）：** 本テンプレートは「シナリオBで逃げ遅れが減る・有効台数を提言する」という**効果検出を前提**にしていたが、段3Rシード変動レプリケーションの結果、**主指標（Type3/4完了率）のA/B差はヌル（本モデルの分解能では検出されない）**で確定した。章立ての含意は次のとおり——
> 1. **結果・考察章の主軸は「A/B差はヌル」**（決定106文言・**点推定+1.23%pt/帯[−3.09,+22.97]%pt**〔raw・実データ算出＝決定126〜144・`e2004d7`回帰を撤回〕・方向主張は全面禁止）。
> 2. **「デマンド交通の有効台数・ルートの提言」は成立しない**ため、政策提言は「本モデル・本規模では方向性のある差は検出されなかった」＋**方法論的貢献**へ転換する。
> 3. **主役の副次的発見は強い初期条件感応性（決定107）**——単一runの避難シミュレーション結果は初期条件に脆弱、という方法論的知見を独立節（例：考察の中心）に置く。「二峰性の実証」「2峰図」とは表現しない。
> 4. **定量A/B主張は④Type3/4完了率のヌル一本**（①完了時間はECDF重ね描き・②需要充足率はB側絶対値・③Type別は診断のみ・決定108）。
> 5. **感度分析（第5章相当）はバス10台×5runへ縮小**（決定109・ヌルの頑健性の傍証）。取消済み3台条件を含む旧複数台数比較は不成立。
> 6. **限界節**：強い初期条件感応性と複数regimeの可能性／乗車中孤立16人／完了率分母の推計差23.5人／Phase 2単一runの初期条件脆弱性（相互参照）。

| 節 | 内容 |
|----|------|
| 1.1 研究背景 | 2015年鬼怒川氾濫の概要と被害実態。自家用車避難の渋滞・孤立問題。高齢者・車非保有者など交通弱者の避難困難。デマンド交通バスの防災活用可能性。 |
| 1.2 研究目的 | 自家用車＋救出走行のScenario Aと、デマンド交通車両を固定経路避難シャトルへ転用するScenario Bを比較し、Type3/4完了率の方向差を本モデルで検出できるか評価する。 |

| 1.4 研究の新規性 | 公開・公的データ、浸水道路閉鎖、SUMO/TraCI、救出走行、固定経路避難シャトル、複数seed評価を同一基盤へ統合した点。 |

### 第3章 研究手法

| 節 | 内容 |
|----|------|
| 3.1 使用データ | 国土地理院KML、A31a GML、OSM、P20 Shapefile、e-Stat 250mメッシュ人口、車両保有台数統計。各データの出典・ライセンスを明示。 |
| 3.2 道路封鎖条件の設定 | 浸水深0.5m以上（waterDepth≥2）で封鎖と判定する根拠。 |

| 3.6 シナリオ比較・感度分析の方法 | A3/B5の反復評価。正式判定＝Type3/4完了率、補助＝完了時間ECDF・需要充足率・Type別診断。バス10台感度。 |
| 3.7 モデル記述・実装環境 | `共通設計/ODD準拠モデル記述.md`を要約し、Python、osmnx、geopandas、networkx、pyogrio、folium、SUMO、TraCIを記載する。 |

### 第5章 考察

| 節 | 内容 |
|----|------|
| 5.1 浸水進行と避難困難性の関係 | 静的分析の結果から、逃げ遅れが急増する転換点と主要幹線道路の封鎖タイミングの考察。 |
| 5.2 渋滞が逃げ遅れに与える影響 | シナリオAの結果から、渋滞考慮の有無による逃げ遅れ数の差。 |
| 5.3 シナリオA/B差が検出されない理由 | 点推定よりrun間変動が大きく、現在の分解能では方向を識別できないことを考察。 |
| 5.4 初期条件感応性 | run別完了率とロックregime候補を示し、単一run評価の脆弱性を考察。二峰性の統計的実証は主張しない。 |
| 5.5 バス台数感度と輸送限界 | 10台でも符号非一貫であること、需要充足率、raw二重計上バイアスを整理。 |
| 5.6 分析の限界と留意点 | 避難タイミングの均一仮定、固定経路運行、実際の予約DRT・避難行動・運行制約との乖離、Phase間の単位差を記載する。 |
| 5.7 今後の展望 | ①他洪水リスク地域への手法転用。②リアルタイム化による避難支援システム化。③より精緻な需要応答バスモデルへの発展。 |
