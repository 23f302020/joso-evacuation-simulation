# 論文構成 — Phase 1 + Phase 2 + Phase 3 完成した場合（完全版）

> 作成日：2026/04/29
> 前提：Phase 1（静的分析）+ Phase 2（SUMO動的シミュレーション）+ Phase 3（バス追加・A/B比較・感度分析）まで完成した場合の構成
> 論文タイトル案：「河川氾濫時における自家用車避難とデマンド交通バス活用の比較シミュレーション ─ 2015年鬼怒川氾濫を事例として ─」

> **⚠️ 研究方針の反映メモ（2026-07-03・執筆時に反映）**
> - **T-D-M3（41市区町村の位置づけ）**：41市区町村の全域拡張は RQ 本体（常総市・2015鬼怒川の実事例）とは論理的に分離し、**「手法の移転可能性のデモ」として独立章・節（例：第5章）**に置く。各市シナリオは「A31a想定最大規模の仮想シナリオであり鬼怒川の実浸水時系列とは無関係」と当該章冒頭で明記。RQ接続文は「本手法が入力データ（ハザードマップ・人口メッシュ・道路NW）さえあれば他自治体へ適用可能であることを示す」。
> - **T-D-S2（デマンド呼称の精密化）**：本研究のバスは固定ルートのピストン輸送であり需要応答配車ではない。タイトル・序論では「デマンド交通**車両を転用した**避難シャトル輸送」等へ精密化するか、序論・限界節に「運行形態は固定ルートのピストン輸送に単純化した（需要応答配車は将来課題）」と明示する。
> - 併せて、時間軸は「2015年の再現」ではなく「加速浸水ストレスシナリオ」、逃げ遅れは絶対数でなく A/B 相対比較（人単位・Type別）で記述する（[[時間軸_方針判断_fable5]]）。

> **⚠️ 2026-07-12 主結論確定に伴う構成の含意（[[段4_主指標ヌル確定_方針判断_fable5]] 決定105〜111）：** 本テンプレートは「シナリオBで逃げ遅れが減る・有効台数を提言する」という**効果検出を前提**にしていたが、段3Rシード変動レプリケーションの結果、**主指標（Type3/4完了率）のA/B差はヌル（本モデルの分解能では検出されない）**で確定した。章立ての含意は次のとおり——
> 1. **結果・考察章の主軸は「A/B差はヌル」**（決定106文言・**点推定+1.23%pt/帯[−3.09,+22.97]%pt**〔raw・実データ算出＝決定126〜144・`e2004d7`回帰を撤回〕・方向主張は全面禁止）。
> 2. **「デマンド交通の有効台数・ルートの提言」は成立しない**ため、政策提言は「本モデル・本規模では方向性のある差は検出されなかった」＋**方法論的貢献**へ転換する。
> 3. **主役の発見は regime bimodality（初期条件感応性・決定107）**——単一runの避難シミュレーション結果は初期条件に脆弱、という方法論的知見を独立節（例：考察の中心）に置く。可視化は「帯がゼロをまたぐ図」「regimeの2峰図」が主役。
> 4. **定量A/B主張は④Type3/4完了率のヌル一本**（①完了時間はECDF重ね描き・②需要充足率はB側絶対値・③Type別は診断のみ・決定108）。
> 5. **感度分析（第5章相当）はバス10台×5runへ縮小**（決定109・ヌルの頑健性の傍証）。「3・5・10台による逃げ遅れ変化」という旧記述は不成立。
> 6. **限界節**：regime bimodality／乗車中孤立16人／完了率分母の推計差23.5人／Phase 2単一runの初期条件脆弱性（相互参照）。

## 論文構成

### 第1章 序論

| 節 | 内容 |
|----|------|
| 1.1 研究背景 | 2015年鬼怒川氾濫の概要と被害実態。自家用車避難の渋滞・孤立問題。高齢者・車非保有者など交通弱者の避難困難。デマンド交通バスの防災活用可能性。 |
| 1.2 研究目的 | 自家用車のみの避難（シナリオA）とデマンドバスを加えた避難（シナリオB）をシミュレーションで比較し、公共交通の避難支援効果を定量的に評価する。 |
| 1.3 研究の対象・範囲 | 空間：茨城県常総市。時間：破堤から2015/09/16 10:20までの8時点。手法：静的分析（Phase 1）・動的シミュレーション（Phase 2）・シナリオ比較（Phase 3）の3段構成。 |
| 1.4 研究の新規性 | 実際の浸水時系列データとオープンデータのみを使用。デマンド交通バスを洪水避難シミュレーションに組み込んだ事例としての位置づけ。 |
| 1.5 論文構成 | 各章の概要を1〜2文で説明。 |

---

### 第2章 先行研究・関連研究

| 節 | 内容 |
|----|------|
| 2.1 洪水時の避難行動研究 | 自家用車避難の実態と問題点。逃げ遅れ発生メカニズムの先行知見。 |
| 2.2 GISを用いた道路閉鎖・避難経路分析 | 浸水深と道路通行可否の関係（0.5m閾値の根拠）。ネットワーク分析による避難困難性評価の事例。 |
| 2.3 交通シミュレーションを用いた避難研究 | SUMO等を用いた避難研究事例。渋滞・車両競合の考慮。 |
| 2.4 公共交通を活用した避難支援研究 | デマンド交通・福祉バス等を用いた避難困難者支援の先行研究。 |
| 2.5 オープンデータを活用した防災分析 | OSM・国土数値情報・e-Statを組み合わせた分析事例。 |
| 2.6 本研究の位置づけ | 上記研究群との差分と新規性。「浸水時系列+SUMOシミュレーション+デマンドバス」の統合の新規性。 |

---

### 第3章 研究手法

| 節 | 内容 |
|----|------|
| 3.1 使用データ | 国土地理院KML、A31a GML、OSM、P20 Shapefile、e-Stat 250mメッシュ人口、車両保有台数統計。各データの出典・ライセンスを明示。 |
| 3.2 道路封鎖条件の設定 | 浸水深0.5m以上（waterDepth≥2）で封鎖と判定する根拠。 |
| 3.3 Phase 1：静的避難困難性推計 | 分析フロー・逃げ遅れ定義（簡潔に記述）。 |
| 3.4 Phase 2：SUMO動的シミュレーション（シナリオA） | 道路NW変換・車両エージェント投入・TraCI動的閉鎖の手順。 |
| 3.5 Phase 3：シナリオB デマンドバス設定 | バス固定ルートの定義（16避難所付近にバス停設置）。高齢者エージェント（車非保有）のバス乗降設定。バス台数パラメータ（3・5・10台）の設定方法。 |
| 3.6 シナリオ比較・感度分析の方法 | シナリオA/B の比較指標（逃げ遅れ数・避難完了時間・渋滞指標）。台数感度分析の実施方法。 |
| 3.7 実装環境 | Python 3.13、osmnx、geopandas、networkx、pyogrio、folium、SUMO、TraCI。 |

---

### 第4章 分析結果

| 節 | 内容 |
|----|------|
| 4.1 常総市道路ネットワークの概要 | ノード数・エッジ数、主要幹線道路の分布。 |
| 4.2 浸水範囲の時系列変化 | 8時点の浸水ポリゴン面積の推移（表・グラフ）。 |
| 4.3 時点別道路封鎖状況 | 各時点の封鎖エッジ数・封鎖率の推移表と地図。 |
| 4.4 静的分析の結果（Phase 1） | 時点別逃げ遅れ人数の推移（要約）。 |
| 4.5 シナリオA：自家用車のみ（Phase 2） | 渋滞の発生・解消。逃げ遅れ車両数の推移。 |
| 4.6 シナリオB：デマンドバス追加（Phase 3） | バス5台時の避難完了人数・逃げ遅れ数。高齢者エージェントのバス利用状況。 |
| 4.7 シナリオA/B 比較 | 逃げ遅れ数・避難完了時間・渋滞指標の比較表・グラフ。バス追加による改善効果の定量化。 |
| 4.8 台数感度分析（バス3・5・10台） | 台数別の逃げ遅れ数変化グラフ。改善効果の飽和点の有無。 |

---

### 第5章 考察

| 節 | 内容 |
|----|------|
| 5.1 浸水進行と避難困難性の関係 | 静的分析の結果から、逃げ遅れが急増する転換点と主要幹線道路の封鎖タイミングの考察。 |
| 5.2 渋滞が逃げ遅れに与える影響 | シナリオAの結果から、渋滞考慮の有無による逃げ遅れ数の差。 |
| 5.3 デマンドバスの避難支援効果 | シナリオA/B比較から、バス追加が逃げ遅れ削減に寄与する条件と限界。特に高齢者・車非保有者への効果。 |
| 5.4 最適なバス台数の検討 | 感度分析の結果から、費用対効果の観点での適切な台数の提案。 |
| 5.5 避難困難地域への政策提言 | 逃げ遅れが集中した地区に対する具体的な対策案（バス停位置・優先ルート等）。 |
| 5.6 分析の限界と留意点 | 避難タイミングの均一仮定。バスの需要応答ロジックを単純化していること。実際の避難行動の複雑さとの乖離。 |
| 5.7 今後の展望 | ①他洪水リスク地域への手法転用。②リアルタイム化による避難支援システム化。③より精緻な需要応答バスモデルへの発展。 |

---

### 第6章 結論

| 節 | 内容 |
|----|------|
| 6.1 まとめ | 3つのフェーズの主要な知見を段階的に記述。「バス○台追加で逃げ遅れが○%減少した」という形で具体的数値を含める。 |
| 6.2 政策的含意 | 分析結果が示す実務的な示唆（行政・交通事業者向け）。 |
| 6.3 今後の課題 | 5.7の展望を課題として再整理し、優先順位付きで記述。 |
