# 研究集計と解釈の監査

③knowledge-work-pluginsの[validate-data原文](references/upstream/data/skills/validate-data/source.md)を研究向けに適用した別入口。変更内容は[MODIFICATIONS.md](MODIFICATIONS.md)、権限と併用は[運用正本](../../../05_タスク管理/スキル・エージェント運用.md)を参照する。上流の共有可否評価を正式な実験採用判定にしない。

1. 対象系列・登録済み分析・採用run一覧、指標式、母集団、観測窓、使用実装/入力/成果物SHAを特定する。旧系列・失敗run・人工fixtureが実比較へ混在していないか確認する。
2. 人物/request/event/道路行など各表の粒度とjoin keyを確認する。結合前後の件数とID対応、重複、欠損、除外を全件で照合し、join増殖や未観測の0埋めを検出する。
3. Type別の固定分母、施設受入/退出/未完了、served/admitted、取消/代替、右打切りを区別する。未乗車者を待ち時間平均から無言で除外せず、平均の平均や対応seedを失う集約を避ける。
4. 予定時刻・実呼出し・観測時刻、実時間/モデル時間、単位と百分率/percentage pointを確認する。比較する条件・seed・窓・分母が登録契約と一致するか照合する。
5. 主要な集計を一次成果物から独立に再計算し、会計・小計・割合を突き合わせる。個別行の追跡は全件検査の補助とし、同じ生成関数の再呼出しだけを独立検証としない。
6. 図表の軸・単位・分母・期間・出典、点推定と不確実性、仮定と実測の区別を確認する。対象系列の全登録セルが揃う前の方式方向解釈、Phase 3の凍結ヌル結論の書換え、事後除外や未登録検定を行わない。

成果物は対象/根拠SHA、再計算方法、整合/不一致/未確認の指摘、影響する指標・主張、必要な限定事項。未取得の副指標や不足資料を明記し、監査完了から実験READY・record・公開の許可を推定しない。既存の同一SHAに対する独立監査結果は再利用し、追加分析案は実施と分離する。
