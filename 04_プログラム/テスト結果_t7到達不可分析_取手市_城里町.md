## 1. 現象の概要

市別シナリオ HTML（`output/scenario_cities/{code}/`）において、  
**取手市（08217）と城里町（08310）** で時刻 **t7 を選択すると到達不可になる地点が存在する**。

- t0〜t6 では閉鎖道路を回避したルートが成立する
- t7 でのみ一部地点から全避難所への経路が遮断される

## 3. t7 で到達不可が生じる理由

### 3-1. t7 = A31a 最終浸水想定の 100% 適用

`city_scenario.py` の `build_scenario_flood_dict` は、A31a 浸水想定ポリゴンを  
**破堤点代替（A31a 重心）からの距離の分位点**で段階的に分配する。

```
SCENARIO_PROGRESS = [5.2, 17.2, 29.2, 41.2, 53.2, 65.2, 77.2, 141.5] / 141.5
                   → [3.7%, 12.2%, 20.6%, 29.1%, 37.6%, 46.1%, 54.6%, 100.0%]
```

t7 は `progress = 1.0`（100%）であるため、**すべての A31a ポリゴンが浸水エリア**として適用される。  
これはハザードマップが想定する**最大浸水規模のシナリオ**に相当する。

### 3-2. t6→t7 の閉鎖本数の急増（最大ジャンプ幅）

| 市区町村 | t6 閉鎖本数 | t7 閉鎖本数 | 増加本数 | 増加率 |
|---------|-----------|-----------|---------|--------|
| 取手市 | 1,392（9.2%） | 2,328（15.3%） | **+936** | **+67%** |
| 城里町 | 536（11.9%） | 1,030（22.8%） | **+494** | **+92%** |

t7 で残りの **45.4%（54.6%→100%）** の A31a ポリゴンが一気に追加される。  
これが t6 まで確保できていた迂回ルートを遮断する。

### 3-3. 城里町で閉鎖率が高い地理的理由

城里町は那珂川・久慈川・水戸里川が谷を刻む中山間地であり、  
道路のほとんどが河川沿いを通る。

- 道路総数が少ない（4,511 本）のに対し、A31a ポリゴンが多い（5,634 件）
- t7 の閉鎖率 **22.8%** は、36 市区町村中でも最上位レベル
- 谷沿いの幹線道路が浸水すると、山間集落が孤立しやすいネットワーク構造

### 3-4. 取手市で閉鎖率が高い地理的理由

取手市は利根川・小貝川の合流点付近に位置し、A31a データは 08_20（都道府県管理）のみ。

- 利根川本川分はハザードマップで別管理のため 08_10 非対象
- 都道府県管理の中小河川（小貝川等支流）の浸水想定が市内道路網に広く分布
- 道路総数は多い（15,191 本）が、浸水ポリゴンが道路沿いに集中するため  
  閉鎖率（15.3%）は浸水想定面積比（1.3%）の約 12 倍に達する

## 4. 「不具合ではない」根拠

### 4-1. アプリの動作仕様（app.js の実装確認）

```javascript
// app.js L130, L275
const closures = data.closures[activeTime] || [];   // 現時点の瞬間閉鎖リスト
const closedSet = new Set(data.closures[activeTime] || []);
const route = shortestRoute(startNode, closedSet);  // 閉鎖エッジを除いた Dijkstra
```

アプリは選択した時刻の **瞬間閉鎖リストのみ** を適用する設計であり、  
t7 では仕様通り「t7 時点の閉鎖エッジを除いた道路網でルート探索」を行っている。

### 4-2. シナリオ設計の意図との整合性

| 観点 | 説明 |
|------|------|
| t7 の意味 | 実際の避難タイムライン終端ではなく、**A31a 最大浸水想定（最悪シナリオ）** の適用時点 |
| 到達不可の解釈 | 「想定最大浸水が実現した場合に孤立する地区が存在する」という**研究知見** |
| 常総市との対比 | 常総市でも実データ版で 40 出発地中 17 件が到達不可（t0 から固定）。市別版も同様の孤立現象 |
| 閉鎖条件の根拠 | A31a waterDepth ≥ 2（≥ 0.5m）の国土数値情報。国交省基準に準拠 |

### 4-3. 他市区町村との比較

36 市区町村のうち t7 閉鎖率が高い市町村ほど到達不可が生じやすい。  
t7 に到達不可が出ること自体が「閉鎖率が相対的に高い地区」を識別する指標となる。

## 5. 卒論・説明時の要約文（例）

> 取手市・城里町において時刻 t7（2015-09-16 相当、シナリオ最終段階）で到達不可が生じる。  
> これは t7 が A31a 浸水想定ポリゴンの **100%** を閉鎖条件として適用するためであり、  
> 取手市で全道路の 15.3%（2,328 本）、城里町で 22.8%（1,030 本）が封鎖される。  
> 特に城里町は那珂川・久慈川沿いの谷地形により道路密度が低く、  
> 幹線代替路を持たない集落が浸水ゾーンで囲まれる。  
> これはシステムの不具合ではなく、A31a 最大浸水シナリオにおける  
> **地区孤立リスクを示す研究上の有効な発見**である。
