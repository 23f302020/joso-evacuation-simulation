## 5. ファイルI/Oドライバー（pyogrio 経由）

pyogrio は GDAL を内部バンドルしており、以下のドライバーが利用可能であることを確認済み。

| ドライバー名 | 対象形式 | 読み書き |
|------------|---------|--------|
| KML | KML（国土地理院 浸水時系列） | rw |
| LIBKML | KML（高機能版） | rw |
| GML | GML（国土数値情報 A31a） | rw |
| ESRI Shapefile | .shp/.dbf/.shx（避難施設P20） | rw |
| GPKG | GeoPackage（道路エッジ保存用） | rw |

**備考：** `fiona` は Python 3.13 + Windows 環境で GDAL バイナリの互換性問題があったため不採用。`pyogrio` が同等の機能をすべてカバーしている。
