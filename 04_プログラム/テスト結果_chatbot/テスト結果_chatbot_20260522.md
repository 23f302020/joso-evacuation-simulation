## 2026年5月22日 追加確認

ユーザー側で `requirements.txt` を手動アップロード後，Space上の公開ファイルを再確認した．`requirements.txt` はRAG用に更新されていたが，`app.py` と `README.md` はGradioテンプレートのままだった．そのため，Spaceは `BUILD_ERROR` 状態であり，RAGチャットとしてはまだ起動していない．

次に必要なのは，SpaceのFilesタブで `app.py` と `README.md` もRAG版に置き換えることである．

## 2026年5月22日 READMEアップロード時エラー対応

ユーザーが `README.md` を上書きしようとした際，Hugging Face側で次のエラーが発生した．

```text
YAMLメタデータエラー: "colorTo"は[red, yellow, green, blue, indigo, purple, pink, gray]のいずれかである必要があります。
```

原因は，RAG版 `README.md` のYAML front matterで `colorTo: cyan` を指定していたことである．Hugging Face Spaceで使用できる色に `cyan` は含まれていないため，`colorTo: indigo` へ修正した．

## 2026年5月22日 Space起動後の実行時エラー対応

ユーザーが `app.py`，`README.md`，`requirements.txt` を更新後，Space上の3ファイルはRAG版に反映されていることを確認した．ビルドは進行し，runtimeは `BUILDING` から `APP_STARTING` へ進んだが，最終的に `RUNTIME_ERROR` となった．

Hugging Face APIで確認したエラーは以下である．

```text
ModuleNotFoundError: No module named 'audioop'
ModuleNotFoundError: No module named 'pyaudioop'
```

原因は，Hugging Face SpaceのPython 3.13環境で標準ライブラリ `audioop` が削除されており，Gradioの依存ライブラリ `pydub` が代替の `pyaudioop` も見つけられなかったことである．

対応として，`04_プログラム/chatbot_hf_space/requirements.txt` に以下を追加した．

```text
pyaudioop>=0.2.0
```

次に，修正後の `requirements.txt` をSpaceへ再アップロードする必要がある．
