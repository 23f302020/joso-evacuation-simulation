| 集計 | 値 |
|---|---|
| type3 完了率（集計） | 984/1,036 = 0.949807 |
| type4 完了率（集計） | 357/369 = 0.967480 |
| 集計差 | **+0.017673** |
| type3・type4 が**両方存在する** origin | 202 |
| うち両型の完了率が**完全一致**する origin | **173（85.6%）** |

| type4 の完了率を type3 のウェイトで再加重 | 0.973039（実測 type4 0.967480） |
| type4 のみ存在する origin | 6（車両6台） |
| type3 のみ存在する origin | **144（車両220台）** |

→ **同一 origin 内では両型の完了率が85.6%で完全一致する**（同一の救出走行車両を人口比で按分しているため）。type3 の完了率を type4 のウェイトで再加重すると 0.949807 → 0.964597 となり、集計差 0.017673 のうち **0.014790（約84%）が構成効果（origin ウェイトの差）で説明される**。残差は「type3 のみが存在する144 origin（220台）」が type3 を押し下げることによる。

**→ 決定46の「型内差は allocation shadow であって demographic 現象ではない」は、定量的に裏づけられた。**

なお `pearson_assigned_type4_share_vs_type34_completion_rate = 0.049207`（ほぼ無相関）は**非加重の相関係数**であり、構成効果の検出力が低い。上記の再加重分解が決定的な統計量である（事実の記載であり、指標の採否は判断しない）。
