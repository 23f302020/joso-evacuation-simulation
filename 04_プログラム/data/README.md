# 入力データの取得方法

このディレクトリには、国土数値情報、国土地理院、e-Stat 等から取得した研究用入力データを配置する。
生データは再ダウンロード可能でサイズが大きいため、Git では追跡しない。追跡対象はこの README と `manifest.csv` のみとする。

## 取得手順

```powershell
cd 04_プログラム
python scripts/download_data.py
```

`manifest.csv` の `download_method` が `direct_zip` のデータは自動取得と展開を行う。
`manual` のデータは配布サイトのUIやAPI条件に依存するため、`source_url` から手動で取得し、`local_path` に記載した場所へ配置する。

## 注意

- 配布元の利用規約を確認したうえで使用する。
- 取得済みZIP、展開済みGML/XML/Shapefile、PDF、Excel等はGit管理しない。
- フォルダ名の文字化けを避けるため、新規取得時は `manifest.csv` の `local_path` に合わせた英数字中心のパスへ配置する。
