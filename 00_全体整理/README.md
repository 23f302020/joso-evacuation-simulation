## Phase 2 へ進む前の状態

Phase 1 は、茨城県内41市区町村を対象とするシナリオ型避難ルート探索の成果物として固定する。対象外は鹿嶋市・神栖市・東海村の3市町村である。五霞町は A31a 08_20 境界±500mバッファ対応により対象へ昇格済み。

Phase 2 は、まず常総市実データ版を対象に、SUMOネットワーク変換、車両投入、TraCI動的道路閉鎖の順で進める。
