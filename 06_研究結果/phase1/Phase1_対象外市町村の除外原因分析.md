# Phase 1 対象外市町村の除外原因分析

**作成日：** 2026/05/09  
**対象：** 鹿嶋市・神栖市・東海村・五霞町（茨城県44市区町村中4市村）  
**目的：** 各市町村がシミュレーション対象外となった理由をデータ・地形・制度の観点から分類し、研究の限界と今後の課題を整理する

---

## 1. 除外理由の類型化

本研究の Phase 1 では茨城県内44市区町村のうち40市区町村をシミュレーション対象とし、4市町村を対象外とした。除外に至ったプロセスは **3段階**で構成されており、どの段階で除外されるかによって除外理由が異なる。

```
[Step 1] A31a GML の取得
   ↓ A31a-24_08_10（国管理河川・鬼怒川系）
   ↓ A31a-24_08_20（都道府県管理河川）
   ↓
[Step 2] N03 行政境界との空間結合
   市区町村境界内にポリゴンが intersects するか？
   ↓ YES → 対象候補
   ↓ NO  → 対象外
   ↓
[Step 3] waterDepth ≥ 2（≥0.5m）でフィルタ
   → 有効ポリゴン0件 → 対象外確定
```

4市町村はすべて **Step 2〜3 の「境界内0件」** で除外されているが、**その根本原因は3パターンに分類される。**

| 市区町村 | コード | 除外ステップ | 根本原因パターン | 研究制約への影響 |
|---------|--------|:----------:|--------------|--------------|
| 東海村 | 08341 | Step 2-3 | **地形的理由**（台地地形により洪水域が市域に到達しない） | 低（対象外が地理的に適切） |
| 鹿嶋市 | 08222 | Step 2-3 | **地理的理由**（汽水域・沿岸部、河川洪水想定区域なし） | 低（対象外が地理的に適切） |
| 神栖市 | 08232 | Step 2-3 | **地理的理由 + データ制約**（沿岸 + 利根川系データ欠如） | 中 |
| 五霞町 | 08542 | Step 2-3 | **データ制約**（利根川系A31aが茨城県版に未収録） | **高**（実際は高リスク地域） |

## 2. 空間診断結果（定量データ）

A31a 全ポリゴン（08_10: 40,811件 / 08_20: 64,737件）と各市区町村境界の空間関係を2段階で確認した。

| 市区町村 | 08_10 境界内 | 08_20 境界内 | 08_10 最近傍距離 | 08_20 最近傍距離 |
|---------|:-----------:|:-----------:|:--------------:|:--------------:|
| 東海村 | 0件 | 0件 | **0.17 km** | 4.58 km |
| 鹿嶋市 | 0件 | 0件 | 2.41 km | 10.44 km |
| 神栖市 | 0件 | 0件 | 1.71 km | 9.89 km |
| 五霞町 | 0件 | 0件 | **∞（15km圏0件）** | **0.24 km** |

> 東海村は 08_10 ポリゴンが 0.17km という至近距離に存在するが市境界内に入らない。  
> 五霞町は 08_10 が 15km 圏に0件（利根川系データが茨城県08に完全欠落）、08_20 は 0.24km に存在するが境界内に入らない。

### バッファ距離別ヒット数（東海村 · 08_10）

```
  0 m  →   0 件
100 m  →   0 件
200 m  →   5 件
500 m  →  18 件
```

170m の差異は「地形境界とポリゴン境界の一致」を示しており、データの欠落ではない。

## 3. 各市町村の詳細分析

### 3.1 東海村（コード: 08341）

**除外判定：地形的理由による対象外（正当）**

| 項目 | 内容 |
|------|------|
| 人口（2015） | 38,360人 |
| 高齢化率 | 18.1%（茨城県最低水準） |
| 面積 | 38.0km² |
| 地形的特徴 | 那珂川・久慈川に挟まれた海岸段丘台地 |
| 洪水対応避難所 | 19件（GSI 2号 CSV） |
| 乗用車（R8・軽除く） | 約16,674台 |

**除外の地理的根拠：**

東海村は那珂川（南側）と久慈川（北側）に挟まれているが、那珂川の浸水想定区域（A31a）は南側のひたちなか市方向に広がり、村境界に到達しない。久慈川の浸水想定は15km圏に6,294件存在するが、台地地形が洪水流入を遮断している。

```
           ← 那珂川 →
ひたちなか市  ||||| 浸水域  ||||| 東海村（台地）
                                   ↑ 170m の境界差
```

**研究への含意：**  
東海村は洪水被害を受けにくい地形に位置しており、「対象外」は地理的に妥当な判断である。  
洪水避難シミュレーションの対象外とすることは研究の限界ではなく、**適切なスコープ設定**である。  
ただし、高潮・津波リスクは別途存在する（A31aの対象外）。

---

### 3.2 鹿嶋市（コード: 08222）

**除外判定：地理的理由による対象外（正当）**

| 項目 | 内容 |
|------|------|
| 人口（2015） | 67,544人 |
| 高齢化率 | 25.5% |
| 面積 | 106.0km² |
| 地形的特徴 | 鹿島灘沿岸・北浦（汽水湖）西岸 |
| 洪水対応避難所 | 77件（GSI 2号 CSV）|
| 乗用車（R8・軽除く） | 約29,797台 |

**除外の地理的根拠：**

鹿嶋市内を流れる北浦・鰐川・外浪逆浦等は湖沼・汽水域であり、A31aの対象となる「河川洪水浸水想定」は設定されていない。08_10 の最近傍ポリゴンは2.41km外側に存在し、流域が市域内に及んでいない。

**注目すべき点：**  
鹿嶋市は洪水対応避難所が **77件（40対象市区町村中で最多水準）** ある。これは、河川洪水想定はなくとも **高潮・津波・内水氾濫のリスクへの備え** として多数の避難所が指定されていることを示す。A31a対象外であることは「洪水リスクがない」ことを意味しない。

**研究への含意：**  
河川洪水シミュレーションの対象外として適切。ただし、今後の研究拡張として **沿岸洪水（高潮）シミュレーション** の対象候補となりうる。

---

### 3.3 神栖市（コード: 08232）

**除外判定：地理的理由 + データ制約（軽記載推奨）**

| 項目 | 内容 |
|------|------|
| 人口（2015） | 95,216人（44市区町村中4位） |
| 高齢化率 | 21.9%（比較的低い） |
| 面積 | 146.8km² |
| 地形的特徴 | 利根川河口部・鹿島灘沿岸・工業港湾都市 |
| 洪水対応避難所 | 68件 |
| 乗用車（R8・軽除く） | 約16,468台 |

**除外の根拠（2層構造）：**

① **地形的要因**：神栖市は利根川河口・太平洋沿岸の低平地に位置するが、国管理河川の浸水想定区域が市域内に設定されていない。市内を流れる河川は利根川支流・霞ヶ浦南部の小河川であり、A31a 08_10 の対象河川（那珂川・鬼怒川水系）は市境近傍に留まる。

② **データ制約**：利根川本川の浸水想定データ（国交省関東地方整備局管轄）が茨城県 A31a-08 セットに含まれていない（五霞町と同様の制約）。08_10 の最近傍1.71kmはこの小河川の浸水想定で、利根川本川のデータが実際にどこに存在するかは別途確認が必要。

**研究への含意：**  
神栖市（人口95,216人）を除外していることは規模の大きな除外だが、A31a データに基づく河川洪水シミュレーションでは現状のデータ構造上の必然的な結果である。論文では「利根川河口部の浸水想定データが本研究のデータセットに含まれていない」と軽く記述することを推奨する。

---

### 3.4 五霞町（コード: 08542）

**除外判定：データ制約による対象外（要記載・研究の重大な限界）**

| 項目 | 内容 |
|------|------|
| 人口（2015） | 8,890人（茨城県最小規模） |
| 高齢化率 | 33.5% |
| 面積 | 27.0km² |
| 地形的特徴 | 利根川・渡良瀬川合流部（茨城県最南西端）|
| 洪水対応避難所 | 11件 |
| 実際の洪水リスク | **極めて高い**（後述） |

**除外の技術的根拠：**

| 確認 | 結果 |
|------|------|
| 08_10（鬼怒川・那珂川系）15km圏 | 0件（利根川系データが茨城県08に完全欠落） |
| 08_20（都道府県管理河川）最近傍 | 0.24km（町の南側・茨城県外境を指す） |
| A31a-08 の収録河川 | 那珂川水系・涸沼川系・鬼怒川水系・茨城県内小河川 **のみ** |

**利根川データが茨城県A31aに含まれない構造的理由：**

国土数値情報 A31a は都道府県単位で提供される。利根川は関東7都県にまたがる **広域一級河川** であり、国土交通省関東地方整備局が独立した浸水想定区域図（県番号に依存しない独自体系）を管理している。茨城県番号「08」の A31a セットには那珂川・鬼怒川水系のみが収録され、利根川本川・渡良瀬川の浸水想定は現行データセットに含まれない。

**五霞町の実際の洪水リスク（データ外の事実）：**

五霞町は日本有数の洪水リスク地帯である。

```
渡良瀬遊水地（世界ラムサール条約湿地）
      ↓ 渡良瀬川
五霞町 ← 利根川本川 → 江戸川分岐点（関宿）
```

- **渡良瀬遊水地**（五霞町西側に隣接）：100年に1度の洪水調節機能を持つ遊水池
- **利根川計画高水位**：五霞町付近で T.P.+6m 超（常総市破堤点の鬼怒川水位より高い地点も存在）
- **歴史的洪水**：1947年カスリーン台風では茨城県南西部が広範囲に浸水
- **ハザードマップ（国土交通省）**：五霞町全域が浸水想定区域に含まれる（但し関東地整管轄データ）

**これはデータ制約による除外であり、地形的な安全性を意味しない。**

## 5. 除外理由の3分類まとめ

### Type 1：地形的理由（研究の限界ではない）

**対象：東海村・鹿嶋市**

- A31a が市域に到達しないことは地理的事実であり、データ不足ではない
- 河川洪水シミュレーションの対象外とすることは **研究スコープの適切な設定**
- 論文では「対象外市区町村」の説明として事実を記述するだけで十分
- 将来的に高潮・津波シミュレーションを行う場合は対象となりうる

### Type 2：地理的理由 + データ制約（軽記載推奨）

**対象：神栖市**

- 利根川河口部という地理的特性と利根川系データ欠如が重複
- 大規模市（人口95,216人）の除外であるため、論文の対象範囲説明で触れる
- 「利根川水系の浸水想定データは今回のA31aデータセットに含まれないため対象外」と1文で記述

### Type 3：データ制約（要記載・研究の重大な限界）

**対象：五霞町**

- **実際には高洪水リスク地域** であるにもかかわらず、データ制約で除外された
- 研究の結論に影響する可能性がある（河川洪水脆弱地域が分析から抜けている）
- 論文の「研究の限界」節で **明示的に言及** することが必要
- 今後の課題として「利根川水系A31aデータの取得と茨城県南西部への拡張」を提示

## 6. 卒論「研究の限界」節への転記案

### 対象外市区町村の記述（本文案）

> 本研究では茨城県内44市区町村のうち、A31a 浸水想定区域データが行政境界内に存在する40市区町村をシミュレーション対象とした。対象外の4市区町村については以下の理由による。
>
> 東海村は那珂川・久慈川に挟まれた海岸段丘台地上に位置し、いずれの河川の浸水想定区域も市域内に到達しないことが空間解析により確認された（最近傍距離 170m）。鹿嶋市は汽水域・鹿島灘沿岸に位置し、河川洪水浸水想定の対象となる国管理河川が市域内に存在しない。神栖市は利根川河口部に位置し、同様に A31a 対象河川の市域内設定がない。
>
> **五霞町については、利根川・渡良瀬川合流部に位置する高洪水リスク地域であるが、国土数値情報 A31a の茨城県版（08）には利根川水系のデータが収録されておらず、シミュレーション対象から除外せざるを得なかった。** これはデータ制約による除外であり、同町が洪水リスクから安全であることを意味しない。今後の課題として、国土交通省関東地方整備局が管理する利根川水系浸水想定データの取得と分析対象への統合が挙げられる。

### 今後の課題への接続

| 課題 | 対象市町村 | 必要データ | 難易度 |
|------|----------|----------|--------|
| 利根川系A31a取得・統合 | 五霞町・神栖市 | 国交省関東地整 浸水想定区域図（利根川本川） | 中 |
| 沿岸洪水（高潮）シミュレーション | 鹿嶋市・神栖市・東海村 | 高潮浸水想定区域図（別途整備） | 高 |
| 茨城県外への拡張 | 五霞町隣接（埼玉・千葉側） | N03境界・A31a他都県版 | 高 |
| 利根川本川氾濫の広域分析 | 茨城県南西部全体 | 広域氾濫モデル | 極高 |

## 7. Phase 2 以降への含意

対象外4市町村のうち、五霞町については Phase 2 以降で **補論的な分析対象** として扱う可能性がある。

| Phase | 五霞町への対応方針 |
|-------|----------------|
| Phase 2（SUMO） | 対象外のまま。利根川系データ取得が完了すれば補足として追加可能 |
| Phase 3（バス比較） | 小規模高齢化町村（人口8,890人・高齢率33.5%）としてケーススタディ候補 |

一方、東海村・鹿嶋市・神栖市は河川洪水シミュレーションの性質上、Phase 2〜3でも対象外が適切である。
