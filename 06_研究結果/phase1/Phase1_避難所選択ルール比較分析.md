# Phase 1 避難所選択ルール比較分析

**作成日：** 2026/05/09  
**対象：** 茨城県内41市区町村 / 常総市実データ版（2015年鬼怒川氾濫）  
**目的：** 最寄り避難所・浸水域外避難所・市外避難所含む の3ルールを比較し、避難計画上の示唆を導出する

---

## 1. 避難所選択ルールの定義

| ルール | 定義 | 特徴 |
|--------|------|------|
| **Rule A** 最寄り避難所 | 出発地から道路距離が最短の避難所に向かう | 移動距離最小化、現行シミュレーション設計 |
| **Rule B** 浸水域外避難所 | A31a 浸水想定区域外の避難所のみを対象とする | 安全到達先の確保、収容容量が減少 |
| **Rule C** 市外避難所含む | 隣接市区町村の洪水対応避難所を含めて選択肢を拡大 | 選択肢最大化、長距離移動・道路閉鎖リスクあり |

### 現行シミュレーション（Phase 1）の設計

`city_scenario.py` では **Rule A（最寄り避難所）** を採用している。  
JavaScript クライアントサイドの Dijkstra で「時刻 t における開通エッジのみ通過可能なグラフ」を構築し、すべての避難所への最短路を計算して距離最小のものを選択する。  
浸水区域と避難所の重複チェックは行っておらず、Rule B・C は Phase 1 では未実装である。

## 4. 3ルール比較：優位性と課題

### 4.1 Rule A：最寄り避難所

**優位性：**
- 移動距離を最小化し、避難時間を短縮できる
- 実装が単純（Dijkstra 1回で確定）
- 現行の Phase 1 シミュレーション設計

**課題：**
- 避難所が浸水区域内でも誘導してしまう
- 浸水進行が速い場合、到着時には避難所が使用不能になっているリスク
- 常総市では19件中9件（47%）が浸水域内に位置する可能性がある

**適用場面：** 洪水浸水深が浅く（0.5m未満）、避難所施設が機能維持できる場合

---

### 4.2 Rule B：浸水域外避難所

**優位性：**
- 目的地の安全性が保証される（到着時に避難所が使用可能）
- 浸水域が拡大しても避難先は維持される
- 避難計画の実効性が高い

**課題：**
- 常総市では収容容量が34%減少（13,848人 → 9,134人）
- 避難所が南部に集中するため、北部・東部居住者の移動距離が増大
- 浸水域判定に A31a の事前情報が必要（リアルタイム判定は困難）
- 閉鎖エッジが避難所へのルートを遮断する確率も高まる

**適用場面：** 大規模洪水で避難所も被災するシナリオ（今回の鬼怒川氾濫規模）

---

### 4.3 Rule C：市外避難所含む

**優位性：**
- 選択肢を大幅に拡大（常総市: 19件 → 198件）
- 収容容量の制約を実質的に解消
- 特定地点への集中を緩和

**課題：**
- 距離が長い（隣接市まで最低8〜20km）
- t1〜t2 以降は主要道路が閉鎖され、市外へのルートが遮断される可能性
- 市をまたいだ避難誘導には自治体間の事前協定が必要
- 車両不所持者・高齢者・要支援者が多い地区では自家用車避難が難しい

**適用場面：** 早期避難（t0 前の出発）と組み合わせた場合に最も効果的

## 6. 避難計画上の示唆

### 6.1 洪水規模に応じたルール選択

| 想定洪水規模 | 推奨ルール | 理由 |
|------------|---------|------|
| 軽微（浸水深0.5m未満） | Rule A | 避難所機能を維持。移動距離優先が合理的 |
| 中規模（浸水深0.5〜2m、一部施設被災） | Rule B | 浸水域内施設を除外し、機能する避難所に誘導 |
| 大規模（2015年鬼怒川氾濫レベル） | Rule B + Rule C（早期避難時） | 市内収容不足を隣接市の施設で補完 |

### 6.2 特に注意が必要な市区町村

**①避難所数が少なく閉鎖率が高い市区町村**  
（河内町・笠間市・美浦村・常総市・潮来市）  
→ Rule B を適用すると選択肢がさらに限られるため、**Rule C（市外避難所）との組み合わせが不可欠**

**②市内避難所が浸水域に偏在する市区町村**  
→ 常総市（北東部の施設が浸水リスク大）のように、**避難所の地理的分布に偏りがある場合、Rule A は実質的に機能しない**

**③市街地が氾濫源河川に近く早期閉鎖が始まる市区町村**  
→ t0 時点から閉鎖が始まる37/41市区町村では、**t0 前の出発が市外避難所（Rule C）の現実的な選択窓口**

### 6.3 Phase 2 以降への接続

| Phase | ルール拡張の方向性 |
|-------|-----------------|
| Phase 2（SUMO） | 複数車両エージェントが同時に避難する際の Rule A vs B vs C の混在交通を模擬 |
| Phase 3（バス比較） | Rule C（市外避難所）への長距離輸送で高齢者・要支援者カバーを補完 |

## 8. 論文転記メモ

### Phase 1 結論への接続

> **第○節 避難所選択条件の違いによる影響**  
> Phase 1 シミュレーションでは Rule A（最寄り避難所）を採用したが、  
> 常総市 P20 データの分析から、19件中9件（総収容の34%）が破堤点5km圏内の浸水推定域内に位置することが示された。  
> Rule B（浸水域外避難所）を適用した場合、市内収容可能人数は13,848人から9,134人に34%減少し（収容率15.0%）、  
> 常総市人口（61,000人）に対して市内避難所のみでの収容には根本的な限界がある。  
> これは Rule C（市外避難所含む）を組み込んだ自治体間連携の必要性を示唆している。
