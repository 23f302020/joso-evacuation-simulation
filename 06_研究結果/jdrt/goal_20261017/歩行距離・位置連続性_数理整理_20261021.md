# 歩行距離と位置連続性の数理整理（技術診断）



対象は新guard ng261021gの人工直線道路・2人物・4技術variantであり、4variantの人物を8人の独立標本として扱わない。避難支援効果、施設受入率、方式優劣は集計しない。全70正式セルが揃う前の方向解釈には使用しない。



native getterを $v_k$、道路上の縦位置を $s_k$、座標を $\mathbf{x}_k=(x_k,y_k)$、観測間隔を $\Delta t_k$ とすると、登録されたSUMO内部の歩行予算に対応する量は



$$L_{\parallel}=\sum_k v_k\Delta t_k.$$



同じlane上の縦位置から独立に照合する量は $\sum_k|s_k-s_{k-1}|$、観測座標の折線長は



$$P_{XY}=\sum_k\|\mathbf{x}_k-\mathbf{x}_{k-1}\|_2.$$



直線の縦移動と横移動では $\|\Delta\mathbf{x}\|_2=\sqrt{(\Delta s)^2+(\Delta\ell)^2}$ であるため、横移動があると $\|\Delta\mathbf{x}\|_2/\Delta t$ がnative縦速度getterを上回り得る。従って、$v_k\le v_{\max}$ は $\|\Delta\mathbf{x}\|_2/\Delta t\le v_{\max}$ の証明ではない。座標折線長を実際の曲線移動距離そのもの、native予算を現実の等方的な身体移動距離と同一視しない。



一方、制御による同一時刻の置換には $\mathbf{x}(t^+)=\mathbf{x}(t^-)$ と $s(t^+)=s(t^-)$ を要求する。これを通常の次stepの横移動と分け、前後receiptをexactに照合する。歩行予算/速度のしきい値を緩和せず、誤った次stepのXY上限代理を除き、微小な同一呼出しの位置ずれを検出する契約へ修正した。



例としてsame_direction/p3の観測窓は0.5〜50.5秒・100区間。native縦速度積分は44.987293 m、XY観測折線長は45.1192883 m、差は0.131995277 m。1stepの縦位置差と速度積分の最大絶対残差は1.819e-13 mだった。これは人工入力の検証値で、研究の期待効果・一般的な誤差率・3000m時の補正率には外挿しない。

全8ケース人物行、原本SHA、式、窓、結合粒度はaudit_history/native_internal_fixture_20261021/longitudinal_xy_math.json、再計算手順は同longitudinal_xy_math.py。一次ファイルから速度積分と位置差を別々に計算し、欠損/重複/路線変更/非有限値を検査した。元run/PAP/入力/主要指標/除外規則は変更していない。
