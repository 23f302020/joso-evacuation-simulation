# native patch 技術採用前レビュー（2026-10-21）

現行PAPを変えず、stage置換で同じ物理位置を保存する技術修正として整合する。最終的な開始許可は新READY原本・現行SHA/版/容量・未記録/孤児/入力の確認後に限る。本レビューはcoreを開始しない。

実nativeでは全45本・315一次ファイル、12/13群を観測した。残るfalse位置/時刻guardは有効な同一edge replaceStage経路ではAPI側が現位置/時計に同期するため、未観測である。ソースの条件付き到達性推論と、productionから抜き出した同じC++guard断片を人工のpolymorphic objectでコンパイルした16条件試験/2欠落guard反例を分離して併記する。欠落版は意図した位置/時刻条件で失敗し、元断片は16条件を通過。これを「実SUMOで13群のfalse分岐を観測した」と書き換えない。ABI/メモリ寿命/全有効APIの網羅証明ではない。

現在の全26統合・54改変反例・全14設定smokeは現行共通5で独立PASS。new preflightは進行中。正式0/70、研究core0。全70前の方式方向解釈なし。歩行距離のnative縦速度積分とXY折線長、仮定fleet/需要と実測を区別し、bridge/路面高/施設開設などの不足は最終報告へ残す。

担当は現親agentで、別agentの追認ではない。モデル設定はユーザーの役割方針に従うが実backendを独立確認していない。原本・source/binary/compiler/ログSHAと項目別の確認範囲・限界は同名JSONを参照。
