# Phase 2 比較基準固定

作成日：2026/05/19  
目的：Phase 3以降で比較基準として使うPhase 2の扱いを固定する。

---

## 1. 固定する比較基準

Phase 2は、SUMO/TraCIによる **シナリオA：自家用車のみの避難交通流** として固定する。  
Phase 3では、デマンド交通バスを追加したシナリオBを作成し、Phase 2のシナリオAと比較する。

---

## 2. 試行別の位置づけ

| 試行 | 位置づけ | 採用理由 |
|---|---|---|
| small | 動作確認・説明用 | 車両数が少なく、HTMLやアニメーションで処理内容を説明しやすい |
| 10pct | 主比較指標 | 全41市区町村で条件をそろえて完了しており、実行負荷と比較可能性のバランスがよい |
| full | 常総市詳細・参考指標 | 実車両数に近い条件で常総市の交通集中・未到着を確認できるが、全域横比較には重い |

---

## 3. 評価指標

| 指標 | Phase 2での意味 | Phase 3比較での使い方 |
|---|---|---|
| 到着台数・到着率 | 避難交通が目的地へ到達できた割合 | バス導入により到着率が改善するかを見る |
| 未到着台数 | 発車できない、または終了時点で未到着の車両 | 逃げ遅れ候補の減少を見る |
| 逃げ遅れ主指標 | 出発edge閉鎖、再経路失敗、長時間停止などの主判定 | Phase 3の改善効果の中心指標 |
| 平均旅行時間・最終到着時刻 | 避難完了までの交通流上の負荷 | バス導入が一般車の避難時間を悪化させないかを見る |
| 主要避難路の停止・低速 | 国道294号、県道357号などの路線別混雑 | バス追加による局所混雑の変化を見る |

---

## 4. 固定判断と理由

| 判断 | 採用内容 | 理由 |
|---|---|---|
| 比較基準 | Phase 2シナリオA | 研究テーマが自家用車避難とデマンド交通バス活用の比較であり、Phase 2は前者を交通流として実装した成果物であるため |
| 主試行 | 10pct | 全41市区町村で同条件の結果があり、卒論上の地域比較に使いやすいため |
| 常総市詳細 | fullも併用 | 2015年鬼怒川氾濫の主対象地域であり、実車両規模に近い条件の結果を考察に使えるため |
| 未到着の扱い | 逃げ遅れ候補 | fullの未到着14台は閉鎖済み出発edgeにより発車できない記録であり、道路閉鎖影響として解釈できるため |
| 出発時刻 | 一斉出発を基準 | 交通集中を確認しやすく、Phase 3で条件をそろえた比較がしやすいため |

---

## 5. Phase 3で変えてよいもの・変えないもの

### 変えないもの

- 対象道路ネットワーク
- t0〜t7の道路閉鎖タイムライン
- 避難所安全性判定
- Phase 2シナリオAの評価値
- small / 10pct / full の基本区分

### Phase 3で追加するもの

- バス車両
- バス利用対象者
- バス乗降・往復運行ルール
- シナリオA/B比較CSV
- バス輸送人数、バス未輸送人数、要支援者改善効果

---

## 6. 最終結論

Phase 2は、追加実装を増やす対象ではなく、Phase 3以降の比較基準として固定する。  
今後は、Phase 2の値を変更せず、Phase 3で追加するシナリオBの結果と比較する。
