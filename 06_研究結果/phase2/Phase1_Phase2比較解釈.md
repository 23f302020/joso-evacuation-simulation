# Phase 1 / Phase 2 比較解釈

> **⚠️ 2026-07-12 追記（[[A_prime結果解釈_方針判断_fable5]] 決定31〜36／[[段4_主指標ヌル確定_方針判断_fable5]] 決定107）：** 本書の「逃げ遅れ0」「車両が到着できた」系の結果は **SUMO既定（300秒）テレポート有効下の値**である。Phase 3のA'（テレポート無効・`time-to-teleport=-1`）で未到着が発生し、既定テレポートが渋滞を消していたと判明した。**「渋滞由来の逃げ遅れは発生しない」という一般主張は全廃**（Phase 2結論は撤回しない）。「Phase 2の逃げ遅れ0を実災害時の安全性の証明として扱う」ことは既に禁じているが、加えてPhase 3の **regime bimodality（単一runは初期条件に脆弱）** も限界として相互参照すること。

> 作成日：2026/05/18  
> 位置づけ：Phase 1の静的分析結果とPhase 2の動的SUMO結果を、卒論で混同せず比較するための考察整理

---

## 1. 比較の基本方針

Phase 1とPhase 2は、どちらも浸水に伴う道路閉鎖が避難へ与える影響を扱うが、分析の単位と意味が異なる。

Phase 1は、道路ネットワーク上で閉鎖道路を除外し、出発地から避難所までの最短経路が存在するかを調べる静的分析である。ここでの主な結果は、閉鎖道路数、到達不可メッシュ数、到達不可人口である。

Phase 2は、SUMO上で車両を走行させ、時刻別の道路閉鎖と再経路探索を反映した動的交通流シミュレーションである。ここでの主な結果は、車両到着数、未到着数、逃げ遅れ主指標、閉鎖時の再経路探索結果である。

したがって、Phase 1の到達不可数とPhase 2の逃げ遅れ台数は、同じ意味の数値として直接比較しない。

---

## 2. 指標の違い

| 項目 | Phase 1 | Phase 2 |
|---|---|---|
| 分析方法 | 静的ネットワーク分析 | 動的交通流シミュレーション |
| 実装単位 | 道路グラフ、出発地メッシュ、避難所 | SUMO edge、車両エージェント、安全避難所 |
| 道路閉鎖 | 閉鎖edgeをグラフから除外 | TraCIでSUMO edgeを通行不可化 |
| 経路探索 | 道路距離最短経路 | SUMOのroute生成と閉鎖後の再経路探索 |
| 主な結果 | 到達不可メッシュ・人口 | 到着車両・未到着車両・逃げ遅れ主指標 |
| 渋滞 | 考慮しない | SUMO上の車両流として考慮 |
| 考察での役割 | 潜在的な避難困難箇所の抽出 | 自家用車避難ベースラインの検証 |

---

## 3. Phase 1から読み取れること

Phase 1では、浸水範囲と道路ネットワークを重ね合わせ、浸水深0.5m以上の範囲と交差する道路を閉鎖対象とした。そのうえで、閉鎖道路を除外したネットワーク上で避難所までの最短経路を探索した。

この結果から読み取れるのは、道路閉鎖によって避難経路が失われる可能性のある地点である。たとえば、閉鎖edge数が多い地域や、避難所への経路が途切れる地域は、静的な道路ネットワーク条件のもとで避難困難になりやすい地域として整理できる。

ただし、Phase 1では車両の流れ、混雑、発進時刻、再経路探索のタイミング、交通容量などは考慮しない。そのため、Phase 1の到達不可は「道路ネットワーク上で経路が存在しない状態」であり、実際に車両が走った場合の到着可否そのものではない。

---

## 4. Phase 2から読み取れること

Phase 2では、Phase 1の閉鎖条件をSUMO edgeへ対応付け、車両を出発地から安全避難所へ向かわせた。閉鎖時刻に達するとTraCIで対象edgeを通行不可とし、走行中車両に再経路探索を行わせた。

この結果から読み取れるのは、今回設定した交通流条件のもとで、自家用車避難がどの程度成立するかである。全41市区町村の10pct試行では、23,054台すべてが到着し、逃げ遅れ主指標は0であった。

この結果は、Phase 1で閉鎖edge数が多かった地域でも、SUMO上では安全避難所までの代替経路が残り、車両が到着できたことを示している。ただし、これは「今回のモデル仮定下で」の結果であり、実災害で逃げ遅れが発生しないことを意味しない。

---

## 5. 閉鎖edge数と逃げ遅れの関係

Phase 1閉鎖edge数の上位地域は、水戸市、筑西市、つくば市、取手市、常総市などであった。これらの地域では、浸水想定区域と道路ネットワークの重なりが大きく、静的には避難経路が影響を受けやすい。

一方、Phase 2の10pct試行では、これらの地域を含む全41市区町村で逃げ遅れ主指標は0であった。このことから、閉鎖edge数が多いことと、SUMO上で逃げ遅れ車両が発生することは同義ではないといえる。

考えられる理由は次のとおりである。

- 閉鎖edgeが多くても、SUMOネットワーク上に代替経路が残っていた。
- 安全避難所を目的地として選び、最近傍の到達可能な避難所へ向かわせた。
- 6時間圧縮時間軸のなかで、閉鎖が進む前に到着できた車両が多かった。
- 10pct試行では車両数を縮小しているため、全量時より混雑が弱くなった可能性がある。
- SUMOの再経路探索により、閉鎖後も迂回できた車両があった。

このため、Phase 1は「閉鎖リスクの空間的分布」を示し、Phase 2は「その条件を交通流として動かしたときの到着可否」を示すものとして組み合わせて解釈する。

---

## 6. 比較結果の本文用表現

本文では、次のように説明できる。

Phase 1では、道路閉鎖を反映した静的な最短経路探索により、浸水に伴う道路ネットワーク上の避難困難箇所を抽出した。これにより、閉鎖edge数が多い地域や、避難所への経路が失われやすい地域を把握できた。

Phase 2では、Phase 1の閉鎖条件をSUMO/TraCIへ接続し、自家用車を車両エージェントとして走行させた。その結果、10pct試行では全41市区町村で逃げ遅れ主指標は発生しなかった。この結果は、今回のモデル仮定下では、閉鎖道路を避ける再経路探索と安全避難所への目的地設定により、車両が到着可能であったことを示す。

ただし、Phase 1の到達不可とPhase 2の逃げ遅れは異なる単位の指標である。Phase 1は経路存在性の評価であり、Phase 2は車両流の評価である。そのため、両者は数値を直接比較するのではなく、Phase 1で示した道路閉鎖リスクが、Phase 2の動的シミュレーションでどのような交通挙動として現れるかを確認する関係として扱う。

---

## 7. 比較時に避けるべき解釈

- Phase 1の到達不可メッシュ数とPhase 2の逃げ遅れ台数を、同じ単位の指標として比較する。
- Phase 2の逃げ遅れ0を、実災害時の安全性の証明として扱う。
- Phase 1の閉鎖edge数が多い地域を、必ずPhase 2でも逃げ遅れが多い地域と断定する。
- full試行を実行していない35市区町村について、全量試行でも同じ結果になると断定する。

---

## 8. 比較の結論

Phase 1とPhase 2を組み合わせることで、道路閉鎖が避難に与える影響を二段階で評価できた。Phase 1では、浸水によって避難経路が制約される可能性を静的に把握した。Phase 2では、その閉鎖条件を動的交通流シミュレーションへ接続し、自家用車避難の基準ケースを構築した。

今回のPhase 2結果では、10pct試行で主指標上の逃げ遅れは発生しなかった。このことは、Phase 2の仮定条件下では車両が安全避難所へ到着可能であったことを示す。一方で、10pct試行、6時間圧縮時間軸、一斉出発、安全避難所固定、SUMO警告の存在といった制約があるため、結果は「自家用車避難ベースライン」として扱い、Phase 3のデマンド交通比較へ接続する。
