# Phase 2 SUMO結果説明

> 作成日：2026/05/18  
> 位置づけ：Phase 2のSUMO/TraCI実行結果を、卒論本文の結果説明へ転記するための整理  
> 対象：Phase 1対象41市区町村、自家用車避難シナリオA

---

## 1. Phase 2で実施した内容

Phase 2では、Phase 1で生成した市区町村別の道路閉鎖条件をSUMO/TraCIへ接続し、自家用車のみで避難する場合の交通流シミュレーションを行った。Phase 1は閉鎖道路を除外した静的な最短経路探索であったのに対し、Phase 2では実際に車両エージェントをSUMOネットワーク上へ投入し、道路閉鎖が進行するなかで目的地となる安全避難所へ到着できるかを確認した。

対象地域は、Phase 1で成果物化済みの茨城県内41市区町村である。鹿嶋市、神栖市、東海村はPhase 1の対象外であるため、Phase 2全域拡張にも含めていない。

---

## 2. 実行条件

| 項目 | 内容 |
|---|---|
| 対象 | Phase 1対象41市区町村 |
| シナリオ | シナリオA：自家用車のみ |
| 道路ネットワーク | Phase 1のOSM道路ネットワークを市区町村別にSUMO変換 |
| 閉鎖道路 | Phase 1の時刻別閉鎖edgeをSUMO edgeへ対応付け |
| 時間軸 | t0〜t7を6時間のSUMO時間へ圧縮 |
| 出発時刻 | 全車両がシミュレーション開始時刻に一斉出発 |
| 避難目的地 | 浸水リスクあり避難所を除外した安全避難所 |
| 再経路探索 | 道路閉鎖後、走行中車両に対してTraCIで再経路探索を実行 |
| 主評価指標 | 未到着かつ再経路失敗、長時間停止、または出発edge閉鎖に該当する車両 |

## 4. small試行の結果

small試行では、各出発地メッシュにつき1台の車両を投入した。これは、SUMOネットワーク、routeファイル、閉鎖制御、再経路探索、summary出力が全市区町村で成立するかを確認するための疎通確認である。

| 指標 | 値 |
|---|---:|
| 実行市区町村数 | 41 |
| 車両数 | 7,720 |
| 到着台数 | 7,720 |
| 未到着台数 | 0 |
| 逃げ遅れ主指標 | 0 |

small試行では、全41市区町村で車両が安全避難所へ到着した。この結果から、市区町村別SUMOネットワーク、出発地・避難所スナップ、閉鎖タイムライン、TraCI制御の基本的な接続は成立していると判断できる。

---

## 5. 10pct試行の結果

10pct試行では、全出発地メッシュを残しつつ、人口から世帯数を近似して車両台数を1/10に縮小した。空間分布を保ちながら、全域比較に使える軽量な主試行として位置づけた。

| 指標 | 値 |
|---|---:|
| 実行市区町村数 | 41 |
| 車両数 | 23,054 |
| 到着台数 | 23,054 |
| 未到着台数 | 0 |
| 逃げ遅れ主指標 | 0 |

10pct試行では、全41市区町村で未到着車両および逃げ遅れ主指標は発生しなかった。この結果は、今回設定した安全避難所、出発地分布、車両台数換算、6時間圧縮時間軸、一斉出発、再経路探索条件のもとでは、主指標上の逃げ遅れが確認されなかったことを示す。

ただし、この結果は実災害において逃げ遅れが発生しないことを意味しない。Phase 2では、避難開始判断、個人差、道路容量の現実的な調整、信号制御、避難者の迷い、避難所以外への移動などは十分には扱っていない。そのため、10pct試行の結果は「今回のモデル仮定下での自家用車避難ベースライン」として扱う。

## 7. 閉鎖道路数が多い地域

Phase 1閉鎖edge数が多い地域は、Phase 2でも入力条件として道路閉鎖の影響を受けやすい地域である。閉鎖edge数の上位は以下のとおりである。

| 08217 | 取手市 | 2,328 | 1,302 | 0 |

## 8. 本文用まとめ

Phase 2では、Phase 1で得られた道路閉鎖条件をSUMO/TraCIへ接続し、自家用車のみで避難する交通流シミュレーションを構築した。対象はPhase 1で成果物化した41市区町村であり、small試行および10pct試行を全市区町村で実施した。10pct試行では計23,054台の車両を投入し、すべての車両が安全避難所へ到着したため、今回のモデル仮定下では主指標上の逃げ遅れは発生しなかった。

一方で、この結果は2015年鬼怒川氾濫時の避難行動を完全に再現したものではない。時間軸は6時間へ圧縮しており、出発時刻は一斉出発、避難目的地は安全避難所に限定している。また、full試行は6市区町村のみである。そのため、Phase 2の結果は実災害での安全性を直接保証するものではなく、Phase 3でデマンド交通バスを導入した場合の比較基準となる自家用車避難ベースラインとして位置づける。
