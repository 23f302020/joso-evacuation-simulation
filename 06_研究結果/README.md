## 引用にあたっての注意

**撤回済みの数値がある。** バス到着67人・救出走行削減29台・シナリオB 9,540台・充足率 0.271255／0.020584 ほかは引用禁止。撤回済み成果物は `../outputs/retracted/` に隔離してある。

**方向主張は禁止。** 主指標のA/B差はヌルであり、「バスが有利」等の方向を持つ主張は行わない。

全禁止事項は `../CLAUDE.md`「恒久禁止事項」を参照。
