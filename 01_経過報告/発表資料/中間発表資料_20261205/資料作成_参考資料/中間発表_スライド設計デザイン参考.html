図表の守るルール

  • 率の図には分母・時点・系列名を必ず添える
  • 差の図にはゼロ線を引く。軸を途中で切らない
  • 異なる段階（これまでの研究とこれからの研究）の率を同じ軸に混ぜない
  • 未完了者を分母から外さない。退出を施設受入に足さない
  • 「模式図」は位置・大きさが実測でないことを図内に明記
  • 方向を示す語（有利・改善・悪化）は結論文に使わない

3. hyperframes composition の構造

各スライドは「ルート要素＋時間付きクリップ＋一時停止の GSAP タイムライン」。レンダラはフレームごとにタイムラインをシークするので、アニメーションは 時計に依存させず（Date・乱数・requestAnimationFrameを使わない）に書いている。

<div class="stage" data-composition-id="s07" data-start="0" data-width="1920" data-height="1080">
  <h2 class="clip" data-start="0" data-duration="6" data-track-index="1">…</h2>
  <svg class="clip" data-start="0.6" data-duration="5.4" data-track-index="2">…</svg>
</div>
<script>
  const tl = gsap.timeline({ paused: true });
  tl.from("#s07 .a", { opacity: 0, y: 24, stagger: .12 }, .2);
  window.__timelines = window.__timelines || {};
  window.__timelines.s07 = tl;     // composition id と同名で登録
</script>

本ページは12個の composition を1ページに並べたプレビュー用。実際に動画化・書き出しするときは、スライド1枚ずつを単独の composition HTML に分けて使う（ルートの data-width/height は1920×1080）。
