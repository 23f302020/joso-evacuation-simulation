# **デマンド交通の災害時活用政策提案**

眞坂研究室　氏名：古賀玲次

  


# 1.  はじめに

デマンド交通は，自家用車を自由に運転できない高齢者などの移動手段として重要な役割を担っており，住民の生活の質や社会参加を支える上で不可欠な存在である．特に人口が少なく公共交通サービスの維持が困難な地域では，住民の日常生活を支える貴重な交通手段である．そのため，地域に必要な交通サービスとして持続的な運営が求められるが，運行費用の面から継続性が課題となるケースが多い[4]．デマンド交通の継続には平常時の移動支援に加えた新たな価値を見出すことが一つの糸口となる．そこで本研究では，デマンド交通に平時以外の付加価値を持たせる一案として，災害時におけるデマンド交通の活用可能性を検討する．

# 2.  研究計画

本研究では，栃木県において発生リスクの高い災害の一つである河川氾濫に着目して検討を行う.対象事例は，平成27年9月関東・東北豪雨に伴う鬼怒川氾濫である．2015年9月10日，茨城県常総市三坂町付近で鬼怒川左岸の堤防が決壊し，市域の広い範囲で浸水被害が発生した[1][2]．水害時の自動車避難では，車両が動けなくなる危険や避難経路上の混雑が指摘されている[3]．本研究では，鬼怒川氾濫を取り上げ，既存のデマンド交通バスを災害支援に活用する方法を検討する．

# 3.  研究全体の流れ

本研究では，Phase 1からPhase 3までの3段階で分析と検討を行う.表1は,研究に使用するデータと用途である.

Phase1では，鬼怒川が氾濫時の浸水による避難困難者を静的に推計する,浸水データ，道路ネットワーク，メッシュ人口，避難施設データを組み合わせ~~,~~浸水範囲から通行困難道路を設定し，それぞれの住民に対して避難所までの経路を求め、経路が確立できない住民を避難困難者として算出する.

Phase 2では動的シミュレーションを行う．実際の氾濫では，浸水範囲は徐々に広がっていく.また,住民が一斉に自動車で避難をした場合,周辺道路に渋滞が生じる可能性もある。そのため，動的な変化を考慮し，避難困難者の推計と交通予測を行う。Phase 1の全閉鎖を一度に与えた静的な経路確認に対し，Phase 2では，時刻ごとの道路の閉鎖を行い，走行中に進路を閉鎖された車両が都度別経路を再探索する．その後，対象地域における基準避難シナリオを作成する.

Phase 3では，Phase 2までの結果を踏まえ，既存のデマンド交通を災害時の避難支援に活用する可能性を，様々な観点から検討する．

最後に，デマンド交通バスを導入する条件を設定する．バスの乗車対象者，乗降地点，目的地とする避難所，運行台数，経路選択方法を整理し，自家用車のみの場合と同じ指標で比較できるようにする．比較指標としては，到着人数，未到着人数，主要避難路の混雑，バス輸送人数などを検討する．

# 5. 今後の予定

本研究では，2015年鬼怒川氾濫を事例に，浸水時の道路閉鎖を考慮した避難シミュレーションの構築を計画している．現時点では，Phase 1（避難困難者の静的推計）とPhase 2（SUMO・TraCIによる動的シミュレーション）の実装の一部が完了している．

今後は，浸水データ，道路ネットワーク，人口メッシュ，避難施設データを組み合わせ，自家用車避難の基準シナリオとデマンド交通バス活用シナリオを作成する予定である．
