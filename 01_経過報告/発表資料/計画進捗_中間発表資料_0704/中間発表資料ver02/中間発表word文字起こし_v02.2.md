河川氾濫時における自家用車避難とデマンド交通バス活用の比較シミュレーション
に関する研究
眞坂研究室　氏名：古賀玲次

1. はじめに
地域公共交通として導入されているデマンド交通は，平時の移動支援手段として期待される一方で，利用者数や運行費用の面から継続性が課題となる場合がある[5]．本研究では，デマンド交通に平時以外の付加価値を持たせる一案として，河川氾濫時の避難支援への活用可能性に着目する．

対象事例は，平成27年9月関東・東北豪雨に伴う鬼怒川氾濫である．2015年9月10日，茨城県常総市三坂町付近で鬼怒川左岸の堤防が決壊し，市域の広い範囲で浸水被害が発生した[1][2]．水害時の自動車避難では，車両が動けなくなる危険や避難経路上の混雑が指摘されている[6][7]．そこで本研究では，自家用車避難が一部道路へ集中した場合の到着遅れや逃げ遅れ候補を交通流シミュレーションで確認する．

避難支援には，徒歩避難，家族・近隣住民による送迎，福祉輸送，自治体バスなど複数の方法がある．本研究では，そのうち既存のデマンド交通バスを災害時避難に活用する案を検討対象とする．本発表では，Phase 1とPhase 2の結果を報告し，Phase 3は今後の実装対象とする．

表1．研究フェーズの位置づけ

| フェーズ | 役割 | 本発表での扱い |
|---|---|---|
| Phase 1 | 閉鎖道路を除き，避難所までの経路有無を確認する | 報告対象 |
| Phase 2 | 自家用車のみの交通流をSUMOで再現し，到着・未到着・混雑を確認する | 報告対象 |
| Phase 3 | デマンド交通バス導入時の効果を自家用車のみの場合と比較する | 今後実装 |

2. 方法
本研究では，浸水データ，道路ネットワーク，人口メッシュ，避難施設データを組み合わせる．道路閉鎖はSUMO実行後の結果ではなく，事前に作成する入力条件である．A31a浸水想定区域の浸水深コードを用い[8]，浸水深0.5m以上の範囲と道路リンクが重なる場合に通行困難道路とした．0.5m以上をしきい値としたのは，浸水深0.5m程度で自動車走行が危険になることが示されているためである[7]．

Phase 1では，閉鎖道路を除いた道路ネットワーク上で，出発地から洪水対応避難所までの経路が存在するかを確認した．Phase 2では，Phase 1の閉鎖道路をSUMO edge IDへ変換し，TraCIにより走行中の道路閉鎖と再経路探索を行った．SUMO上の時間は0〜21,600秒とし，浸水時系列t0〜t7を6時間に対応付けた．

表2．主な使用データと派生データ

| 区分 | データ・ファイル | 研究内での役割 |
|---|---|---|
| 浸水 | 国土地理院KML，A31a浸水想定区域 | 浸水範囲と閉鎖道路条件の作成 |
| 道路・区域 | 道路ネットワークGraphML，行政区域N03 | 経路検索とSUMOネットワーク作成 |
| 人口・避難先 | 250m人口メッシュ，避難施設P20 | 出発地，車両数，避難所の設定 |
| SUMO入力 | `joso.net.xml`，`closure_timeline_sumo.json`，`agent_origins_sumo.csv`，`agent_origins_10pct.csv`，`shelters_sumo.csv` | 交通流シミュレーションの入力 |

3. 結果
Phase 1の常総市試行では，出発地40メッシュ，人口2,257人，高齢者611人を対象とした．閉鎖道路を考慮した結果，到達不可となったのは17メッシュ，人口952人，高齢者223人であった．また，茨城県内41市区町村へ静的経路検索を拡張し，市区町村別シナリオHTMLを生成した．

Phase 2では，常総市を対象にsmall，10pct，fullの3規模で自家用車避難を実行した．full試行の1,001台は常総市全体の車両数ではなく，対象40メッシュの人口を1世帯2.3人としてメッシュごとに世帯換算し，切り上げた避難車両数である．常総市全体の自動車保有台数25,698台とは区別する．

表3．主な結果

| 区分 | 指標 | 結果 |
|---|---|---|
| Phase 1 | 到達不可 | 17メッシュ，人口952人，高齢者223人 |
| Phase 2 full | 到着・未到着 | 1,001台中987台到着，14台未到着 |
| Phase 2 full | 主要道路の混雑 | 県道357号で最大137台・停止105台，国道294号で最大61台・停止7台 |
| 41市区町村 | 10pct試行 | 合計23,054台，逃げ遅れ候補0台 |

未到着14台は，いずれも閉鎖済みの出発edgeから発車できなかった車両である．これは設定した道路閉鎖条件により，出発地点周辺の道路がすでに通行困難となった状態を示す．本研究では，これらを逃げ遅れ候補として扱う．

4. 考察と今後の予定
Phase 1とPhase 2は，閉鎖道路タイムラインを共有している点で接続している．一方で，Phase 1は経路の有無を確認する静的分析であり，Phase 2は車両走行を扱う動的分析である．そのため，到達不可人口と未到着車両数は単位が異なり，直接比較しない．

現時点では，自家用車のみで避難した場合の基準シナリオを作成できた．今後はPhase 3として，デマンド交通バスを導入したシナリオを作成し，到着率，未到着台数，主要避難路の混雑，バス輸送人数を比較する．なお，他の避難支援手段との比較や出発時刻分散の感度分析は今後の課題である．

5. おわりに
本研究では，2015年鬼怒川氾濫を事例に，浸水時の道路閉鎖を考慮した避難シミュレーションを構築した．Phase 1では到達不可人口を把握し，Phase 2では自家用車のみの交通流と混雑を確認した．これらの結果を，デマンド交通バス活用を検討するPhase 3の比較基準として用いる．
