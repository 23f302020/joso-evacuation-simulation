河川氾濫時における自家用車避難とデマンド交通バス活用の比較シミュレーション
に関する研究
眞坂研究室　氏名：古賀玲次

1. はじめに
地域公共交通として導入されているデマンド交通は，平時の移動支援だけでなく，災害時の避難支援にも活用できる可能性がある．本研究では，平成27年9月関東・東北豪雨に伴う鬼怒川氾濫を事例とし，浸水時の道路閉鎖を考慮した避難シミュレーションを構築する．

河川氾濫時には，道路が浸水により通行困難となり，通常時の最短経路では避難可能性を評価できない．また，自家用車避難が一部道路へ集中すると，速度低下や停止が生じる可能性がある．そこで本研究では，自家用車のみで避難する場合を基準として整理し，今後デマンド交通バスを導入した場合と比較するための基盤を作成する．

表1．研究フェーズの位置づけ

| フェーズ | 役割 | 本発表での扱い |
|---|---|---|
| Phase 1 | 浸水時に閉鎖される道路を除き，避難所までの経路有無を確認する | 報告対象 |
| Phase 2 | 自家用車のみの交通流をSUMOで再現し，到着・未到着・混雑を確認する | 報告対象 |
| Phase 3 | デマンド交通バス導入時の効果を自家用車のみの場合と比較する | 今後実装 |

2. 方法
本研究では，浸水データ，道路ネットワーク，人口メッシュ，避難施設データを組み合わせる．まず，A31a浸水想定区域から浸水深0.5m以上の範囲を抽出し，道路リンクと重なる箇所を通行困難道路とした．この閉鎖道路タイムラインをPhase 1とPhase 2で共通して用いる．

Phase 1では，閉鎖道路を除いた道路ネットワーク上で，出発地から洪水対応避難所までの経路が存在するかを確認した．Phase 2では，Phase 1の閉鎖道路をSUMO edge IDへ変換し，TraCIにより走行中の道路閉鎖と再経路探索を行った．SUMO上のシミュレーション時間は0〜21,600秒とし，浸水時系列t0〜t7をこの6時間に対応付けた．

表2．主な使用データと派生データ

| 区分 | データ・ファイル | 研究内での役割 |
|---|---|---|
| 浸水 | 国土地理院KML，A31a浸水想定区域 | 浸水範囲と閉鎖道路条件の作成 |
| 道路・区域 | 道路ネットワークGraphML，行政区域N03 | 経路検索とSUMOネットワーク作成 |
| 人口・避難先 | 250m人口メッシュ，避難施設P20 | 出発地，車両数，避難所の設定 |
| SUMO入力 | `joso.net.xml`，`closure_timeline_sumo.json`，`agent_origins_sumo.csv`，`shelters_sumo.csv` | 交通流シミュレーションの入力 |

3. 結果
Phase 1の常総市試行では，出発地40メッシュ，人口2,257人，高齢者611人を対象とした．閉鎖道路を考慮した結果，到達不可となったのは17メッシュ，人口952人，高齢者223人であった．また，茨城県内41市区町村へ静的経路検索を拡張し，市区町村別シナリオHTMLを生成した．

Phase 2では，常総市を対象にsmall，10pct，fullの3規模で自家用車避難を実行した．full試行の1,001台は常総市全体の車両数ではなく，対象40メッシュの人口を1世帯2.3人として換算した避難車両数である．常総市全体の自動車保有台数25,698台とは区別する．

表3．主な結果

| 区分 | 指標 | 結果 |
|---|---|---|
| Phase 1 | 到達不可 | 17メッシュ，人口952人，高齢者223人 |
| Phase 2 full | 到着・未到着 | 1,001台中987台到着，14台未到着 |
| Phase 2 full | 主要道路の混雑 | 県道357号で最大137台・停止105台，国道294号で最大61台・停止7台 |
| 41市区町村 | 10pct試行 | 合計23,054台，逃げ遅れ候補0台 |

4. 考察と今後の予定
Phase 1とPhase 2は，閉鎖道路タイムラインを共有している点で接続している．一方で，Phase 1は経路の有無を確認する静的分析であり，Phase 2は車両走行を扱う動的分析である．そのため，到達不可人口と未到着車両数は単位が異なり，直接比較しない．

現時点では，自家用車のみで避難した場合の基準シナリオを作成できた．今後はPhase 3として，デマンド交通バスを導入したシナリオを作成し，到着率，未到着台数，主要避難路の混雑，バス輸送人数を比較する．

5. おわりに
本研究では，2015年鬼怒川氾濫を事例に，浸水時の道路閉鎖を考慮した避難シミュレーションを構築した．Phase 1では到達不可人口を把握し，Phase 2では自家用車のみの交通流と混雑を確認した．これらの結果を，デマンド交通バス活用を検討するPhase 3の比較基準として用いる．
