## Slide Frame

スライドの全ページに共通して適用される「枠」の要素を定義します。SLIDE-PATTERN-{name}.mdはコンテンツエリアの構造のみを定義するため、タイトルエリア・ページ番号・装飾はすべてここで一括管理します。これにより、どのパターンを使っても枠の見た目が統一されます。

**タイトルエリア：** 上部中央配置。点線（`·····`）で両側を挟んだブラケット形式で表示。例：`·············· [ グラフと図の効果的な使用法 ] ··············`。コンテンツパネルの外側・上部に配置し、パネル内には含めない。
**ページ番号：** なし
**装飾：** 左上と右サイドに有機的なウェーブ形状（ブロブ）を Primary（#29ABE2）と Secondary（#A8DCF0）のグラデーションで配置。コンテンツスライドでは白いインナーパネル（border: 1.5px solid #CDD8E3）をブロブの前面に配置する。

```yaml
slide_frame:
  title_area:
    position: "top-center"
    text_align: "center"
    decoration: "dotted-bracket"
    format: "·· [ タイトル ] ··"
  page_number:
    position: "none"
    format: "none"
  decoration: "gradient-blob-top-left-and-right"
  inner_panel:
    border: "1.5px solid #CDD8E3"
    border_radius: "3px"
    padding: "24px 32px"
    margin: "0 60px 16px"
```

## Do / Don't

**Do（やること）**

- 左上と右サイドにウェーブ形状のブルーグラデーションブロブ装飾を配置する
- セクションタイトルは `[ タイトル ]` 形式で両側に点線を添え、上部中央に配置する
- コンテンツは白いインナーパネル（細いボーダー付き）の中に整理して表示する
- グラフ・表・アイコンカードなど視覚要素を積極的に活用する
- 数字付き黒丸バッジ（セクション番号）でコンテンツ間の階層を明示する

**Don't（やってはいけないこと）**

- テキストのみのスライドを作らず、必ず図解・グラフ・アイコン等の視覚要素を使う
- ブロブ以外の派手な装飾要素を追加して画面を混雑させない
- 原色や高彩度の色を追加してブルー系の統一感を損なわない
- フォント種類を増やしてタイポグラフィの統一感を壊さない

### Pattern: cover-title-center

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

**概要：** 大きなタイトルテキストとサブタイトルをスライド中央に配置し、装飾的な背景グラフィック（グラデーション・波形・図形）を組み合わせたカバースライドレイアウト
**適したシーン：** プレゼン・提案書の表紙、章の区切りスライド、セクション導入スライド

**Structure（構造）**

スライド全体（タイトルエリアも含む）を使うカバーレイアウト。背景に装飾グラフィック（グラデーション、波形、半透明の幾何学図形など）を配置し、中央にタイトル・サブタイトルを大きく表示する。通常、SLIDE.mdのSlide Frameを無効化またはシンプルに変更して使う。

**Elements（各要素の役割）**


| 要素         | 配置        | 役割                  |
| ---------- | --------- | ------------------- |
| 背景装飾グラフィック | スライド全体    | ブランドらしさと視覚的インパクトを演出 |
| メインタイトル    | 中央（大フォント） | スライドまたは章の主題を大きく表示   |
| サブタイトル     | タイトル下     | 副題・説明文・キャッチコピー      |


**注意点：**

- このパターンはSlide Frameのタイトルエリアを使わない（またはカバー専用デザインに変更する）
- 背景装飾はブランドカラーのグラデーションが定番（SLIDE.mdのブランドカラーを参照）
- テキストはシンプルに2行以内に収めることで洗練された印象になる

### Pattern: agenda-toc

このファイルはスライドのレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。

**概要：** 左上にセクションラベルとタイトルを配置し、その下に番号付き目次リストを縦に並べた1カラムレイアウト。各行は大きな番号・縦線・項目名・点線・ページ番号で構成される。
**適したシーン：** プレゼンテーションの目次・アジェンダスライド。章立てのある資料の冒頭や、セクション区切りの案内に最適。

**Structure（構造）**

スライド全体は1カラム構成。左上にセクションラベル（小文字大文字・アクセントカラー）とタイトル（H1）を配置し、その下に番号付きリストを縦に等間隔で並べる。各リスト行は左から順に「大番号・縦区切り線・項目名・点線リーダー・ページ番号」で構成され、左右に余白を持たせた中央エリアに整列する。

**Elements（各要素の役割）**


| 要素          | 配置          | 役割                         |
| ----------- | ----------- | -------------------------- |
| セクションラベル    | 左上・タイトルの上   | このスライドの種別を示す小見出し（例：AGENDA） |
| タイトル（H1）    | 左上          | スライドのタイトル（例：目次）            |
| 番号（01〜）     | 各行の左端       | セクションの順序を示す大きな番号           |
| 縦区切り線（|）    | 番号の右隣       | 番号と項目名の視覚的な区切り             |
| 項目名         | 縦区切り線の右     | 各セクションの名称                  |
| 点線リーダー（……）  | 項目名とページ番号の間 | 視線を右端のページ番号へ誘導する           |
| ページ番号（p.XX） | 各行の右端       | 対応するページ番号                  |


**注意点：**

- 番号・項目名・ページ番号はすべてアクセントカラーで統一するとまとまりが出る。
- 項目数は4〜8項目程度が視認性の観点から望ましい。それ以上は2カラム化を検討する。
- ページ番号が不要な場合は省略し、点線リーダーも削除してよい。

### Pattern: two-section-stacked-text

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

**概要：** コンテンツエリアを上下2セクションに分け、各セクションに見出し＋本文テキスト＋リストを配置する積み重ねテキストレイアウト。上段は見出し＋本文テキスト、下段は見出し＋本文テキスト＋番号付きリストの構成。
**適したシーン：** 背景説明と具体的なステップの組み合わせ、概要と手順の提示、課題と対応策のリスト、2つのトピックを縦に並べて説明する場面

**Structure（構造）**

コンテンツエリアを上下2セクションに均等分割する。上段と下段の間に細い区切り線を設ける。各セクションは左端にアクセントボーダー付きの見出しを持つ。上段は見出し＋本文（2〜3行）、下段は見出し＋本文（1行）＋番号付きリスト（3項目）。

**Elements（各要素の役割）**


| 要素       | 配置       | 役割                       |
| -------- | -------- | ------------------------ |
| 上段見出し    | 上セクション上部 | 上段の主題を太字・左アクセントボーダー付きで表示 |
| 上段本文テキスト | 上段見出しの下  | 2〜3行の説明文。背景・概要・問題提起など    |
| 区切り線     | 上段と下段の境界 | 2セクションを視覚的に分離する横線        |
| 下段見出し    | 下セクション上部 | 下段の主題を太字・左アクセントボーダー付きで表示 |
| 下段本文テキスト | 下段見出しの下  | 1行の補足説明または導入文            |
| 番号付きリスト  | 下段本文の下   | 3項目の手順・ポイント・対応策を番号付きで整理  |


**注意点：**

- 上段・下段の縦の高さが均等になるよう、各セクションのテキスト量を調整すること
- 下段のリストは3項目が最適。4項目以上は別パターンを検討すること
- 見出しの左アクセントボーダーにブランドカラーを適用するとデザインが統一される

### Pattern: three-stage-circle-flow

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリアを除いたコンテンツ領域のみを対象とします。

**概要：** 3つの大きな円形アイコン（ステージ名ラベル付き）を矢印で横に連結し、各円の下に見出し・サブタイトル・区切り線・箇条書きを配置するステージ型フローレイアウト。プロセスの3段階・3フェーズ・3ステップを順序立てて説明する際に適している。

- **適用場面:** プロセス解説、導入手順、ロードマップ概要
- **情報密度:** 中（段階ごとに3項目の詳細を内包）
- **方向性:** 左から右への時系列的な流れの可視化

**Structure**

```
┌─────────────────────────────────────────────────┐
│  ┌──────────┐      ┌──────────┐      ┌──────────┐│
│  │  (circle)│  →   │  (circle)│  →   │  (circle)││
│  │ ステージ1 │      │ ステージ2 │      │ ステージ3 ││
│  └──────────┘      └──────────┘      └──────────┘│
│    見出し1          見出し2            見出し3     │
│    サブタイトル      サブタイトル        サブタイトル │
│    ────             ────               ────       │
│    ・詳細テキスト    ・詳細テキスト      ・詳細テキスト│
└─────────────────────────────────────────────────┘
```

**Elements**

- ステージ円形アイコン：width/height 110px、円形、ボーダー2px、背景#F0F0F0、ステージ名（font-size:12px / bold）
- テキストエリア（円の下）：見出し（15px bold 中央）、サブタイトル（12px bold）、区切り線（40px）、箇条書き（11px / 3項目）
- 矢印：「→」font-size:24px / color:#CCCCCC / align-self:flex-start; margin-top:48px

**Usage Guide**

- 3ステージは「現状→移行→目標」「計画→実行→評価」のように対比構造を持たせると効果的
- 円形内のアイコン代替文字は実装時にアイコン画像やSVGアイコンに差し替える
- 各ステージの箇条書きは3項目で統一し、文字数も揃えるとバランスが良い
- ステージ名はステージ番号（Phase1など）とラベルを組み合わせると識別しやすい

### Pattern: before-after-two-col

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

**概要：** 「Before（課題・現状）」と「After（改善後・目標）」を左右2カラムで対比するパターン。中央の矢印で変化の方向を明示する。
**適したシーン：** ビジネス提案・改善提案・課題解決の提示・現状と目標の比較

**Structure（構造）**

左カラム（BEFOREラベル、×マーカーのリスト3〜4項目）と右カラム（AFTERラベル、○マーカーのリスト3〜4項目）を左右対称（各約42%）に配置し、中央に矢印（→、約8%）を置く。

**Elements（各要素の役割）**


| 要素         | 役割                         | 推奨文字数         |
| ---------- | -------------------------- | ------------- |
| BEFORE ラベル | 左カラムが「現状・課題」であることを示すヘッダー   | 固定（"BEFORE"）  |

| AFTER ラベル  | 右カラムが「改善後・目標」であることを示すヘッダー  | 固定（"AFTER"）   |
| ○ リストアイテム  | 改善後の状態・達成すべき目標を箇条書きで列挙     | 1項目あたり20〜40文字 |


**注意点：**

- BEFOREとAFTERの項目数は揃えること（3〜4項目が最適）
- 各項目は対応関係が分かるよう順番を揃えると効果的
- 矢印は装飾のため、コンテンツとして変更しない

### Pattern: four-step-flow

このファイルはスライドのレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。

**概要：** 上部に中央揃えのタイトルを配置し、下部に4枚の等幅カードを横並びにしたフロー図レイアウト。各カードは番号バッジ・ラベル・イラストで構成され、カード間の矢印でステップの流れを示す。
**適したシーン：** プロセス・手順・ワークフローの説明。「〜の進め方」「〜のステップ」のように順序のある内容を視覚的に整理したいときに最適。

**Structure（構造）**

スライド全体は上下2段で構成される。上段にタイトルエリア（中央揃え）、下段に4つの等幅カード（各約22%）を横に並べる。カード間には順序を示す矢印（▶）を挟む。各カードは上部に番号バッジ（丸形・アクセントカラー）、中央上にテキストラベル、中央下にイラストを縦に積み上げる構成。

**Elements（各要素の役割）**


| 要素       | 配置          | 役割                     |
| -------- | ----------- | ---------------------- |
| タイトル（H1） | スライド上部・中央揃え | スライド全体のテーマ・タイトル        |
| カード（×4）  | 横並び・等幅      | 各ステップのコンテナ。角丸・ボーダー付き   |
| 番号バッジ    | 各カードの上端中央   | ステップの順序を示す番号（1〜4）      |
| ステップラベル  | 各カード中央上部    | そのステップで行うことの短い説明（1〜2行） |
| イラスト     | 各カード中央下部    | ステップの内容を補強するビジュアル      |
| 矢印（▶）    | カード間（計3箇所）  | ステップの進行方向・順序の明示        |


**注意点：**

- ステップ数は4固定のパターン。
- イラストがない場合は、カード下部をアイコン（SVG・絵文字）またはカラーブロックで代替できる。
- 番号バッジの色はデザインシステムのアクセントカラーを使用する。
