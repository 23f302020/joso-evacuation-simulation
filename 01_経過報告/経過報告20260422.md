### 1-3. 新しい研究の核心

```
【前提】
  平常時：デマンド交通バスは高齢者向け固定ルートシャトルとして運行
          （住宅街 → 病院 → 買い物 の決まったルートを低頻度運行）
  災害時：別ルートを動的に検索し、避難輸送として切り替え運用

【比較シミュレーション】
  シナリオA（ベースライン）：全住民が自家用車で避難
      → 道路が車で飽和 → 渋滞 → 逃げ遅れ多数

  シナリオB（提案）：車を持たない世帯・高齢者がデマンド交通バスを利用
      → 道路の車両数が減少 → 渋滞緩和 → 逃げ遅れ減少
```

**研究の強み：**

- 2015年鬼怒川氾濫という実際の事例データと照合できる
- 「新インフラ不要（平常時シャトルバスの転用）」という現実的な政策提案
- 「バスがあると渋滞が減る」という直感的に分かりやすいメッセージ

### 2-4. 実装前の意思決定（3件）

#### ① シミュレーションツールの選定


| 項目       | 内容                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| **決定内容** | **SUMO（Simulation of Urban MObility）を使用する**                                                                        |
| 検討した選択肢  | SUMO / MATSim                                                                                                      |
| 選定理由     | 本研究の主目的は「渋滞の再現と比較」であり、SUMOは交通流シミュレーション特化ツールとして渋滞・車両フローの精密な再現に最も適している。最重要先行論文（JIPR 2025）もSUMO＋数理計画法を使用しており、比較可能性が高い |
| 却下した選択肢  | MATSim（DRTモジュールで動的バスルートを扱える点は有利だが、渋滞の精密な再現より行動計画に強みがあり、本研究の主目的とはミスマッチ）                                             |


#### ② 道路閉鎖条件の閾値


| 項目       | 内容                                                                                 |
| -------- | ---------------------------------------------------------------------------------- |
| **決定内容** | 浸水深 **0.5m以上** の道路リンクを通行不可とする                                                      |
| 変更前の設定   | 浸水深 0.3m（30cm）以上                                                                   |
| 変更後の設定   | **浸水深 0.5m（50cm）以上**                                                               |
| 変更理由     | 国土交通省「洪水ハザードマップ作成の手引き」が「浸水深0.5m以上で一般乗用車の通行が事実上不可能」と明示。JAF走行テストでも60cmでセダンのエンジン停止を確認 |
| 論文での記述方針 | 「国土交通省の基準（洪水ハザードマップ作成の手引き）に基づき、浸水深0.5m以上の道路リンクを通行不可として設定した」                        |

### 3-3. 法制度・先行文献調査

**避難行動要支援者**

- 根拠法令：災害対策基本法 第49条の10
- 定義：「災害が発生した際に自ら避難することが困難な者」
- 名簿作成：全市区町村（1,741団体）に義務付け（平成25年改正）

**浸水深と行動困難の基準**

- 0.5m以上：ほとんどの人が屋外避難困難（国交省「川の防災情報」）
- 0.5m以上：一般乗用車の通行が事実上不可能（国交省 洪水ハザードマップ手引き）

**最重要先行論文（JIPR 2025）**

- タイトル：「A simulation-based framework for leveraging shared autonomous vehicles to enhance disaster evacuations in rural regions with a focus on vulnerable populations」
- 掲載：Journal of Infrastructure Preservation and Resilience（Springer）、2025年3月
- DOI：10.1186/s43065-025-00122-6
- 概要：農村部×脆弱者×SAV×道路閉鎖シナリオという構造が本研究と類似。ツールはSUMO＋数理計画法を使用。
- **本研究との差別化：** SAV（将来技術）ではなく現行のデマンド交通（DRT）を活用し、日本の法制度に基づく要支援者定義に準拠する点。

## Part 6：SUMO + TraCI 実装設計

シミュレーション構築に向け、SUMOで浸水時系列に応じた動的道路閉鎖とバス運行を実装するための技術設計を整理した。

### 6-1. 実装の全体フロー

```
浸水時系列データ（GSI KML・8時点）
        ↓
 各タイムステップで浸水ポリゴンと道路リンクを照合
        ↓
 TraCI API で浸水深0.5m以上の道路リンクを閉鎖
        ↓
 SUMO 上の車両・バスが閉鎖道路を迂回
        ↓
 逃げ遅れ人数・渋滞・避難完了時間を出力
```

### 6-2. 動的道路閉鎖（Python + TraCI）

Python の `traci.edge.setDisallowed()` API で、浸水ポリゴンと交差するエッジをリアルタイム閉鎖する。osmnx で取得した常総市の道路ネットワークと浸水ポリゴン（GSI KML）を GeoDataFrame で重ね合わせてエッジIDリストを時点別に生成し、各シミュレーションステップに対応する閉鎖リストを TraCI に渡す。

### 6-3. バスの運行設定（シナリオB）

**方針：固定往復ルートとして実装（卒論スコープ）**

SUMO の公共交通定義（pt）でバスを固定ルート往復させる方式が最もシンプル。浸水で通れなくなった場合の動的ルート変更は TraCI で実装可能だが、卒論スコープでは**台数の感度分析（3・5・10台）**に絞る。

### 6-4. 評価指標の取得


| 評価指標          | 取得方法                                           |
| ------------- | ---------------------------------------------- |
| 道路の平均速度（渋滞指標） | `traci.edge.getLastStepMeanSpeed(edge_id)`     |
| 道路上の車両数（密度）   | `traci.edge.getLastStepVehicleNumber(edge_id)` |
| 逃げ遅れ判定        | 浸水到達時刻に浸水エリア内にいる車両・歩行者をカウント                    |
| 避難完了          | 車両が避難所エッジに到達したことを検出                            |
