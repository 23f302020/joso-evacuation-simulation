## 2. 現在の結論と研究の到達点

Phase 1からPhase 3までの実装、比較、感度確認、可視化、研究結果の監査は完了した。確定した研究上の問いへ回答するために必要な結果はそろっており、Phase 3の追加実行や追加実装は不要である。

研究の正式結論は次のとおりである。

> 本研究で実施した条件と試行回数の範囲では、デマンド交通バスを導入した場合と導入しない場合の間で、高齢者や車を持たない人が避難を完了できる割合について、一貫した改善または悪化は確認できなかった。

これは「バスに効果がない」「両者が同じ」と証明したものではない。今回のモデルと試行回数では、全体への効果の方向を確実に判別できなかったという意味である。一方、バスが実際に住民を避難所まで輸送し、自家用車を使えない人へ別の移動手段を提供できたことは確認できた。

## 3. 研究設計の監査と方針変更

Phase 3実装前の批判的レビューにより、次の重大な問題を検出した。

1. 想定していた救出走行削減数と実際の人口・世帯会計に大きなずれがあった。
2. SUMOの既定設定により、長時間停止した車両が自動的に移動させられ、渋滞が人工的に解消される可能性があった。
3. 小規模な試行と常総市全体の想定人口に大きな規模差があった。
4. 高齢者や車を持たない人の避難効率・公平性へ直接答える評価項目が不足していた。

このため、「バスを追加すれば改善する」という期待を前提にせず、比較条件、車両会計、評価方法、再現性を先に固定してから結果を確認する方針へ変更した。差が出ない場合も正式な研究結果として受け入れることを、結果確認前に決めた。

## 5. A/B実行条件の統一

AとBの違いがバスの有無だけになるよう、次の処理を共通化した。

1. 浸水による道路閉鎖の適用
2. 閉鎖時の全車両の再経路探索
3. 出発前に経路が閉鎖された車両の判定
4. シミュレーション終了条件
5. 車両ごとの記録と実行概要の出力
6. 長時間停止車両を自動移動させる機能の無効化

実行時には経路ファイルの指定を必須とし、A用とB用の取り違えを防止した。また、実行ID、経路ファイルの識別値、車両数、開始・終了時刻、乱数条件を記録する仕組みを追加した。

## 6. シナリオAの再実行と未到着479台

長時間停止車両の自動移動を無効にしてシナリオAを再実行した結果、9,569台のうち9,090台が到着し、479台が到着できなかった。旧結果の「全車到着」は、300秒以上停止した車両をSUMOが自動移動させる既定設定に依存していた。

未到着479台は次の三つに分けて確認した。


| 状態      | 台数   | 説明                      |
| ------- | ---- | ----------------------- |
| 道路上の孤立  | 68台  | 道路閉鎖によって避難所へ進める経路がなくなった |
| 交差点の詰まり | 24台  | 交差点付近で動けなくなった           |
| 待ち行列    | 387台 | 前方の混雑や閉塞により進めなくなった      |


これにより、「渋滞による逃げ遅れは発生しない」という旧解釈を撤回した。ただし、Phase 2の道路変換、動的閉鎖、可視化、41市区町村の地域比較は、手法構築と地域の特徴を確認する成果として維持する。

## 7. 評価方法の固定

主な比較対象は、高齢者や車を持たない人が6時間以内に避難所へ到着できた割合とした。比較途中で計算方法が変わらないよう、対象人数を3,231.5人に固定し、実際に到着した人だけを到着者として数えた。

また、次の判定規則を結果確認前に固定した。

1. A側3回とB側5回のすべての組合せ、合計15組を比較する。
2. 15組すべてでBが良い、または15組すべてでBが悪い場合だけ、改善・悪化の方向を述べる。
3. 一つでも方向が異なる場合は、「今回のモデルでは方向差を確認できない」とする。
4. 都合の悪い試行を後から除外しない。

## 8. バス利用者集計と車両会計の是正

最初の有効なB計測では、バス到着141人と集計されていた。しかし、一次ログを確認すると、運行を打ち切った2便の車内にいた16人が、避難所へ着いていないにもかかわらず到着者へ含まれていた。

この16人を除き、実際に避難所へ到着した人数を125人と確定した。16人は「バスへ乗ったが避難所へ到着できなかった人」として未到着へ数え、バス運行に固有のリスクとして残した。

到着125人を1台当たり2.3人で換算し、迎えに行く車の削減数を次のように固定した。

```text
125人 ÷ 2.3人/台 の小数点以下切り捨て ＝ 54台
```


| シナリオ   | 自家用車   | 迎えに行く車 | 合計        |
| ------ | ------ | ------ | --------- |
| A：バスなし | 8,164台 | 1,405台 | 9,569台    |
| B：バスあり | 8,164台 | 1,351台 | 9,515台＋バス |

## 9. 単一試行の廃止と複数試行への変更

同じプログラムでも、車両の動きに使う初期値が変わると、到着人数が大きく変わることが分かった。バス到着人数は125人から75人、さらに207人へ変動し、そこから計算する車両削減数も54台、32台、90台と安定しなかった。

そこで、特定の一回を正解として採用する方法を廃止し、車両削減54台を固定したうえで、次の複数試行を事前に決めて実行した。

## 12. デマンド交通バスの確認できた利点と限界

確認できた利点は次のとおりである。

1. B側5回で、1回につき75〜165人を避難所まで輸送した。
2. 自分で車を使えない人へ、迎えの自家用車とは別の避難手段を提供できた。
3. バス輸送に対応して、迎えに行く車を54台減らす車両構成を作れた。

一方、次の限界がある。

1. 地域全体の避難完了率が必ず高くなるとは確認できなかった。
2. バスへ乗った後に避難所へ到着できなかった人が発生し得る。
3. バスを待つ時間、道路閉鎖の時刻、出発の集中によって効果が変わる可能性がある。
4. 現在のバスは完全な予約最適配車ではなく、定めた乗降地点を往復する方式である。

## 13. バス10台の感度確認

バスを10台に増やした条件でもB側5回を実行した。A側3回との15組比較は、通常値でBが高い10組・低い5組、安全側に補正した値で高い8組・低い7組となった。

台数を増やしても方向が一貫しなかったため、「バスを増やせば避難完了率が必ず改善する」とは言えない。これにより、通常のバス台数で得た正式結論が、10台条件でも変わらないことを確認した。
