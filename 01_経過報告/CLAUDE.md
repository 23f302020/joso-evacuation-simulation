# 01_経過報告 — ガイド

指導教員向け進捗報告フォルダ。報告書は**毎週水曜日**に作成し、**月ごとのサブフォルダ**に置く。発表資料は `発表資料/` にまとめる。

最新の記入済み報告 → `経過報告2026年05月/経過報告20260527.md`
（7月以降は水曜日ぶんの空ファイルを先に用意してある）

## フォルダ構成

```
01_経過報告/
├── 経過報告2026年04月/             ← 経過報告20260401.pptx / coment.txt / 20260422.md
├── 経過報告2026年05月/             ← 経過報告20260513.md / 20260520.md / 20260527.md
├── 経過報告2026年07月/             ← 20260715 / 20260722 / 20260729（いずれも未記入）
├── 経過報告2026年08月/             ← 20260805 / 20260812 / 20260819 / 20260826（未記入）
├── 経過報告2026年09月/〜2026年12月/ ← フォルダのみ（.gitkeep のみ配置）
├── 経過報告2027年01月/・2027年02月/ ← フォルダのみ（.gitkeep のみ配置）
└── 発表資料/
    ├── 計画進捗_中間発表資料_0704/  ← 中間発表資料ver01〜ver04・SLIDE-md・SLIDE-PATTERN
    └── 計画進捗_最終発表資料/       ← 最終発表用（未着手）
```

- 月フォルダ名は `経過報告YYYY年MM月/` 形式（月はゼロ埋め、時系列順に並ぶ）。報告書は毎週水曜日ぶんを、報告日の月フォルダに置く。
- 月フォルダは2027年2月まで作成済み。ファイルのない月には `.gitkeep` を置き、git 管理下に残す。
- 報告書ファイルは8月ぶんまで空ファイルを用意済み。9月以降は報告曜日が変わる可能性があるため、確定してから作成する。
- 発表資料（中間・最終）は報告書とは分け、`発表資料/` 配下の該当フォルダに置く。

## 新規作成時のフォーマット

```markdown
# 経過報告 YYYYMMDD

## 達成事項
- （前回報告から実施・完了したこと）

## 現在の課題・判明した事実
- （技術的に判明したこと、障壁になっていること）

## 次回までの予定
- （次の報告までに着手・完了する作業）
```

## 注意

- ファイル名は `経過報告YYYYMMDD.md` の形式（フォルダ名は `経過報告N月`）
- `.pptx` は `.md` とは別に手動作成（Markdown から変換）
- コメントファイル（`*coment.txt`）は教員フィードバックを記録したもの
- 発表資料の版管理は `中間発表資料verNN/` のようにバージョン単位のフォルダで行う
