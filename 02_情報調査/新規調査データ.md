## 各データソース詳細

### 1. 京都大学防災研究所：浸水深分布解析結果

| 項目 | 内容 |
|------|------|
| 提供元 | 京都大学防災研究所（第二報ページ） |
| 形式 | ArcGIS ラスター形式 / KMZ 形式 |
| 対象範囲 | 常総市全域 |
| 時系列 | なし（最大浸水深分布のみ） |
| 実績/想定 | 2015年実際の浸水位・浸水深推定 |
| 取得状況 | 未ダウンロード |

**評価：**
- 既存の A31a ハザードマップより2015年実災害に近い深度データ
- 時刻別の浸水進行データではないため、時系列道路閉鎖の直接解決にはならない
- 深度の精度向上・検証に有用

---

### 2. 浸水ナビ API

| 項目 | 内容 |
|------|------|
| 提供元 | 国土交通省・国土地理院 |
| URL | https://suiboumap.gsi.go.jp/ |
| API仕様書 | https://suiboumap.gsi.go.jp/pdf/Data-riyo_manual.pdf |
| 取得可能データ | 指定地点の最大浸水深・浸水開始時間・指定時間の浸水深・時系列タイル |
| 実績/想定 | 想定破堤シミュレーション（2015年実績そのものではない） |
| 取得状況 | 未確認 |

**評価：**
- 時系列の道路閉鎖を再構築するための最有力候補
- 鬼怒川・三坂町付近の破堤点が API 対象に含まれるか確認が必要
- 対応していれば `closure_timeline` の時間発展問題を解消できる可能性が高い

---

### 3. 国土地理院：平成27年9月関東・東北豪雨データ

| 項目 | 内容 |
|------|------|
| 提供元 | 国土地理院（GSI 災害ページ） |
| 形式 | KML・時点別 PDF・空中写真・UAV 動画 |
| 実績/想定 | 2015年実績 |
| 取得状況 | KML は取得済み（既存 D1-No.917 と同系統） |

**評価：**
- 現在使用している KML と同系統（LineString 中心・深度なし）
- 追加 KML や空中写真は目視検証に活用できる
- `closure_timeline` の構造問題の直接解決には繋がらない

| 項目 | 内容 |
|------|------|
| 提供元 | 国土交通省 下館河川事務所 |

### 5. 国土地理院：基盤地図情報 DEM（5m / 10m）

| 項目 | 内容 |
|------|------|
| 提供元 | 国土地理院（基盤地図情報サイト） |
| 形式 | DEM ラスター（5m / 10m 解像度） |
| 備考 | ダウンロードにログイン（無料登録）が必要 |

**評価：**
- 浸水深を地形から再推定する際の基礎データとして有用
- 単体では浸水時系列にはならない
