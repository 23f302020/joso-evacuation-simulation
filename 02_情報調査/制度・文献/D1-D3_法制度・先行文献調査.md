## D-1. 避難行動要支援者の法的定義と制度

### 根拠法令

| 条文 | 内容 |
|------|------|
| 災害対策基本法 **第8条第2項** | 「要配慮者」の定義：高齢者・障害者・乳幼児その他特に配慮を要する者 |
| 災害対策基本法 **第49条の10** | **「避難行動要支援者」の定義**および市町村長による名簿作成義務 |
| 災害対策基本法 **第49条の14** | 「個別避難計画」の作成に関する市町村の努力義務（令和3年改正追加） |

**定義の条文（第49条の10第1項）：**
> 「要配慮者のうち、**災害が発生し、又は災害が発生するおそれがある場合に自ら避難することが困難な者**であって、その円滑かつ迅速な避難の確保を図るため特に支援を要するもの」

- e-Gov 法令: https://laws.e-gov.go.jp/law/324AC0000000193/

**法改正の経緯：**
- **平成25年（2013年）改正：** 名簿作成が市町村の**義務**として法定化
- **令和3年（2021年）改正：** 個別避難計画の作成が**努力義務**として追加

### 内閣府「避難行動要支援者の避難行動支援に関する取組指針」

- 最新版：令和3年5月改定
- URL：https://www.bousai.go.jp/taisaku/hisaisyagyousei/youengosya/r3/pdf/shishin0304.pdf
- 全市区町村（1,741団体）に名簿作成義務あり → 令和4年時点で作成率100%
- 改定の背景：令和元年台風19号等での要支援者被害多発を受けた制度強化

### 名簿の典型的な登録条件

| カテゴリ | 登録条件（例） |
|---------|-------------|
| 高齢者（介護） | **要介護認定3・4・5**（一部自治体は要介護1・2も含む） |
| 高齢者（認知症） | 認知症の診断を受けた者 |
| 身体障害者 | **身体障害者手帳1〜2級**（上肢障害除く）、一部3級も対象 |
| 知的障害者 | **療育手帳A（最重度・重度）** |
| 精神障害者 | **精神障害者保健福祉手帳1〜2級** |
| 難病患者 | 難病法に基づく特定疾患の治療受給者証所持者 |
| その他 | 自力避難困難と市町村長が認めた者（手挙げ方式） |

> **優先度が特に高い者：** ハザードマップ危険区域内に居住し、かつ独居または高齢者のみの世帯

### 規模の統計

| 区分 | 全国人数（概数） | 出典 |
|------|--------------|------|
| 要介護・要支援認定者（全体） | 約705万人（令和5年度末） | 厚労省 介護保険事業状況報告 |
| うち要介護3以上 | 約280万人（推計） | 同上 |
| 身体障害者手帳所持者 | 約416万人 | 厚労省「令和4年生活のしづらさに関する調査」 |
| 障害者総数（推計） | 約1,164.6万人（人口比約9.3%） | 内閣府 令和4年版障害者白書 |

> 避難行動要支援者名簿の全国合計登録者数は消防庁調査PDFに掲載されている可能性あり → [消防庁調査結果](https://www.soumu.go.jp/menu_news/s-news/01shoubo01_02000734.html)

### 研究への活用

- 本研究における「要避難者」の定義を、災害対策基本法第49条の10の「避難行動要支援者」に準拠させることで**法的根拠を持った定義**となる
- 「浸水エリア内の高齢者」という仮定に加えて、**名簿登録基準（要介護3以上等）との対応関係**を論文中で明記する

## D-2. 浸水深と歩行・車両通行困難の関係

### 歩行困難の基準（国土交通省）

| 浸水深 | 人への影響 |
|--------|----------|
| 約0.2m | 流速が速い場合、歩行不可能になる |
| 約0.5m | **ほとんどの人が屋外避難困難**（伊勢湾台風・関川水害調査より） |
| 約0.7m | 成人男性でも屋外避難困難 |
| 1.0m以上 | 立っていることが不可能、流される危険 |

※女性・高齢者は0.5mで困難、成人男性は0.7mで困難（伊勢湾台風調査）

- 出典：[国交省「川の防災情報」浸水深と避難行動](https://city.river.go.jp/kawabou/reference/index05.html)

### 車両通行困難の基準

| 浸水深 | 車両への影響 | 出典 |
|--------|------------|------|
| 約0.3m | 一般乗用車の走行が困難になり始める | 国交省 洪水ハザードマップ手引き |
| **約0.5m** | **一般乗用車の通行が事実上不可能。エンジン停止リスク大** | 国交省 川の防災情報 |
| 約1.0m | 大型車（バス・トラック）でも走行困難 | 国交省資料 |

- 出典：[洪水ハザードマップ作成の手引き（改定版）](https://www.mlit.go.jp/river/basic_info/jigyo_keikaku/saigai/tisiki/hazardmap/pdf/hm_kaitei.pdf)
- 出典：[地下街等の浸水対策ガイドライン](https://www.mlit.go.jp/river/basic_info/jigyo_keikaku/saigai/tisiki/chika/pdf/g-11_g-14.pdf)

### モデル仮定への反映

> **道路閉鎖条件を30cm → 0.5mへ修正することを推奨**

「0.5m以上で一般乗用車通行が事実上不可能」という国交省の明示的な基準があり、30cmよりも根拠が明確。

**論文での記述案：**
> 「国土交通省『洪水ハザードマップ作成の手引き』に基づき、浸水深0.5m以上の道路リンクを通行不可と設定した。」

## D-3. 先行文献：MATSim DRT ×避難論文

### 最重要先行研究（JIPR 2025）

| 項目 | 内容 |
|------|------|
| **タイトル** | "A simulation-based framework for leveraging shared autonomous vehicles to enhance disaster evacuations in rural regions with a focus on vulnerable populations" |
| **掲載誌** | Journal of Infrastructure Preservation and Resilience（Springer Open） |
| **DOI** | **10.1186/s43065-025-00122-6** |
| **arXiv** | arXiv:2502.07787（2025年2月投稿） |
| **公開日** | 2025年3月7日 |
| **URL** | https://link.springer.com/article/10.1186/s43065-025-00122-6 |

**概要：**
米国フロリダ州サムター郡（農村部）を対象に、共有型自律走行車（SAV）を活用した災害避難支援フレームワークを提案。数理計画法＋SUMOで、道路閉鎖なし・洪水による道路閉鎖ありの両シナリオを検証。障害者・高齢者・英語非熟達者を含む脆弱人口の優先支援に特化。

**本研究との類似点・差異点：**

| 比較項目 | JIPR 2025論文 | 本研究 |
|---------|-------------|--------|
| 対象地域 | 農村部（米国フロリダ州） | 農村部（日本・対象市町村） |
| 要支援者への注目 | あり（障害者・高齢者等） | あり（災害対策基本法の要支援者定義に準拠） |
| 災害種別 | ハリケーン | **洪水・浸水** |
| 交通モデル | SAV（自律走行車） | **現行のデマンド交通（DRT）** |
| シミュレーションツール | SUMO＋数理計画法 | **MATSim（DRTモジュール）** |
| 道路閉鎖のモデル化 | あり | あり（浸水深0.5m閾値） |
| 日本の法制度への接続 | なし | **あり（災害対策基本法・内閣府指針）** |

**差別化の意義：**
JIPR 2025論文はSAV（将来技術）を前提とするが、本研究は**現在日本で実用されているデマンド交通**を活用するため、即応的な避難支援政策への接続性が高い。
