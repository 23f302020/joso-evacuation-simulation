## 4. 250mメッシュ人口統計（e-Stat）

### 常総市の地域メッシュコード

| メッシュ種別 | コード | 対象エリア |
|------------|--------|----------|
| 1次メッシュ | **5439** | 常総市全域（主要部） |
| 2次メッシュ | **543975** | 水海道市街地周辺（中央部）★ 最重要 |
| 2次メッシュ | **543976** | 常総市東部（小貝川沿い） |
| 2次メッシュ | **543965** | 常総市南部（石下地区） |
| 2次メッシュ | **543966** | 常総市南東部 |

> 常総市の東端が東経140°を超える場合は **5440** 系メッシュも一部含まれる。  
> 確定版は統計局の市区町村別メッシュコード一覧で確認：https://www.stat.go.jp/data/mesh/m_itiran.html

### e-Stat APIでのデータ取得

```python
# Python例：e-Stat APIで250mメッシュ人口取得
import requests

APP_ID = "<YOUR_APP_ID>"  # https://www.e-stat.go.jp/api/ で無料取得
STATS_DATA_ID = "T001109"   # 平成27年国勢調査 250mメッシュ

# 2次メッシュ 543975 の全250mメッシュを取得
url = "https://api.e-stat.go.jp/rest/3.0/app/json/getStatsData"
params = {
    "appId": APP_ID,
    "statsDataId": STATS_DATA_ID,
    "cdAreaFrom": "543975000",
    "cdAreaTo": "543975999",
}
response = requests.get(url, params=params)
```

### e-Stat 統計GISからのCSVダウンロード（推奨・簡便）

1. https://www.e-stat.go.jp/gis/statmap-search?type=1&toukeiCode=00200521 にアクセス
2. 「平成27年国勢調査」→「地域メッシュ統計」→「4分の1地域メッシュ（250m）」を選択
3. 2次メッシュコード `543975`（+ 必要に応じて `543976`, `543965`）を入力
4. ZIP形式でCSVダウンロード

### CSVの主要フィールド

| フィールド名 | 内容 |
|------------|------|
| `KEY_CODE` | 250mメッシュコード（10桁） |
| `T001109_001` | 総人口 |
| `T001109_002` | 男性人口 |
| `T001109_003` | 女性人口 |

> **注意：** 人口5人未満のメッシュは秘匿処理（`*`）。農地・河川敷エリアで多発するが、住宅密集地では問題ない。

## 5. 道路ネットワーク（OSM + osmnx）

### 取得方法

```python
import osmnx as ox

# 常総市の道路ネットワーク取得
G = ox.graph_from_place("常総市, 茨城県, 日本", network_type="drive")

# または bbox指定（常総市付近）
G = ox.graph_from_bbox(36.20, 35.95, 140.05, 139.85, network_type="drive")
```
