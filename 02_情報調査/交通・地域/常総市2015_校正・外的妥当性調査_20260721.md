# 常総市2015年水害の校正・外的妥当性調査

> 調査日：2026/07/21  
> 目的：現行シミュレーションを2015年常総市の実態と照合するため、道路、自動車保有、避難行動、渋滞、逃げ遅れ、地域公共交通の根拠を確認する。

## 1. 結論

避難行動、救助規模、車両保有、定性的な道路混雑、当時の予約型乗合交通について、公的資料から研究背景と入力仮定を改善できる情報を確認した。一方、災害当日の区間別速度・渋滞長・交通量の時系列と、2015年9月時点の道路ネットワーク完全版は確認できなかった。このため、現行モデルの地域文脈と外的妥当性の説明は強化できるが、実災害を数値的に再現したとする校正には不足が残る。

## 3. 避難情報・避難行動・救助

常総市検証報告書では、避難準備情報は9月10日1時40分に2,448世帯・7,229人を対象として発令され、2時20分に避難指示へ切り替えられた。その後、対象地域は拡大したが、12時50分の三坂町における決壊時点で、決壊地点周辺を含む左岸広域には避難指示が出ていなかった地域があった。最終的に35,000人を超える住民を対象として避難措置が講じられ、浸水域から4,200人を超える住民が救助された。

内閣府の住民アンケートは、浸水区域・避難勧告等の対象区域の516件を対象とした。自宅にいた回答者の行動は、おおむね自宅に留まった人42%、安全な避難所ではない場所へ移動した人30%、避難所へ移動した人29%で、約6割が自宅外へ移動した。避難した理由は「危険を感じた」52%、「避難勧告・指示を聞いた」16%、「自宅にいられなくなった」14%だった。避難のきっかけは避難勧告・指示34%、家族・近所・職員等からの働きかけ32%である。一方、自宅に留まった理由は「浸水しないと思った」47%、「2階等へ逃げればよい」19%、「危険を感じなかった」15%だった。

これらは、全員が同時に避難する設定よりも、避難参加率と開始時刻を分布として扱う必要性を示す。ただしアンケート比率をそのまま全市人口へ外挿するには、回答者選定と無回答の偏りを検討する必要がある。

## 4. 道路・渋滞

内閣府資料には、交通混雑により市内避難所へ近づくことが困難となり、近隣自治体へ避難所提供を依頼したことが記録されている。9月18日11時時点の避難者1,786人のうち、市内避難所840人、市外避難所946人であり、市外避難も重要だった。

平成27年度全国道路・街路交通情勢調査（道路交通センサス）には、主要道路区間の平常時交通量、旅行速度、道路構造があるため、国道294号・354号等の自由流速度や通常時交通量の確認に利用できる。ただし、これは水害当日の観測ではない。今回の調査では、2015年9月10日の区間別速度、渋滞長、待ち行列、時刻別交通量を数値で示す一次資料は確認できなかった。

現行の道路ネットワークはOSMの取得時点に依存する。国土地理院の基盤地図情報には道路縁等が含まれるが、過去時点のデータ利用には入手可能時期と経路ネットワーク化の追加確認が必要である。したがって、現行網は常総市の道路形状を用いたモデルであり、2015年9月時点の全道路構成を完全再現したものとは記述しない。

## 5. 自動車保有

関東運輸局の平成27年度末市区町村別表によると、2016年3月31日時点の常総市は、自家用登録乗用車24,105台、営業用を含む登録乗用車合計24,155台だった。自家用の全車種と二輪車を合計した表上の値は28,604台、営業用を含む総計は30,438台である。この表は軽自動車を含まないため、市内で使用可能な全車両数ではない。また、水害当日の避難車両数でもない。

現行モデルのA側9,569台、B側9,515台は、市内保有台数を再現する在庫値ではなく、対象人口と行動仮定から生成した避難交通需要である。24,105台をそのまま車両発生数に置き換えることはせず、今後校正する場合は「浸水対象世帯数×避難参加率×1世帯当たり避難車両数」として分解する。

## 6. 予約型乗合交通「ふれあい号」—旧認識の訂正

従来文書には「2015年時点の常総市にはデマンド交通が存在しない」と記載されていたが、これは誤りである。常総市の予約型乗合交通「ふれあい号」は2009年10月26日に運行を開始している。

2015年度は222日運行し、延べ19,518人、1日平均87.9人、1台1日平均14.7人、乗合率1.83人だった。1日平均利用者数と1台1日平均からは6台相当の運行規模と読める。年齢別では70歳代7,401人、80歳以上8,367人で、両者は延べ利用者の約80.8%を占めた。ただし、水害のため2015年9月10日から10月12日まで運休し、10月13日に再開している。

したがって研究上の位置づけは次のように訂正する。

- 誤：2015年にはデマンド交通がなかったため、架空の新規導入を比較した。
- 正：2015年に地域の予約型乗合交通は存在したが、水害時は運休していた。本研究は、そのような地域交通車両を災害時に固定経路避難シャトルへ転用する仮想比較である。
- 限界：現行実装は予約需要へ応答する動的DRTではなく、固定乗降地点と避難所を往復する。実際の「ふれあい号」の配車・運行を再現していない。

## 7. 校正・改善への利用順

### 追加実装なしで反映できる事項

1. 発表・卒論の地域背景へ、避難行動アンケート、定性的混雑、ふれあい号の実績と運休を引用する。
2. 「2015年にDRTは存在しなかった」という記述を撤回する。
3. 自動車保有24,105台は軽自動車を除く登録乗用車在庫であり、避難車両数と同一ではないと明記する。
4. 現行OSMと2015年道路網、SUMO渋滞と実測渋滞の差を適用限界へ加える。

### 新しい仕様判断と再実行が必要な事項

1. 住民アンケートに基づく避難参加率・開始時刻分布の導入。
2. 平成27年度道路交通センサスを用いた主要道路の自由流速度・平常時交通量校正。
3. 車両発生を、対象世帯、避難参加率、相乗り人数、軽自動車を含む保有状況へ分解する。
4. ふれあい号の実在規模を用いた車両台数感度と、災害時運休／転用可能条件の比較。

これらは現行の正式結果とは別実験にする。値の採否が研究条件を変えるため、判断前に実装しない。

## 8. 未取得の理由と追加調査候補

| 未取得項目 | 推測される理由 | 追加調査候補 |
|---|---|---|
| 災害当日の速度・渋滞長 | 一般道路の災害時プローブデータは公開資料に集計されていない、または民間保有 | 常総市・茨城県への照会、ETC2.0/民間プローブの利用条件確認 |
| 災害当日の時刻別交通量 | 常設観測点が限られ、避難交通だけを分離できない | 道路管理者資料、検証委員会付属資料、研究機関データの照会 |
| 2015年9月の完全な経路網 | 現行OSMは現在状態、基盤地図は必ずしも経路接続済みでない | Geofabrik等の過去OSM、GSI旧版、道路台帳との差分確認 |
| 個人別避難手段・出発時刻 | アンケートは集計値で、個票は非公開の場合がある | 内閣府・調査実施者へ匿名個票の利用可否を照会 |
