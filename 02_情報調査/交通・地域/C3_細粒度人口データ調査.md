## 1. 平成27年国勢調査 小地域集計（町丁・字等別）← 最重要

### 概要

2015年時点の常総市の**町丁・字等単位**の人口・世帯データ。シミュレーション対象年（2015年）と完全に一致するため最優先で使用する。

### 取得可能テーブル

| テーブル | 内容 | バス配車への活用 |
|---------|------|----------------|
| **表2** | 男女別人口・世帯数 — 町丁・字等 | 各町丁の総人口・世帯数の把握 |
| **表3** | 年齢（5歳階級）・男女別人口 — 町丁・字等 | **65歳以上の分布 → バス優先カバーエリアの特定** |
| **表6** | 世帯家族類型別一般世帯数 — 町丁・字等 | 単身高齢世帯・65歳以上のみ世帯の分布 |

### 取得手順

1. 下記URLにアクセスし、対象テーブルのCSVをダウンロード
2. `AREA_CODE` で常総市（市区町村コード `08211`）のレコードを抽出
3. 表3から65歳以上人口を町丁別に集計

```
e-Stat URL（08茨城県 小地域集計）:
https://www.e-stat.go.jp/stat-search/files?tclass=000001082828&cycle=0&layout=datalist
```

### CSVの主なフィールド（概略）

| フィールド | 内容 |
|-----------|------|
| `AREA_CODE` | 地域コード（町丁・字等の識別子） |
| `AREA_NAME` | 地域名称（例：水海道〇〇町） |
| 総人口列 | 町丁の総人口 |
| 年齢階級列 | 5歳刻みの人口（65〜69歳、70〜74歳 … 等） |
| 65歳以上計列 | 65歳以上合計 |

## 2. e-Stat 250mメッシュ人口（T001109）

### 概要

250m × 250m のメッシュ単位で人口・世帯数・年齢別人口を取得できる。町丁・字等より細かい空間分解能でエージェントを配置したい場合に使用する。

### 常総市の主要2次メッシュコード

| メッシュコード | 対象エリア |
|-------------|----------|
| `543975` | 水海道中央エリア |
| `543976` | 常総市東部エリア |
| `543965` | 石下地区 |

### 取得方法

**A. CSVダウンロード（APIキー不要・推奨）**
- e-Stat 統計GIS → 地域メッシュ統計 → 250mメッシュ → 茨城県 → CSV DL
- URL: https://www.e-stat.go.jp/gis/statmap-search?type=1&toukeiCode=00200521

**B. e-Stat API（appId必要・無料）**
```
GET https://api.e-stat.go.jp/rest/3.0/app/json/getStatsData
  ?appId=【取得したappId】
  &statsDataId=T001109
  &cdArea=【メッシュコード】
```

## 3. jSTAT MAP — 配車エリア設計の可視化ツール

| 機能 | 内容 |
|------|------|
| 表示粒度 | 250m / 500m / 1kmメッシュ、町丁・字等 |
| 表示内容 | 人口・年齢・世帯数のコロプレスマップ |
| エクスポート | CSV・Shapefile |
| 利用条件 | **無料・登録不要** |
| URL | https://www.e-stat.go.jp/gis/gislp/ |

### バス配車設計への活用手順

1. jSTAT MAPで常総市の65歳以上人口を地図表示
2. 高齢者が密集する町丁・メッシュを視覚的に特定
3. 浸水エリア（国土地理院KML）と重ねて「浸水 × 高齢者密集」エリアを抽出
4. 抽出エリアをバスの優先カバーゾーンとしてルート設計に反映

## 4. 小地域 vs 250mメッシュ — 使い分け方針

| 比較軸 | 小地域集計（町丁・字別） | 250mメッシュ |
|--------|----------------------|------------|
| 空間粒度 | 町丁・字等（広さ不均一） | 均一な250m格子 |
| 対象年次 | 平成27年（2015年）が利用可 | 平成27年も利用可 |
| SUMO連携 | 町丁ポリゴンで需要ゾーン設定 | メッシュ重心に直接エージェント配置 |
| 推奨用途 | バス停位置・需要ゾーンの設計 | エージェント初期座標の割り当て |

**推奨方針：** エージェントの初期配置は250mメッシュ重心座標を使用し、バスの優先カバーエリアの設計は町丁別65歳以上人口で判断する。
