## 1. 国土地理院・国土交通省の氾濫シミュレーションデータ

### 浸水ナビ（最重要ツール）

| 項目 | 内容 |
|------|------|
| 名称 | 地点別浸水シミュレーション検索システム |
| 提供機関 | 国土交通省・国土地理院 |
| URL | https://suiboumap.gsi.go.jp/ |
| データ形式 | CSV・NetCDF（メッシュ形式） |
| API | あり（緯度・経度・破堤点・経過時間を指定して時系列浸水深を取得） |
| API仕様書 | https://suiboumap.gsi.go.jp/pdf/Data-riyo_manual.pdf |

**重要な機能：**
- 破堤点と経過時間を指定して、任意地点の時系列浸水深データをAPIで取得可能
- **時系列データを自動取得できる唯一の公式ツール**
- 鬼怒川の対応状況は個別確認が必要だが、対応していれば研究に直接使える

## 2. 過去の主要氾濫事例のデータ

### 2-1. 2019年台風19号（千曲川・阿武隈川等）← 代替第1候補

| データ種別 | 形式 | URL |
|-----------|------|-----|
| **浸水推定図（GeoJSON・Shapefile）** | ✅ GeoJSON | https://www.gsi.go.jp/BOUSAI/R1.taihuu19gou.html |
| 被害等の記録（国交省） | PDF | https://www.mlit.go.jp/river/shinngikai_blog/shaseishin/kasenbunkakai/shouiinkai/kikouhendou_suigai/1/pdf/11_R1T19niyoruhigai.pdf |
| 千曲川・犀川出水速報 | PDF | https://www.hrr.mlit.go.jp/chikuma/bousai/shussui/20191012kouzui/sokuhou.pdf |

**特徴：**
- 国土地理院が**浸水推定段彩図の輪郭線をGeoJSON・Shapefile形式で公開**→ 最もGIS利用しやすい
- 対象河川：千曲川・阿武隈川・久慈川・那珂川・荒川水系等
- 国管理河川だけで約25,000haが浸水、全国140箇所で堤防決壊

**千曲川（長野市・千曲市）が代替候補として有力な理由：**
- 道路ネットワーク（OSM）が整備されている
- 浸水エリアと主要道路の交差が多く、渋滞シミュレーションに適した地形
- GeoJSONデータがすぐに使える

### 2-3. 2018年西日本豪雨 真備町（岡山県倉敷市）← 避難行動研究が最充実

| データ種別 | 形式 | URL |
|-----------|------|-----|
| 住民避難行動×ハザードマップ認知 | 論文PDF | https://www.jstage.jst.go.jp/article/jscejhe/75/2/75_I_1381/_pdf |
| 洪水避難と地理的要因 | 論文PDF | https://www.jstage.jst.go.jp/article/jisss/35/0/35_153/_pdf/-char/ja |
| 氾濫流の数値解析 | 論文 | https://www.jstage.jst.go.jp/article/ejgeo/14/1/14_53/_article/-char/ja/ |

- 浸水深最大5m以上・浸水面積約1,200ha

## 4. 推奨する研究データ構成

鬼怒川データを主軸とした場合の最適な組み合わせ：

```
【浸水データ】
  国土地理院 KML（5時点）
  ＋ 浸水ナビAPI（時系列補完・鬼怒川対応確認要）
  ＋ 京大防災研の浸水深分布（精密な空間分布）

【道路ネットワーク】
  OpenStreetMap + osmnx（常総市範囲）

【シミュレーション基盤】
  PLATEAU evacuation-simulation-tools を参考に
  「バスあり/なし」の2シナリオを実装

【検証データ】
  常総市検証報告書（救助人数 約4,258人）
  との照合でシナリオAを検証
```
