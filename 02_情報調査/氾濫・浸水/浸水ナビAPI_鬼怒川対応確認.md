# 浸水ナビAPI 鬼怒川対応確認

> 調査日：2026/04/22  
> 結論：**鬼怒川は浸水ナビAPIに対応済み。常総市周辺の破堤点も取得可能。**

---

## 結論サマリー

| 確認事項 | 結果 |
|---------|------|
| 鬼怒川の対応 | ✅ **対応済み**（河川コード: 8303030203） |
| 管轄 | 国交省 関東地方整備局 下館河川事務所（コード: 21261） |
| 水系 | 利根川水系 |
| 降雨規模 | L1（計画規模）・L2（想定最大規模）両対応 |
| 常総市周辺の破堤点 | ✅ あり（20〜22km区間に複数設定） |
| 2015年実破堤点（左岸21k）の完全一致 | ⚠️ 完全一致なし。**左岸19.5km（BP030）または22.25km（BP034）が最近傍** |

## 2015年実破堤点との対応

- **実際の破堤地点：** 鬼怒川左岸 約21k（茨城県常総市三坂町）
- **浸水ナビでの代替：** 左岸19.5km（BP030）または左岸22.25km（BP034）が最近傍

> 浸水ナビの破堤点は「堤防が実際に存在する区間」を対象に設定されており、2015年の実破堤点（左岸21k）との完全一致はないが、前後の破堤点を使ってシミュレーションは可能。

## 利用するAPIエンドポイント

### 破堤点リスト取得
```
GET https://suiboumap.gsi.go.jp/shinsuimap/Api/Public/GetBreakPoint
  ?lon=139.97&lat=36.06
```

### 最大浸水深取得（左岸19.5km・BP030を使用）
```
GET https://suiboumap.gsi.go.jp/shinsuimap/Api/Public/GetMaxDepth
  ?lon=139.963&lat=36.088
  &bpid=033dac45-a94e-4982-ae06-f47b44bd2ecb
```

### 時系列浸水深取得（ハイドログラフ）
```
GET https://suiboumap.gsi.go.jp/shinsuimap/Api/Public/GetHydrographData
  ?lon=139.969&lat=36.111
  &bpid=b770fb0b-b927-4c31-824f-bf4fdbc7cb8a
```
