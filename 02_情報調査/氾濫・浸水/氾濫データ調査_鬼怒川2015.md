## 3. 交通渋滞の記録

### 確認できた情報（定性的）

- 常総市の検証報告書に「**交通渋滞により市内の避難場所への避難が困難となった**」ため、隣接市に避難場所確保を依頼したことが明記されている
- 主要幹線：**国道294号**（南北軸）・**国道354号**・**県道土浦境線**（東西軸）に避難車両が集中

### 定量的な渋滞記録（速度・渋滞長等）

**⚠️ 確認できず。**

- ETC2.0プローブデータは2015年当時は整備途上
- 検証報告書本文（PDF）の中に渋滞に関する詳細記述がある可能性あり
- → 常総市検証報告書PDFを直接精読して確認が必要

## 6. 研究設計への影響

### 重要な注意点

> **2026/07/21訂正：2015年時点の常総市には予約型乗合交通「ふれあい号」が存在した。** 2009/10/26に運行開始し、2015年度は延べ19,518人が利用した。ただし水害により2015/09/10〜10/12は運休したため、災害時の避難輸送実績としては扱わない。

→ 本研究のシナリオBは、当時存在した地域交通車両を災害時に**固定経路避難シャトルへ転用できた場合**の仮想比較として位置づける。実際のふれあい号の災害運行や予約型の動的配車を再現したものではない。

### 入手確定データでできること

| 研究フェーズ | 使用できるデータ |
|------------|----------------|
| 浸水エリアの設定 | 国土地理院KML（5時点）＋京大防災研の浸水深分布 |
| 道路閉鎖条件の適用 | 上記浸水深データ × OSM道路ネットワーク |
| 逃げ遅れ人数の照合 | 常総市検証報告書の救助人数（約4,258人） |
| 人口分布の設定 | e-Stat 250mメッシュ人口（常総市範囲） |
| シナリオA（車のみ）の検証 | 上記4つ + 自動車保有率データ |
| シナリオB（バス併用）の比較 | 上記 + バスの仮想設定 |

### 渋滞定量データが取れない場合の対応

- シナリオAの結果（シミュレーション上の渋滞・逃げ遅れ）を実際の救助人数（約4,258人）と照合することでモデルを検証する
- 渋滞の「定量記録」がなくても、シミュレーション上で渋滞が発生することを再現し、シナリオBとの差を示すことで研究として成立する
