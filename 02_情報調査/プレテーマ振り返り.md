## 1. 研究テーマ決定までの経緯

**参照ファイル：`経過報告20260304.md`**

3年次プレテーマの出発点として、公共交通オープンデータを活用した5つの研究テーマ候補を検討した。

| テーマ | 新規性評価 |
|--------|-----------|
| ① 身障者向けバリアフリールート検索 | 先行研究多数・差別化困難 |
| ② 天候で不便になる路線・地域の抽出 | **新規性あり**（路線別脆弱性スコアは未開拓） |
| ③ 引っ越し検討者向け交通スコア | 民間製品との差別化困難 |
| ④ 将来消える路線の予測 | **新規性あり**（廃線リスク予測への特化は少ない） |
| ⑤ 混まない電車検索 | 先行実装豊富・新規性なし |

各テーマについてデータ入手可能性・先行研究・開発難易度の観点から評価した結果、**テーマ②（天候影響分析）** が第一候補、**テーマ④（廃線予測）** が第二候補として選定された。

**使用データの公開状況も確認済み：**
- 気象・人口統計・公共交通データ（GTFS）→ 公開済み・無料取得可能
- バリアフリー詳細情報・家賃・混雑データ → 全国一括の標準オープンデータは限定的

## 2. 先行研究調査と既存システムの確認

**参照ファイル：`経過報告20260311.md`**

テーマ②（天候影響分析）を軸として、以下の3点を追加調査した。

### 先行研究の確認結果

- テーマ②に関しては、西日本豪雨（2018年）や名古屋豪雨（2000年）を事例とした**事後分析の論文は存在する**が、路線・地域をまたいだ「天候脆弱性の統計的定量化」は未整備であることを確認した。
- テーマ④に関しては、廃線の「影響分析」研究は存在するが、**廃線リスクの事前予測モデル**に特化した研究は少ないことを確認した。

### 既存システムとの差別化

「GoStopマネジメントシステム」（日本気象協会）や「交通影響予測」（ウェザーニューズ）など、悪天候リスクを扱う既存サービスは存在するが、いずれも**近い将来の予測・アラート**が目的であり、過去データを用いた路線別の「天候脆弱性スコア」の定量化は行われていない。

### 先生からのコメント（記録）

> デマンド交通について、オープンデータチャレンジ限定で配信あり（乗り合いタクシーに似ている）。デマンド交通事業分析・シミュレーションシステムというアプローチの示唆を受けた。

→ このコメントをきっかけに、研究テーマが「天候×公共交通」から**「デマンド交通×災害時避難」**へと方向転換することになった。

## 3. デマンド交通の基礎調査

**参照ファイル：`経過報告20260401.md`**

デマンド交通（DRT：Demand Responsive Transport）について体系的に調査した。

### デマンド交通の概要

- 利用者の事前予約に応じて経路・スケジュールを柔軟に変更して運行する地域公共交通システム
- 1972年大阪府能勢町で日本初導入、2006年道路運送法改正で法的整備、2020年時点で566市町村に拡大
- フルデマンド・セミデマンド・フレックスルートの3形態が存在する

### 現状の課題

- 2030年にバス運転手が約3.6万人（28%）不足と推計
- 平均乗合率が1.1〜1.2人/台と低く、実質タクシー化している地域が多い
- 高コスト（デマンド交通7,651円 vs 既存バス1,376円、福井小浜市の事例）

### 研究テーマとしての新規性確認

既存の公共交通×災害研究は幹線交通の被災影響が中心であり、**デマンド交通に特化した災害時避難の分析はほぼ皆無**であることを確認した。

## 4. 新規システム構想の策定

**参照ファイル：`経過報告20260401.md`**

「デマンド交通×災害情報」を組み合わせたシステムの構想を整理した。

### コアとなる研究課題

> 「災害時に、デマンド交通しか移動手段がない人は、どこにいて、どれだけ逃げられないか？」

### システム処理フロー

```
浸水エリア（ハザードマップ）
    × 浸水エリア内の人口・高齢者数（250mメッシュ統計）
    × 道路通行可能区間
    ↓
要避難人数の推定 → 必要車両台数・車種の自動判別
    ↓
デマンド交通による避難配車シミュレーション
```

### 開発方針の3案

| 案 | 方針 | 特徴 |
|----|------|------|
| 案A | 脆弱性スコアリングモデル | 研究寄り・論文にまとめやすい |
| 案B | 避難支援シミュレーター | 実装寄り・コンテスト出品にも適する |
| 案C | リアルタイムダッシュボード | 実用寄り・実装は比較的軽量 |

## 5. OSSシミュレーションツールの選定

**参照ファイル：`経過報告20260401.md`**

実装環境として活用できるオープンソースツールを調査・比較した。

### 推奨ツール構成

| 優先度 | ツール | 役割 |
|--------|--------|------|
| ★★★ | MATSim（DRTモジュール） | デマンド交通シミュレーションのコア。公式DRTモジュール実装済み |
| ★★★ | Project PLATEAU（evacuation-simulation-tools） | 日本の行政データとの親和性が高く、水害避難シミュレーションに対応 |
| ★★☆ | SynxFlow | Pythonベース。浸水エリアの生成に活用可能 |
| ★★☆ | GAMA / SiFlo | 住民の避難行動モデルが必要な場合に有効 |
| ★☆☆ | SUMO | MATSimと補完的に使用 |

**MATSimを中心に据えた理由：**
- DRT（デマンド型交通）を公式モジュールとして実装済み（`contribs/drt`）
- GTFSネットワークをそのまま読み込み可能
- 2025年に「農村部の脆弱者向け避難計画へのMATSim適用」論文が発表されており、本研究テーマに直接関連する先行事例が存在する

## 6. 使用データの確保と利用可能性の確認

**参照ファイル：`経過報告20260401.md`、`使用データ一覧.md`**

研究に必要な全データソースについて、稼働状況・無料利用・登録要否を確認した。

### 確認済みデータソース一覧

| データソース | 用途 | 稼働状況 | 登録 |
|---|---|---|---|
| ODPT（公共交通） | デマンド交通・GTFSデータ | 稼働中 | **必須** |
| 気象庁API | 気象・災害警戒情報 | 稼働中 | 不要 |
| ハザードマップポータル | 浸水・土砂災害エリア | 稼働中 | 不要 |
| e-Stat API | 人口メッシュ統計 | 稼働中 | **必須** |
| 国土数値情報 | 将来推計人口・道路データ | 稼働中 | 不要 |
| Project PLATEAU | 3D都市モデル・避難ツール | 稼働中 | 不要 |

### 重要な確認事項

- **ODPTのデマンド交通データ**はGTFS-Flex形式で現在9自治体分のみ公開中。研究対象地域がこの9自治体に含まれるか要確認。
- **RESAS APIは2025年3月24日終了済み**。代替として国土交通省データプラットフォーム（DPF）のGraphQL APIを使用する。
- **人口データ**は250mメッシュ単位で無償取得可能であり、リアルタイム公開が整備されていない地方でも静的データで代替可能であることを確認した。

## 7. 先行研究調査（デマンド交通×避難）

**参照ファイル：`デマンド交通_既存研究調査.md`**

「デマンド交通×災害時避難シミュレーション」研究の先行研究・新規性を確認するため、15件の論文・事例を4カテゴリに分類して調査した。

### 調査カテゴリと主な結果

| カテゴリ | 件数 | 結論 |
|---|---|---|
| A. デマンド交通×災害・避難 | 4件 | 「オンデマンド×避難」の実証は1件のみ（2023年、単車両・少人数規模） |
| B. 配車最適化・アルゴリズム | 4件 | 通常運行向けが中心。災害時条件（道路閉鎖・時間的切迫）を扱う研究はない |
| C. 利用実態・価値分析 | 4件 | 平常時の分析が中心。有事のオペレーション自動化を扱う研究はない |
| D. シミュレーション・ツール | 3件 | MATSimが最も本研究と親和性が高い（2025年に農村部避難適用論文あり） |

### 新規性の確認まとめ

| 研究の観点 | 本研究の新規性 |
|---|---|
| デマンド交通の配車最適化 | 通常運行ではなく**災害時・緊急避難**を対象とする |
| 災害×オンデマンド避難 | 複数車両・広域・自動判別へのスケールアップ |
| 要避難人数→台数自動判別 | **本研究独自の提案**（人口メッシュ×浸水エリア×車種判別） |

> **結論：** 「デマンド交通を使った災害時避難のシミュレーション」という切り口は国内外ともに先行研究がほぼ存在せず、高い新規性が確認できた。

## 8. 研究ロードマップの策定

**参照ファイル：`研究ロードマップ.md`**

プレテーマの調査を踏まえ、4年次本研究に向けた7フェーズのロードマップを策定した。

### 研究テーマの確定

**「災害時におけるデマンド交通を活用した避難支援シミュレーションシステムの構築」**

### 研究の核

> 「災害時に、どの地区へ、どの種類の車両を、何台、どの経路で向かわせるべきかを自動判別すること」

### フェーズ構成

| フェーズ | 内容 |
|---------|------|
| Phase 1 | 研究課題の具体化（RQの1文明文化） |
| Phase 2 | 対象地域・対象災害の決定（宇都宮市・洪水を第一候補） |
| Phase 3 | データ取得と利用可能性の確認 |
| Phase 4 | 最小プロトタイプの作成（要避難人数・必要台数の出力） |
| Phase 5 | 配車・ルート探索ロジックの実装 |
| Phase 6 | シミュレーションと評価（ベースライン比較） |
| Phase 7 | 考察・論文化・発表準備 |

### 今後の課題（プレテーマ段階で認識済み）

- ODPTのデマンド交通データ公開範囲が9自治体に限定されており、対象地域との一致を確認する必要がある
- 災害時の実運行停止データが非公開の場合はシミュレーションで代替する必要がある
- 高齢者・障害者などの避難支援条件のモデル化範囲を卒論スコープに収める必要がある

## 振り返りまとめ

プレテーマを通じて、研究テーマが「天候×公共交通の脆弱性分析」から「デマンド交通×災害時避難シミュレーション」へと明確に絞り込まれた。先行研究調査の結果、本研究テーマは国内外ともに先行事例がほぼなく、高い新規性を持つことが確認された。また、研究に必要なデータソースはすべて無償で取得可能であることも確認済みである。4年次本研究では、プレテーマで策定したロードマップに沿って、最小プロトタイプの構築から順を追って実装を進める。
