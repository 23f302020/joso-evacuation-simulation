## A. 洪水浸水想定区域データ（国土数値情報 A31）

### 配布情報

| 項目 | 内容 |
|------|------|
| 配布元 | 国土交通省 国土数値情報ダウンロードサービス |
| データコード | A31（v4.0最新）、A31b（1次メッシュ単位版・2024年） |
| 形式 | GML / **Shapefile** / **GeoJSON**（研究用途にはGeoJSONまたはShapefileが最適） |
| 配布単位 | 地域選択方式（1次メッシュ単位）。全国一括ではない |
| 最新年次 | v4.0：令和4年（2022年）、メッシュ版：2024年 |
| ライセンス | CC BY 4.0（出典表記の上で商用・非商用・研究利用すべて可） |

### 浸水深の属性

浸水深は「実測値」ではなく**ランクコード（段階値）**で格納されている。

| フィールド | 内容 |
|-----------|------|
| `A31_101` | 計画規模（○○年確率）の浸水深ランク |
| `A31_201` | 想定最大規模の浸水深ランク |
| `A31_301` | 浸水継続時間ランク |
| `A31_401` | 家屋倒壊氾濫危険区域区分 |

**ランクの例（要確認）：** 0〜0.5m未満 / 0.5〜1m未満 / 1〜3m未満 / 3m以上 などの段階

> **実装上の注意：** モデル仮定の「浸水深0.5m以上で要避難」との照合は、ランクコードをしきい値でフィルタリングする形になる。

### 参照URL

- データ一覧（v4.0）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A31-v4_0.html
- メッシュ単位版（2024年）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A31b-2024.html
- 利用規約: https://nlftp.mlit.go.jp/ksj/other/agreement.html

## B. 250mメッシュ人口統計（e-Stat API）

### 配布情報

| 項目 | 内容 |
|------|------|
| 正式名称 | 令和2年国勢調査 地域メッシュ統計（250mメッシュ） |
| 配布元 | 総務省統計局 e-Stat |
| 最新年次 | 令和2年（2020年）国勢調査（2022年〜公開） |
| APIキー | **必要**（無料・要ユーザー登録） |

### 高齢者人口の取得可否

**取得可能。** 250mメッシュ単位で以下の年齢区分が利用できる：

- 0〜14歳 / 15〜64歳 / **65歳以上** / 75歳以上 / 85歳以上

### APIでの取得方法

```
エンドポイント：
https://api.e-stat.go.jp/rest/3.0/app/json/getStatsData
  ?appId=【取得したappId】
  &statsDataId=T001109        ← 250mメッシュ人口・世帯数
  &cdArea=【メッシュコード】
  &lang=J
```

| パラメータ | 説明 |
|-----------|------|
| `appId` | 必須。ユーザー登録後に発行（無料・最大3つ） |
| `statsDataId` | `T001109`（250mメッシュ人口） |
| `cdArea` | 対象メッシュコード（最大100件カンマ区切り） |

直接ダウンロード（API不要）も可能：統計GISからCSV形式で一括取得 → Shapefileの `KEY_CODE` で結合。

### 参照URL

- 統計GIS: https://www.e-stat.go.jp/gis
- APIポータル: https://www.e-stat.go.jp/api/
- APIキー登録: https://www.e-stat.go.jp/mypage/user/preregister
- 250mメッシュデータ: https://www.e-stat.go.jp/gis/statmap-search?type=1&toukeiCode=00200521

## C. 道路ネットワークデータ

### 国土数値情報 N13（道路データ）

| 項目 | 内容 |
|------|------|
| 正式名称 | 道路データ（N13）※旧コードKS-7は廃止済み |
| 形式 | GML / Shapefile / GeoJSON |
| 内容 | 道路中心線位置（高速・国道・都道府県道・市町村道等） |
| ノード・リンク構造 | **なし**（ルーティングには後処理が必要） |
| 属性 | 道路種別・幅員区分・道路状態・有料区分 |
| 最新版 | 2024年度（2026年4月公開） |
| ライセンス | CC BY 4.0 |

> **重要：** N13はルーティング（経路探索）に必要なノード・リンクのトポロジー構造を持たない。経路探索には後処理が必要。

### 推奨代替：OpenStreetMap + osmnx

経路探索・シミュレーション用ルーティングには **OSM + osmnx** の使用を推奨。

| 比較項目 | 国土数値情報 N13 | OpenStreetMap（osmnx） |
|---------|----------------|----------------------|
| ノード・リンク構造 | **なし**（後処理必要） | **あり**（即座にグラフ取得可） |
| Pythonでの取得 | Shapefile読み込み | `osmnx.graph_from_place()` 1行 |
| 道路種別フィルタ | 属性コードで選別 | `network_type='drive'` 等で指定 |
| ルーティング | 追加ライブラリ必要 | NetworkXで直接最短経路探索 |
| 更新頻度 | 年1〜2回 | ほぼリアルタイム |
| **卒業研究推奨度** | 補助データとして | **メインデータとして推奨** |

**Pythonでのosmnx利用例：**
```python
import osmnx as ox
G = ox.graph_from_place("川越市, 埼玉県, Japan", network_type='drive')
# 浸水道路の除外はエッジ属性を更新後にgraph_from_addressで再計算
```

### 参照URL

- 道路データ N13: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N13-2024.html
- osmnx（GitHub）: https://github.com/gboeing/osmnx

## E. jSTAT MAP — GIS上での確認・エクスポートツール

| 項目 | 内容 |
|------|------|
| 機能 | 小地域・250mメッシュの人口・年齢・世帯数を地図上で視覚化 |
| 対応粒度 | 250m / 500m / 1kmメッシュ、町丁・字等、基本単位区 |
| 出力形式 | CSV・Shapefile でエクスポート可 |
| 利用条件 | **無料・登録不要**で基本機能が利用可能 |
| 活用場面 | バス配車の優先カバーエリアを地図上で設計する際に便利 |
| URL | https://www.e-stat.go.jp/gis/gislp/ |
