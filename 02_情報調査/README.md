# 02_情報調査

---

## 読む順番

```
経緯・振り返り/J_実装前調査結果.md   ← まずここ（全調査の統合まとめ）
    ↓
データソース/データカタログ.md        ← データパスを調べるとき
    ↓
目的別ファイル（下記サブフォルダ）
```

| `経緯・振り返り/` | 方針転換の経緯・プレテーマ振り返り・実装前統合まとめ |
