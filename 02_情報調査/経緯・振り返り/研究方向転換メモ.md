## 新しい研究の方向性

### 核心となる問い

> 「鬼怒川氾濫時に、全員が自家用車で避難した場合と、デマンド交通バスを活用した場合で、渋滞・逃げ遅れにどれだけ差が出るか？」

### 研究の構造

```
【前提】
  平常時：デマンド交通バスは高齢者向け固定ルートシャトルとして運行
          （住宅街 → 病院 → 買い物 の決まったルートを低頻度運行）
  災害時：別ルートを動的に検索し、避難輸送として切り替え運用

【比較シミュレーション】
  シナリオA（ベースライン）：全住民が自家用車で避難
      → 道路が車で飽和 → 渋滞発生 → 逃げ遅れ多数

  シナリオB（提案）：一部住民がデマンド交通バスを利用（特に高齢者・車なし世帯）
      → 道路上の車両総数が減少 → 渋滞緩和 → より多くの人が脱出

【評価】
  ・渋滞の発生規模・発生時間
  ・避難完了人数
  ・取り残し人数（逃げ遅れ数）
  ・避難完了に要した時間
```

## 転換前との主な違い

| 項目 | 転換前 | 転換後 |
|------|--------|--------|
| 主役 | デマンド交通による避難輸送の最適化 | **自家用車 vs. バス混在の交通流シミュレーション** |
| 比較対象 | 配車あり vs. 配車なし | **車のみ vs. 車＋デマンドバス** |
| 主な評価指標 | 避難完了時間・取り残し人数 | **渋滞の緩和効果＋逃げ遅れ数の差** |
| シミュレーションの種類 | 配車最適化 | **交通流シミュレーション（マクロ or エージェントベース）** |
| DRTの位置づけ | 避難専用の配車最適化システム | **平常時から存在するシャトルバスが災害時に転用** |
| 対象地域候補 | 宇都宮市等（ODPT対応地域） | **鬼怒川流域（常総市等）** |
| 対象データ | ODPTリアルタイムデータ | **鬼怒川2015年氾濫データ・道路交通データ** |

## 新しい研究の強み

1. **実際の氾濫事例（2015年鬼怒川）との照合が可能** — 実データで検証できる
2. **「平常時のシャトルバスを災害時転用」という現実的な提案** — 新たにインフラを用意しなくてよい
3. **渋滞緩和という社会的に分かりやすい効果を示せる** — 「バスがあると渋滞が減る」という直感的なメッセージ
4. **逃げ遅れデータとの比較が可能** — 2015年鬼怒川では実際の逃げ遅れ人数が記録されている
