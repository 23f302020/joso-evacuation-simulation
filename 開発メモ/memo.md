Phase 2 のシナリオA（自家用車のみ）は、常総市版・全域拡張版ともに実装・テスト済みとして扱う。

## 4. 判断が必要な事項

### J-1. Phase 3の対象範囲

| 案 | 内容 | 判断 |
|---|---|---|
| A | 常総市のみで先行実装 | 採用候補 |
| B | 41市区町村へ最初から拡張 | 保留 |

現時点では、**A：常総市のみで先行実装** が最も適切。  
理由は、バス配車・乗降・往復運行のルールは自家用車より複雑であり、まず常総市でシナリオBの挙動を検証してから全域化した方が、結果の誤読や実装ミスを抑えやすいため。

### J-2. バス設定

| 項目 | 暫定採用案 | 理由 |
|---|---|---|
| 台数 | 5台 | 既存仮定と整合する |
| 定員 | 8人/台 | 小型デマンド交通として説明しやすい |
| 運行 | 避難所発→需要地点→避難所帰着 | 救出行動として卒論本文に説明しやすい |

未確定点は、需要地点の選び方、複数人同乗の条件、1台あたりの最大往復回数である。

### J-3. エージェント4種別・救出走行の扱い

Phase 3では、車保有/非保有、高齢/非高齢の4種別を使って、バス利用候補と自家用車利用者を分ける。  
非車所有者の救出走行は、Phase 2へ単独追加するのではなく、Phase 3のバス活用比較の中で扱う方針とする。

理由は、Phase 2シナリオAへ救出走行だけを追加すると、「救出走行ありの車避難」と「バス活用」の比較軸が混ざりやすいためである。

### J-4. 出発時刻分散

暫定採用案は、平均0秒、標準偏差600秒、上限±1800秒の正規分布で出発時刻をずらす。  
ただし、これはPhase 3本体の前提ではなく、必要に応じて追加する感度分析として扱う。

### J-5. 比較指標

Phase 3では、以下を主指標として固定する。

| 指標 | 用途 |
|---|---|
| 到着台数・到着人数 | 避難完了の量的比較 |
| 逃げ遅れ候補台数・人数 | 改善効果の中心指標 |
| 平均旅行時間 | 交通流としての負荷比較 |
| 主要避難路の低速率・停止台数 | 渋滞の空間的影響を説明する |
| バス輸送人数 | デマンド交通バスの効果を説明する |
