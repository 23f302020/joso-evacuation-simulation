## 第3部：環境の比較（U4）— READY の取り直しの後に、読取で

> READY の取り直し（`choice_revalidate.py`）はユーザーが別に指示する。そこで学校PCに `smoke\ns<日付>a_06` と `_07` ができたら、次を行う。

開発PCの基準は、`05_タスク管理/jdrt/U4_比較基準_ns261108a_06_07_20261113.csv`（24行：smoke 06・07 の各12件。`.csv.gz` は展開した中身、`.csv` と `events.jsonl` は生）。学校PCで同じ12件を、次の関数で計算して、24件が一致するかを表にする。

```powershell
function Get-ContentSha([string]$Path) {
  $sha = [Security.Cryptography.SHA256]::Create(); $fs = [IO.File]::OpenRead($Path)
  try {
    $stream = if ($Path.EndsWith('.gz')) { New-Object IO.Compression.GZipStream($fs, [IO.Compression.CompressionMode]::Decompress) } else { $fs }
    ([BitConverter]::ToString($sha.ComputeHash($stream)) -replace '-', '').ToLower()
  } finally { $fs.Dispose(); $sha.Dispose() }
}
```

- 比べるのは、上の CSV の `file` 列のファイルだけ（`manifest.json`・`progress.json`・`sumo.log`・`tripinfo.xml`・`preflight_ready.json` は、生成時刻・ポートなどで差が出て当然なので比べない）。smoke 06 は `_06` どうし、07 は `_07` どうし。
- **24件すべて一致：合格。** 1件でも違えば、**7番目は開始しない**。差のあるファイル名だけを報告して止める（U4：Opus 5.5 high が判断）。一致・不一致は、環境が同じかどうかだけを示し、方式間の方向は読めない。
