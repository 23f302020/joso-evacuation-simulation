# JDRT研究のゴール・判断基準の具体化案

作成：2026-11-05。対象は既存の最終ゴールの明確化。現在のPAP・主指標・比較条件・除外規則・実装・採用/開始条件を変更するものではない。実goal APIのobjectiveは未変更で、本案を採用済みの方法変更とは扱わない。進捗数値はここへ複製しない。

## 1. 一文で表す最終ゴール

**2015年型洪水を与えた常総市08211の登録モデルで、小型JDRTの導入・道路閉鎖予測利用と、後続の大型バス巡回輸送によって、移動困難者の施設受入が各条件で何人・何％ポイント変わるかを明らかにし、支援できた範囲・できない理由・現実への適用限界を、数式と一次データから第三者が確認・再計算できる研究報告にまとめる。**

実災害当日の全運行や医学的な移動能力を再現したと主張することは、現在の資料・モデルでは完了条件にしない。どの現実の主張を支えられるかも、報告の結論に含める。効果がゼロ・悪化・条件依存という結果でも、下記の検証と説明がそろえば研究成果として成立する。

## 2. 研究が答える問い

1. 小型JDRTを加えると、支援を加えない場合に比べて施設受入は何人・何％ポイント変わるか。
2. 同じ小型JDRTで道路閉鎖予測を使うと、現在情報だけの場合から何が変わるか。登録した閉鎖時刻誤差の違いも含める。
3. 需要規模と初期終点規則によって、その差はどう変わるか。受入できなかった人は、登録された終端状態・要求履歴上でどの状態にあるか。
4. 後続の大型バス巡回輸送は、事前にそろえた供給資源と比較条件の下で、受入・積み残し・混雑をどう変えるか。
5. 以上の結論は、どの人口・道路・洪水・運行・施設の仮定に依存し、現実に一般化するには何の資料が不足するか。

## 3. 現行小型車系列の測定方法

現行PAPの評価窓は2015-09-10 12:50〜18:50の6時間である。主対象はモデル上のType4であり、現実の移動困難者全体を個票で同定した集合ではない。

条件ごとの主指標を次で表す。実装・集計の正本はPAPと登録済み集計器とする。

Y(D,u,r,s) = 100 × A4(D,u,r,s) / N4(s)  [%]

- A4：6時間以内に域内の登録4施設で受入を完了したType4人数。
- N4：そのseedの域内Type4全員。未出発・徒歩不能・満員・退出・時間切れを分母から除外しない。
- D：初期終点規則、u：要求意思の需要水準、r：運行/予測条件、s：seed。
- R0は需要別に同じ基準結果を共用する。式のu表記は比較の対応先を表し、R0の追加反復を意味しない。
- 境界退出は施設受入に加えず、別の人数として報告する。配車・乗車・降車も施設受入と区別する。

| 何の差を答えるか | 登録済み比較 | 表示単位 |
|---|---|---|
| 小型JDRT導入 | R1 − R0 | Type4施設受入人数差、受入率の％ポイント差 |
| 誤差あり予測の利用 | R2P900 − R1 | 同上 |
| 誤差0診断条件での予測利用 | R2P0 − R1 | 同上 |
| 登録した閉鎖時刻誤差による違い | R2P900 − R2P0 | 同上 |

P900は予定閉鎖時刻Tに900秒を足した予測表で、通信遅延ではない。P0は入力表と一致する診断条件で、現実の完全予測ではない。予測利用の比較は追加判定と緊急度を含む運用パッケージの差であり、判定機構1個の単独効果と呼ばない。

2終点規則・2需要水準・R0/R1/R2P900/R2P0を登録の共用関係に従って14条件/seed、5seed、全70件で比較する。需要は要求意思シナリオ5%/50%で、2015年の実測利用率ではない。全5seedの値・平均・最小最大を併記し、結果に合わせたseed追加、結果選別、信頼区間・有意差判定の追加はしない。終点規則/需要と差の差の登録診断も省略しない。

## 4. 完了を判定する成果物

| 到達点 | 完了と判定する証拠 |
|---|---|
| A1 入力根拠・仮定・不足の整理 | 需要、供給/運転者/稼働窓、洪水/路面高、施設容量/開設/初期在所、拠点/入口接続について、出典・対象時点・用途・採用値/仮定・不足と結論への影響を追跡できる一覧がある |
| A2 現行小型車70件の正式採用 | 現行登録の全70件が同じ共通実装/入力/依存契約で独立PASS、専用record7、一意台帳、登録集合との一致を満たす。部分記録・未完journal・未診断異常が残っていない |
| A3 全条件の結果表と登録分析 | 上記4比較と登録診断、全5seed、施設受入/退出、未受入の状態内訳、待ち/打切り・運行等の登録副指標が一次出力から再計算され、主要数値の独立照合が済んでいる |
| A4 数式と結果を結ぶ説明 | 登録済みの固定終点/接続・有効施設容量・有限時間の輸送仕事量/処理能力の上限や必要条件を計算し、実現値との差と式の適用範囲を説明できる。上限の残りを単一要因の因果効果に読み替えない |
| B 後続の大型バス検証 | Aの全70採用・登録分析・結果整理の後、BUS-01〜05の根拠整理、比較資源/条件の判断、別PAP/全セルの事前固定、実装と独立検証、全登録実験、分析・限界の報告が完了している |
| C 統合報告と再現可能性 | 上の問いへの定量的な答え、仮定と未取得資料、代替説明、未検証事項、再現コマンド・データ/実装版・全図表の出典がある。現在地/研究計画/現状把握MD・HTML/タスク/正式台帳が整合し、要件別に検査できる |

Aまでの完了を研究全体の完了と呼ばず、B・Cも完了条件に含める。大型バスの台数・定員・停留所・巡回経路・比較資源・セル数は未確定である。今回の具体化で数値を決めたことにはしない。現小型車の結果整理後に既存後続計画の開始条件に従い、結果観測前に固定する。大型化・巡回・相乗りを同時変更する場合は輸送方式全体の差として解釈する。

この統合報告は研究結果の報告であり、保留中の提出用論文編集や、公開・送信の許可を追加しない。

## 5. 抽象的な判断軸を日常の判断へ落とす

| 判断したいこと | 使う基準 |
|---|---|
| 「より現実的」な入力か | 資料の地域・年月日・対象者・運行目的・測定方法・単位が合うかを確認する。2015実績、後年/他地域の参考、研究仮定を区別する。未取得を0や確認済みの値へ変えない |
| シミュレーションを信用できるか | 登録された人物/要求/車両/施設の会計、時計/phase、閉鎖後進入、位置/経路/移動、SHAと独立検証を満たす。有限試験の合格を全状況の安全保証としない |
| 何を優先して直すか | 主指標の定義・比較の公平性・会計/時計の正しさ・結論を支える根拠に直接影響する問題を先に扱う。見栄えや根拠のない高速化を優先しない。結果を良くするための条件調整はしない |
| 「数式から考察した」と言えるか | 式、変数の意味/単位、入力値の出典、成立条件、計算した上限/必要条件、実現値、差を説明できる範囲を対応付ける。式を列挙しただけで完了としない |
| 仮定を変更してよいか | 現行実行中の条件を固定する。主指標/比較/除外/PAPに影響する変更は、根拠・代替案・影響を整理し、必要なユーザー判断と別の事前登録を経る |
| 効果をどう判定するか | 全登録結果を同じ分母と対にした比較で示す。増加・差なし・悪化・条件依存を同じ規則で報告する。「何％以上改善」を根拠なしに成功条件へ置かない |

## 6. 調査・修正を際限なく続けないための区切り

- 調査テーマごとに「どの式/仮定/結論に使うか」を先に示す。取得済みの同一資料/同一SHAの有効な監査を繰り返さない。
- 各テーマを、採用できる根拠がそろった、または確認した範囲・未取得事項・主張への影響・再開に必要な資料を記録した、のどちらかへ整理する。全不足資料の入手を永続的な完了条件にしない。
- 資料不足で現実の値・導入可能性・実災害への効果を識別できない場合、その主張は保留する。登録モデル内で答えられる範囲と保留理由を報告し、未取得の事実を推測で埋めない。
- 修正は再現可能な不具合、登録契約の不一致、主要な誤解を生む説明に対応付ける。正しい入力/実装/依存が変わらず、有効な証拠がある検証は文脈回復のために再実行しない。
- 追加の感度分析や新しい比較が必要になったら、その問い・終了条件・既存結論への影響を先に記録する。現在の登録結果を見て無制限に条件を増減しない。

## 7. 差替え用の短いgoal文

> 常総市08211の2015年型洪水を対象に、登録モデルの6時間以内の移動困難者施設受入について、JDRT導入・道路閉鎖予測利用で何人・何％ポイント変わるか、どの条件で支援できず何が制約となるかを明らかにする。現行小型車系列の登録70件を同一契約で独立検証・正式記録し、全5seed・全登録比較・副指標を一次データから再集計する。固定終点・接続・施設容量・有限時間輸送の数式と実現結果を照合し、実測根拠・研究仮定・不足資料・一般化の限界を対応付けた再現可能な報告を完成させる。その後、既存後続計画に従って大型バス巡回輸送の別PAP/比較条件/全セルを事前固定し、全登録実験と分析を完了して統合報告へ反映する。主要数値の独立照合、再現手順、全体文書整合と要件別完了監査が済んだ時点で完了とする。結果がゼロ・悪化でも同じ基準で報告する。判断・開始・採用・停止・資料不足の扱いは本具体化案と既存PAP/AGENTSに従う。既存run保全、Drive読取のみ、外部送信/公開禁止、07独立監視、未承認方法変更禁止を維持する。

このchatから別の実行chatへの送信・goal登録内容の変更・新run開始は行っていない。ゴールの文面を差し替える際も、元の完了範囲と制限状態を隠したり変更したりしない。
