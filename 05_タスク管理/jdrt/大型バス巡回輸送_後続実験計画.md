# 大型バス巡回輸送 — 小型車系列完了後の実験計画

作成：2026-10-24。状態：後続実験の実施方針をユーザー指定。設計準備のタスクを登録。本実験未開始、具体条件・PAP・実行許可条件は未確定。

## 1. 目的と着手順

ユーザー指示：「現在の条件である小型車による効果の結果が終了後に大型バスを巡回させた効果を確認するシミュレーションを行いたい。」

現在の受付・代替行動系列の登録全70セルについて、独立検証・正式記録・登録済み分析と結果整理が終わった後、大型バスによる巡回輸送を別系列で検証する。現在の小型車系列の条件や実行順は変えない。

大型バスが一定区画の停留所を巡回し、複数人を乗せて避難施設へ運ぶ方式を対象とする。効果の有無・大小は未確認。過去のPhase 1〜3・Scenario Cを再開せず、既存run・凍結実装（step_busを含む）は保全する。

## 2. 比較設計案（正式採用前）

| 候補条件 | 移動方法 | 比較目的 |
|---|---|---|
| 支援なしの対照 | 共通人物の自家用車＋徒歩 | 大型バス導入による差を確認する |
| 小型車支援 | 現系列に対応する個別迎車 | 巡回バスと個別迎車の違いを確認する |
| 大型バス支援 | 停留所を巡回し、複数人をまとめて施設へ輸送 | 巡回輸送の到達・受入・待ち・混雑を確認する |

人口・人物属性・道路・洪水の時間軸・施設条件・出発準備等を比較条件間でそろえる案とする。大型化と巡回・相乗りの同時変更は「輸送方式全体の差」であり、車体サイズや定員だけの効果とは呼ばない。予測利用の有無まで一度に追加せず、必要性と比較範囲を事前に決める。

同じ台数、同じ運転者数、同じ総座席数、同じ費用は異なる比較である。どの供給制約で公平性を定義するかを明記し、数値を決める前に採用判断を残す。現70セルの結果の単純な横並びを新系列の正式比較としない。既存結果を再利用する場合は全比較条件・実装・観測の一致を事前確認し、不一致なら必要な対照を新系列内で取得する。

## 3. 開始前に決める事項

| 項目 | 決める内容・確認する根拠 |
|---|---|
| 車両・供給 | 台数、定員、車長、速度・加減速、乗降可能者、運転者、稼働時間。確保実績と仮定を分ける |
| 区画・停留所 | 巡回対象、停留所の位置・待機場所、道路への接続、大型車の通行可能性と転回条件 |
| 巡回規則 | 周回順、出庫地点、運行間隔、満員時の扱い、施設への向かい方、降車後の次便 |
| 利用者の行動 | 自宅から停留所への移動、歩行困難者のアクセス・介助、待ち期限、乗れない場合の代替、二重輸送防止 |
| 乗降・受入 | 乗降時間と人数の関係、定員管理、施設の開設・残余容量、満員施設への対応 |
| 洪水・運休 | 道路・停留所の閉鎖、経路断絶、迂回・運休、乗車中孤立、予測を使う場合の情報境界 |
| 比較・評価 | 対照条件、資源をそろえる基準、主指標・分母、対象人数、seed、セル集合、除外・停止規則 |
| 観測 | 施設受入と退出の区別、未完理由、徒歩・待ち・乗車時間、停留所積み残し、乗員数、走行距離、道路混雑 |

台数・定員・停留所・経路・運行間隔・乗降時間・利用率・待ち期限・セル数を、このタスク登録だけで採用しない。乗客定員だけを大きくして現在の1要求1人の制御を流用しても、集団輸送の検証にはならない。
