## 1. Phase 2 の開始方針

Phase 2 は、茨城県全域ではなく、まず **常総市実データ版** を対象に始める。

理由は、常総市では以下の Phase 1 出力が揃っており、SUMO/TraCI へ接続する最小ケースとして扱いやすいためである。

| 入力 | パス | 現状 |
|---|---|---:|
| 道路ネットワーク | `04_プログラム/output/network/joso_road_network.graphml` | ✅ 存在確認済み |
| 道路エッジ | `04_プログラム/output/network/joso_edges.gpkg` | ✅ 存在確認済み |
| 道路閉鎖タイムライン | `04_プログラム/output/closure/road_closure_timeline.json` | ✅ 存在確認済み |
| 出発地メッシュ | `04_プログラム/output/agents/origin_points.csv` | ✅ 存在確認済み |
| 避難所 | `04_プログラム/output/agents/shelters.csv` | ✅ 存在確認済み |
| 到達不可結果 | `04_プログラム/output/routes/unreachable_agents.csv` | ✅ 存在確認済み |

Phase 2 の最小成果は、シナリオA（自家用車のみ）の交通流ベースラインを作ることである。バス・デマンド交通の追加は Phase 3 として扱う。

2026/05/14の棚卸しでは、Phase 2に必要な主要入力データはローカルに存在することを確認した。現時点で追加の外部データ取得は不要である。
