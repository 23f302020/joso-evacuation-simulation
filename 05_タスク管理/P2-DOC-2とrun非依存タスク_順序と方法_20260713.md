## C. P2-DOC-2 の詳細な方法（本記録の主眼）

### 目的

Phase 1の `../03_研究設計文書/phase1/Phase1_本文ドラフト.md` に対応する、Phase 2の統合本文ドラフトを作成する。卒論の第3章（研究手法のPhase 2部分）・第4章（分析結果のPhase 2部分）・第5章（考察・限界）に相当する。章立ての正本は `../03_研究設計文書/phase2/論文構成_Phase2.md`。

### 素材→節のマッピング

既存断片を統合するのみで、新規調査は不要。

| 素材（`../06_研究結果/phase2/` ほか） | 統合先（Phase 2本文ドラフトの節） |
|---|---|
| `Phase2_研究結果.md`・`Phase2_SUMO結果説明.md` | 第4章 分析結果（Phase 2：SUMO実行条件・small/10pct/full結果・渋滞指標） |
| `Phase1_Phase2比較解釈.md` | 第4/5章 Phase 1静的 vs Phase 2動的の比較 |
| `Phase2_考察本文案.md` | 第5章 考察（10pct逃げ遅れ0の解釈・可視化の役割・full試行の扱い・Phase 3接続） |
| `Phase2_限界と今後の課題.md`（**§3.5 単一runの限界・regime bimodality の素地あり**） | 第5章 限界と今後の課題 |
| `../03_研究設計文書/phase2/Phase2_SUMO引用・再現性メモ.md` | 第3章 実装環境・SUMO引用 |
| `phase2/Phase2_図表一覧.md`・`Phase2_評価表テンプレート.md` | 図表挿入位置 |
| 文体テンプレート＝`../03_研究設計文書/phase1/Phase1_本文ドラフト.md` | 全体の文体・表記・表形式を合わせる |

### 手順（順序）

1. `../03_研究設計文書/phase2/論文構成_Phase2.md` の第3〜5章を、Phase 2本文ドラフトの節見出しへマップして骨子を確定する。
2. 上表に従い各断片を各節へ割当て、`Phase1_本文ドラフト.md` の文体・表記・表形式に合わせて統合起草する。
3. **regime bimodality相互参照の確定（最重要・決定107／決定146／決定36）**：Phase 2の「41市区町村で逃げ遅れ合計0」「10pctで逃げ遅れ0」は**SUMO既定300秒テレポート下**の値であり、単一run・初期条件脆弱性の限界を明記し、Phase 3のregime bimodality発見（決定107）を相互参照する。素地は `Phase2_限界と今後の課題.md §3.5` にあるため、これを本文ドラフトの限界節へ取り込み相互参照を確定させる。
4. **一般主張の廃止**：「渋滞由来の逃げ遅れは発生しない」という一般主張は全廃する（`../CLAUDE.md` 明記）。ただし**Phase 2の結論自体は撤回しない**（決定107留意点4・Phase 2は再実行しない）。teleport既定下の値である旨の格下げ注記を付す。
5. 数値整合：Phase 3の撤回値（バス到着67・削減29台・シナリオB 9,540台等）を混入させない。Phase 2の数値はPhase 2成果物（`Phase2_研究結果.md`等）から取る。
6. 出力：新規 `../03_研究設計文書/phase2/Phase2_本文ドラフト.md`（Phase 1と同じフォルダ・同じ体裁）。

### 制約

- run非依存・E3数値非依存。Phase 2本文はPhase 3のヌル結論に数値依存しない。限界節でregime相互参照を挿入するのみ。
- Phase 2の結論撤回は禁止。廃止するのは「渋滞由来逃げ遅れ0」の一般主張のみ。
- Phase 3撤回値の混入禁止。
- **本計画は"記録"であり、P2-DOC-2本体の起草は別作業**（本文ドラフトの実起草は着手指示を待つ）。

## D. タスク間の順序・依存

```
P2-DOC-2（即時着手可・run非依存・最優先の実作業）
  ∥ E3図の紐付け（E3確定稿あり・ただし図4-8-1 ECDFは作図要否判断が先）
  → 状態文書更新（CLAUDE.md/タスク一覧）はsession-endで一括
```

- P2-DOC-2 と E3図紐付けは相互独立で並行可。
- 状態文書更新（V1完成・QA済・決定121/125完了・E3固定の反映）は最後にsession-endスキルで一括するのが効率的。
