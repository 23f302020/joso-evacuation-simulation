## 2. 車両会計の正本（T-D-C1）

- **削減式（シナリオB車両会計の唯一の式）：**

```
シナリオBの救出走行台数 = 浸水域内非保有世帯数 × r − (バス実輸送人数 ÷ k)
```

- **確定パラメータ：**

| パラメータ | 採用値（ベース） | 感度レンジ |
|---|---|---|
| 救出走行発生率 r | **1.0** | 0.5 / 0.75 / 1.0 |
| 迎え車1台あたり救出人数 k | **2.3人** | 1.0人/台 |
| 自家用車避難台数基準 | **1台/世帯** | 上限1.55台/世帯 |
| 非保有世帯率 | **15%（暫定・要確認）** | 10% / 15% / 20% |

- 旧「自家用車20,000台／総数23,500台・約15%削減」は**撤回し「初期粗推計」へ格下げ**（市全体世帯数を浸水域へ誤適用していたため）。
- バスに乗れないType3/4は**シナリオAと同一扱い（迎え車が来る）**として会計を閉じる。
- 検算：非保有世帯 21,539×15%÷2.3 ≈ 1,405世帯／削減 324÷2.3≈141台／シナリオA車両 8,164+1,405≈9,569台（正本一致）。
- 非保有世帯率15%はe-Stat住宅・土地統計調査に該当統計なし（`Phase3_規模整合メモ.md`§6で確認済み）。代替統計（AIRIA茨城県世帯当たり保有台数1.565台/世帯、内閣府消費動向調査全国非保有率19.4%）からも15%は反証されず、確定値への昇格は行わず暫定維持。

## 3. 救出走行のSUMO実装仕様（T-D-H1）

## 5. 指標と定義（用語定義集）

- **避難完了**＝指定避難所到着（浸水エリア脱出は補助指標「エリア離脱」として区別）。
- **逃げ遅れ**＝シミュレーション終了時点で指定避難所に未到着の人数（人単位）。車両→人の換算規則：

| 車両種別 | 換算 |
|---|---|
| 世帯避難車 | 1台 = 2.3人 |
| 救出走行車 | 1台 = k人（暫定2.3） |
| バス | 1便 = 実乗車人数そのもの |

- A/B比較は**人単位・Type別**。逃げ遅れ絶対数は主張せず**相対比較**とする（時間軸＝加速シナリオのため。T-D-H2）。

## 7. 実行計画（手戻り防止）

- **full再実行は「規模是正（対象約2万人）＋救出走行注入＋シナリオB」を1回に集約**する。
- 感度軸（r・非保有率・自家用車台数・バス台数・圧縮率）は一因子で追加する。
- 成果物命名は P3-IMPL 系（正本＝`05_タスク管理/phase3/Phase3_実装タスク管理.md`）。

### 実行方針（2026-07-03・ユーザー指示）：常総市先行 → その後データ拡大
「まず常総市を高粒度・研究価値高く一通りの結果を取得し、その後データ量を増やす」方針で段階実行する。

**フェーズA：常総市（08211）で一通りの完全なA/B結果を取得（最優先）**
- A-1 対象規模是正：出発地を t0（2,257人）→ **A31a想定最大＝約2万人・9,569台**へ（`i3_route_search.py:279` 修正、または region pipeline の t7出発地を常総fullに採用）。
- A-2 救出走行を実装し**シナリオAに注入**→ 常総 full 再実行・比較基準を再固定（T-D-H1）。
- A-3 シナリオB（バス5台・救出走行削減式 r=1.0/k=2.3）を実装 → 常総 full で A/B 実行。
- A-4 指標算出：逃げ遅れ（人単位）・避難完了時間分布・渋滞指標・**Type別（公平性）**。床効果を再評価し主指標を確定（T-D-C2）。
- A-5 最小感度：バス台数3/5/10＋圧縮率1軸で**A/B順位の不変性**を確認（T-D-M2の一部）。
- → 出力：常総市 A/B 比較の完全結果セット（表・図・考察）。**ここまでで卒論の中核結果が揃う。**

**フェーズB：データ量の拡大（フェーズA完了後）**
- B-1 感度分析の全軸（r・非保有率・自家用車台数・福祉比率）を展開（T-D-M2残）。
- B-2 41市区町村へ横展開（手法の移転可能性デモ・論文第5章。T-D-M3の実証）。
- B-3 追加シナリオ（浸水規模別 等）。

粒度優先のため、フェーズAは常総市のみ・full解像度で完結させ、量的拡大は後段に回す。
