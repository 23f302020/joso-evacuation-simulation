# Phase 3 詳細タスク管理

> 作成日：2026/05/19  
> 目的：Phase 3（デマンド交通バス活用シナリオ）に入る前の判断・設計・実装・検証タスクを管理する。

---

## 1. Phase 3の目的

Phase 3では、Phase 2のシナリオA（自家用車のみ）を比較基準として、デマンド交通バスを活用したシナリオBを構築する。  
到着人数、逃げ遅れ候補、旅行時間、主要避難路混雑、バス輸送人数を比較し、自家用車避難だけでは救いにくい住民への効果を考察する。

## 4. 推奨する進行順

1. Phase 3実装前仕様書を作成する。
2. 対象範囲を常総市先行で固定する。
3. バス台数・定員・運行範囲・最大往復回数を固定する。
4. エージェント4種別とバス利用候補の定義を固定する。
5. 常総市限定でシナリオBの小規模試行を作る。
6. シナリオA/B比較CSVを作る。
7. 結果を見て、41市区町村へ拡張するか判断する。

---

## 5. 採用予定の基本方針

| 判断項目 | 推奨案 | 理由 |
|---|---|---|
| 対象範囲 | 常総市先行 | 実装・検証が安定するため |
| バス対象者 | 車非保有者・高齢者優先 | 研究テーマと合いやすいため |
| バス運行 | 避難所→需要地点→避難所 | 救出交通として説明しやすいため |
| 比較軸 | Phase 2 A vs Phase 3 B | 自家用車避難とバス活用の比較が明確なため |
| 感度分析 | Phase 3本体後に追加 | 先に基本比較を完成させる必要があるため |
